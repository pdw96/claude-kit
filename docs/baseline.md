# claude-kit 기준 문서

프로젝트 전체의 기준이다. **값을 옮겨 적지 않는다** — 목표 · 범위 · 구조 · 데이터는 아래 문서가 들고, 여기는
가리키기만 한다(ADR 0007). 여기가 직접 드는 것은 조각 나눔과 범위 변경뿐이다. 모양은 `docs/schema.md`
「기준 문서의 칸」.

## 가리키는 문서

| 무엇 | 어디 |
|---|---|
| 목표와 문제 | `README.md` — 원본과 이력이 사는 곳, 배포 경로가 둘인 이유, 되먹임의 방향 |
| 전체 범위와 하지 않을 일 | `README.md` 「들어 있는 것」 · `CLAUDE.md` 「금지」. 프로젝트 수준의 하지 않을 일을 따로 모은 문서는 없다 — 조각마다 `PRD.md` 의 절이 든다 |
| 시스템 구조 | `README.md`(마켓플레이스 · 사본 · 대장 · 비교기) · `docs/adr/` |
| 데이터 모델 | `docs/schema.md` |
| 작업 규칙과 앵커볼트 | `CLAUDE.md` · `AGENTS.md` 「Review guidelines」 |
| 절차 | `docs/procedure.md` — 조각 2 구현 PR 에서 선다 |

## 조각 나눔

`순서` 가 `—` 이면 아직 순서를 매기지 않은 후보다. 일하다 새 조각이 필요하면 그 자리에서 만들지 않고 여기 한
줄을 더한다.

| 3 | 리뷰 루프(변경 관리) | 리뷰 지적을 설계 ② · ③ 에 비춰 가른다 | 2 | 예정 | — |
