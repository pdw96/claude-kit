# 조각 2 설계 — 절차 지도 · 기준 · 기획 · 설계 문서의 틀

기획은 `PRD.md` 조각 2. 칸의 모양은 `docs/schema.md` 「설계 문서의 칸」.

## ① 바뀌는 것

| 파일 | 새로 / 고침 | 무엇 |
|---|---|---|
| `docs/procedure.md` | 새로 | 절차 지도 — 두 층(프로젝트의 기준 문서 → 조각). 조각이 기준 문서의 나눔에서 나오고 닫으며 돌아가는 길, 그리고 일곱 단계마다 들어가는 조건 · 산출물 · 나가는 조건 · 맡는 도구 · 빈자리. 머리에 「아직 아무것도 강제하지 않는다」 |

앵커볼트를 건드린다 — **기준 문서와 설계 문서의 모양**(`docs/schema.md`). 인터뷰에서 저자가 정했다(2026-10-06).
스크립트 · CI · 감사자 · 대장은 건드리지 않는다.

## ② 보장하는 것 / 보장하지 않는 것

**보장하는 것**

- 지도가 두 층이다 — 조각은 기준 문서의 나눔에서 나오고, 닫으며 나눔을 갱신하고, 기준 범위를 벗어나면 기준 문서를
  먼저 고친다.
- 기준 문서 틀이 다른 문서가 든 값을 옮겨 적지 않는다 — 주인 없는 목표 · 범위만 직접 든다.
- claude-kit 자신의 기준 문서가 서고, 프로젝트의 목표 · 범위를 README 대신 직접 든다. README 를 가리키는 것은
  설치 · 배포 경로뿐이다(저자 결정 2026-10-06 — README 는 입구다).
- 지도의 일곱 단계마다 네 칸(들어가는 조건 · 산출물 · 나가는 조건 · 맡는 도구)이 차 있다. 비면 빈자리로 적혀 있다.
- 빈자리마다 증거(PR) 또는 「증거 없음」이 붙어 있다.
- 강호쟁패 #1 · #3 과 ERP #84 가 지도의 어느 단계에서 무엇을 건너뛰었는지 지도에 적혀 있다.
- 설계 틀의 여섯 제목이 `docs/schema.md` 와 같다.
- 틀에 게임 · ERP 전용 칸이 없다.

**보장하지 않는 것(알려진 한계)**

- **강제하지 않는다.** 지도와 틀을 안 따라도 아무것도 떨어지지 않는다 — 로드맵 1 · 3.
- **각 레포에 가지 않는다.** 틀은 claude-kit 에만 있다 — 로드맵 2.
- **회차가 줄어든다는 것.** 그것은 로드맵 1 의 기준이다.
- 증거 없는 빈자리(진척 · 기준선 · 추적 · WBS · 일정 · 안정화 · 종료)의 절차. 이름만 있다.
- **기존 레포의 기준 문서.** 강호쟁패에 조각 나눔을 세우거나 ERP 설계도를 저장소로 옮기지 않는다 — 로드맵 2 ·
  하지 않을 일 4.
- kickoff 가 기준 문서(조각 나눔)를 낳는 것 — 계정 스킬의 일.
- 계정 스킬과의 정합. 지도가 kickoff 를 「0 착수 전 · 1 기획」에 놓지만, 스킬 쪽 문구는 고치지 않는다.
- SI 용어와의 일대일 대응. 지도는 SI 를 근거로 삼되 바이브코딩에 맞게 접었다(PRD 하지 않을 일 5).

## ③ 받는 입력

없음 — 검사 장치가 아니다. 지도가 근거로 읽는 것은 아래뿐이고, 인용은 이 목록 밖으로 넓히지 않는다.

- 강호쟁패 `PRD.md` · `docs/architecture.md`
- 이 저장소의 `README.md` · `PRD.md` 조각 1 · `evals/README.md`
- 계정 스킬 `project-kickoff` 의 본문

## ④ 결정

- 절차 지도를 먼저 그리고, 변경 관리 구현은 다음 조각 — ADR 0005.
- 기획 + 설계는 한 PR, 구현은 설계 ⑥ 대로 — ADR 0006.
- 기준 문서는 색인 + 조각 나눔, 저장소 안 파일 — ADR 0007.
- 설계 문서의 모양은 `docs/schema.md` 에 둔다(틀 파일만 두는 안이 있었다). 대장의 모양과 같은 자리가 계약의
  자리라서다 — 틀은 그것을 베낀 것이고, 둘이 갈리면 `docs/schema.md` 가 참이다.

## ⑤ 검증 계획

- **역검증(손으로):** 강호쟁패 #1 · #3, ERP #84 를 지도에 대 본다. 지도가 「어느 단계에서 무엇을 건너뛰었나」를
  가리키지 못하면 지도를 고친다. ERP(설계도 → 단계 → 조각)와 강호쟁패(기준은 있고 나눔이 없다)의 차이도 지도의
  두 층으로 설명돼야 한다. 결과는 `docs/procedure.md` 의 사례 절에 남긴다.
- **틀 자기 적용:** 이 문서가 `docs/templates/design.md` 와 같은 여섯 제목을 갖는지 본다 — 이 문서는 틀보다
  먼저 썼으니, 틀을 쓸 때 이 문서의 제목을 그대로 옮긴다.
- `./scripts/gates.sh` 통과 — 아무 스크립트도 안 건드렸으니 그대로여야 한다.
- 모델을 부르지 않는다.
