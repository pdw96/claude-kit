+- K **변조 시험의 지문 — `scripts/gate-key.py`.**
+  - K1 **출력** — 한 줄 `gate-bite-py<파이썬 판>-git<git 판>-<24 자리 16진>`. `--list` 면 든 파일마다 `<12 자리>  <경로>` 를 stderr 에 찍는다. 인자는 없음
+    · `--list` 뿐이고, 그 밖은 사용법을 찍고 종료 2.
+  - K2 **넣는 것** — `git ls-files` 가 아는 파일 전부에서 ③ S 의 빼는 쪽을 뺀 것. 넣는 쪽을 적지 않으므로 새 파일은 저절로 든다(`eval-key.py` 와 같은
+    까닭). 파일마다 경로 · 실행 비트 · 내용의 해시가 든다. 지운 파일도 지문을 바꾼다(`eval-key.py` 와 같은 모양).
+  - K3 **빼는 쪽** — ③ S 의 열두 꼴뿐이다. 검사가 대조하는 문서와 기록이다 — 그 문서가 바뀌어도 늘 도는 검사와 자체 시험(② G2)이 다시 대조한다.
+  - K4 **판** — `python3 --version` · `git --version` 의 판이 키에 든다. 못 읽거나 뜻밖의 모양이면 지문을 내지 않고 종료 1.
+  - K5 **수트 지문 밖** — `run-evals.sh` 가 부르지 않아 `eval-key.py route --list` · `full --list` 에 없다. B 의 PR 본문에서 두 목록으로 본다
+    (`bite-gates.sh` 끝의 K1 을 넓히지 않는다 — ADR 0021 의 6 과 같은 쪽).
+  - K6 **지문 시험** — `bite-gates.sh` 의 수트 지문 시험(`keyed`) 옆에 같은 모양의 절. ③ S 의 빼는 꼴마다 「그대로」, ③ S 의 넣는 꼴(S13 ~ S19)마다 「바뀐다」,
+    판이 키 머리에 든다. 흔든 파일은 그 자리에서 백업으로 되돌린다(ADR 0020 의 3).
+- G **`scripts/gates.sh`.**
+  - G1 **인자 없이** — 지금과 같은 스물넷(과 `claude plugin validate` 둘)을 돌리고, 끝 줄이 「스물넷 다 통과」다. 순서만 바뀐다 — `checks` 를 다
+    돌린 뒤 `bites` 를 지금의 앞뒤 그대로 돌린다. 지금은 변조 시험이 그것이 무는 자체 시험 바로 뒤에 있지만, 변조 시험은 자체 시험의 결과를 읽지 않고
+    제 사본에서 따로 돈다. `bite-gates.sh` 가 맨 끝이라 다른 검사가 다 통과한 뒤에 도는 지금의 성질은 그대로다.
+  - G2 **`--skip-bite <근거>`** — `checks` 묶음(열아홉과 `claude plugin validate` 둘)만 G1 의 순서로 돌린다. 시작에 근거를 찍고, 끝 줄이 「열아홉 통과 · 변조 시험 다섯은 건너뛰었다 —
+    <근거>」다. 근거는 한 줄 글이고 `gates.sh` 는 그 뜻을 보지 않는다 — 무엇을 근거로 줄지는 `eval.yml` 이 든다(② E3).
+  - G3 **거절** — CI 밖(`GITHUB_ACTIONS` 가 `true` 가 아님)의 `--skip-bite`, 빈 근거, 모르는 인자 · 인자 셋 이상은 아무 검사도 돌리기 전에 사용법과 까닭을
+    찍고 종료 2(ADR 0046 의 3). 빈 근거는 「건너뛰었는데 까닭이 없는」 실행이 초록으로 남지 않게 막는다.
+  - G4 **묶음** — 변조 시험 다섯(`bite-verify-docs.py` · `bite-slice-gate.py` · `bite-map-pin.py` · `bite-eval-merged-pass.py` · `bite-gates.sh`)이
+    `bites` 묶음에 있고, 그 묶음에는 `scripts/bite-` 로 시작하는 파일을 부르는 줄 말고 아무 명령도 없다. 늘 도는 열아홉과 `claude plugin validate`
+    둘은 `checks` 묶음이다.
+  - G5 **묶음 · 인자 시험** — `bite-gates.sh` 가 (가) `gates.sh` 의 `bites` 묶음 몸에 `scripts/bite-` 가 아닌 명령 줄이 있거나, 다섯 가운데 하나가
+    `bites` 밖에 있으면 떨어진다 (나) G3 의 꼴마다 `gates.sh` 를 불러 종료 2 · 출력에 `PASS` 가 없음을 본다. 변조본 — `checks` 의 한 줄을 `bites`
+    로 옮긴 `gates.sh` 사본에 (가) 를 대어 떨어지는지 본다.
+- M **`scripts/eval-merged-pass.py`** — M1 판정 · 받는 입력 · 종료 코드는 그대로이고, 경고 줄의 「수트가 돈다」(142 줄)를 「돈다」로, 머리의 사용법이
+  키를 `eval-key.py route` 의 값으로만 적은 것을 `gate-key.py` 의 값도 받는다고 바꾼다 — 변조 시험의 지문에도 같은 판정을 쓰므로(② E2). 그 줄을 글자로 기대하는 자체 시험 · 변조본이 있으면 함께 고친다.
+- E **`.github/workflows/eval.yml` gate 잡.**
+  - E1 **지문과 찾기** — `gates.sh` 앞에서 `gate-key.py` 로 지문을 내고, `workflow_dispatch` 가 아니면 `actions/cache/restore` 로 `.gate-pass` 를 그 키로
+    찾는다. PR 실행은 제 범위와 `main` 범위를, `main` 푸시는 `main` 범위를 읽는다(캐시의 범위 규칙 그대로).
+  - E2 **머지된 PR** — `main` 푸시가 E1 에서 못 찾으면 `eval-merged-pass.py <지문>` 으로 그 푸시를 머지 커밋으로 가진 PR 하나의 merge ref 를 본다 —
+    판정은 ADR 0021 의 1 ~ 3 그대로다. 찾으면 같은 키를 `main` 범위에도 적는다.
+  - E3 **건너뛰기** — E1 이나 E2 가 찾았으면 `gates.sh --skip-bite "<근거>"`, 아니면 인자 없이 부른다. 근거는 캐시에 적힌 `.gate-pass/run.txt`(통과한
+    실행의 URL · 커밋)와 지문이고, 같은 글을 `::notice::` 로도 찍는다. E2 로 찾은 것이면 그 PR 번호와 캐시가 적힌 때가 든다.
+  - E4 **적기** — 인자 없이 돈 `gates.sh` 가 통과한 실행만 `.gate-pass/run.txt` 를 쓰고 E1 의 키로 캐시에 적는다. 건너뛴 실행 · 떨어진 실행은 적지 않는다 —
+    「통과한 실행만 적는다」(ADR 0021 의 1 과 같은 근거). `workflow_dispatch` 는 찾지 않고 늘 다 돌고, 통과하면 적는다.
+  - E5 **모르면 다 돈다** — `gate-key.py` 가 지문을 못 내면 경고 한 줄을 찍고 찾지도 적지도 않고 `gates.sh` 를 인자 없이 부른다. E2 가 API 를 못 읽으면
+    `eval-merged-pass.py` 의 지금 규칙대로 경고하고 다 돈다.
+  - E6 **그 밖은 그대로** — gate 잡의 수트 지문 스텝 · eval 잡 · verdict 잡 · 권한 · 동시성 · 러너가 그대로다. 수트 캐시(`.eval-pass`)와 변조 시험 캐시
+    (`.gate-pass`)는 키의 머리(`eval-` · `gate-`)와 폴더가 달라 서로를 찾지 않는다.

+## ④ 결정
+
+**정한 것**
+
+- 변조 시험을 줄이는 길은 지문 건너뛰기다 — 빠르게 하는 일은 조각 나눔의 새 줄. ADR 0046 의 1.
+- 지문은 검사 코드와 규칙의 원천을 넣고, 검사가 대조하는 문서와 기록(③ S1 ~ S12)을 뺀다 — 빼는 쪽만 적는다. ADR 0046 의 2.
+- 로컬은 늘 다 돈다 — `--skip-bite` 는 CI 에서만 받는다. ADR 0046 의 3.
+- 건너뛰는 것은 변조 시험 다섯뿐이고 검사 · 자체 시험 열아홉은 늘 돈다. ADR 0046 의 4.
+- 지문은 새 스크립트 `gate-key.py` 가 낸다 — `eval-key.py` 에 모드를 더하지 않는다. ADR 0046 의 5.
+- `main` 푸시는 `eval-merged-pass.py` 를 그대로 다시 써 머지된 PR 의 통과를 읽는다. ADR 0046 의 6.
+- 건너뛸 때 남기는 것은 근거(통과한 실행 · 커밋 · 지문)의 notice 와 `gates.sh` 의 끝 줄이다. ADR 0046 의 7.
+
+**열어 둔 것**
+
+없음 — 1 ~ 3 은 저자가 이 착공 세션에서 정했고, 4 ~ 7 은 세션이 제안해 저자가 착공 PR(#125)에서 그대로 받았다(2026-10-22).

+## ⑤ 검증 계획
+
+시험을 세우는 조각이다(`bite-gates.sh` 에 지문 시험과 `gates.sh` 시험을 더한다). 보장의 조건마다 보일 것과 시험 규칙은 이렇다 — 꼴 하나하나와 그 변조본의

+- **시험 규칙**

+# 조각 35 — 게이트 변조 시험의 지문 건너뛰기 (2026-10-22 착공)
+
+요구사항이다 — **무엇을 · 왜.** 어떻게 · 경계는 같은 폴더의 `design.md`, 대안이 있던 결정은 ADR 0046.
+
+이 조각을 「다음 조각」으로 적은 닫힌 조각은 조각 34 다 — 그 `## 닫으며 (2026-10-22)` 가 다음 조각을 「게이트 변조 시험의 지문 건너뛰기」(순서 35)로
+적고, 남은 줄이 다 순서 없는 후보라 저자가 이 줄을 골랐다고 했다. 넘긴 것은 없었다. 이 줄은 의존이 없다. 조각 나눔의 줄은 「무엇을 지문에 넣을지 ·
+건너뛸 때 무엇을 남길지는 이 줄을 꺼내는 조각이 정한다」고 넘겼다 — 저자가 이 착공 세션에서 셋을 정했다(ADR 0046 의 1 ~ 3). 이 착공 세션의
+claude-kit 클론은 얕지 않았다(`git rev-parse --is-shallow-repository` → `false`).
+
+## 문제
+
+**md 만 고친 PR 도 CI gate 잡이 17분 넘게 걸리고, 그 가운데 16분 38초가 지난 PR 과 같은 결과를 내는 변조 시험이다.** 「물지 않는 검사는 게이트가
+아니다」(`CLAUDE.md`)라서 `gates.sh` 는 검사마다 변조본을 만들어 떨어지는지 본다. 그 변조 시험은 검사 코드가 무는지를 보는데, 검사 코드를 고치지 않은
+PR 에서도 매번 다시 돈다.
+
+- **숫자** — `main` 푸시 `f2e458d`(조각 34 B, 바꾼 파일이 다 md · json)의 「키 없이 도는 게이트」 스텝이 17분 9초였다([run 39761325720](https://github.com/pdw96/claude-kit/actions/runs/39761325720),
+  로그의 줄 시각으로 셌다). 그 가운데 변조 시험 다섯이 16분 38초다 — `bite-verify-docs.py` 5분 13초 · `bite-slice-gate.py` 48초 · `bite-map-pin.py`
+  17초 · `bite-eval-merged-pass.py` 10초 · `bite-gates.sh` 10분 10초. 나머지 — 검사와 자체 시험 열아홉, `claude plugin validate` 둘 — 는 31초다. 조각 「부적합 대장」 #119
+  `3654dfb`(run 39732577821)도 약 21분이었다.
+- **어디서 오나** — 변조 시험 시간의 대부분은 문서 대조 검사의 자체 시험(`test-verify-docs.py`, 한 번에 약 12초)을 변조본마다 다시 돌리는 데서
+  온다 — `bite-verify-docs.py` 의 스물여섯과 `bite-gates.sh` 의 마흔여섯, 일흔둘에 약 14분이다(한 번 약 12초 × 72 로 어림했다 — `bite-gates.sh` 안의 절마다
+  시각은 로그에 없다).
+- **같은 결과를 되풀이한다** — 최근 머지된 PR 60(#64 ~ #124 의 첫 부모 머지) 가운데, 검사 코드와 그것이 규칙으로 읽는 파일(③ 의 「넣는 쪽」)을 바꾼
+  것은 19 다. 나머지 41 은 조각 폴더 · ADR · 마스터플랜 · README 같은 기록과 입구 문서만 바꿔, 변조 시험이 볼 것이 그대로였다. 조각 하나가 착공 ·
+  닫기 PR 둘을 늘 내므로 조각마다 적어도 두 번, 머지 뒤 `main` 푸시까지 네 번을 이렇게 쓴다.
+- **세션이 게이트를 다 못 본다** — 조각 34 「닫으며」 「제약에서 어긋난 것」이 로컬 `gates.sh` 를 끝까지 돌리지 않았다고 적었다. 로컬은 변조 시험이
+  더 느리다 — 이 세션의 클라우드 컨테이너에서 스물넷이 약 31분이었고, 변조 시험 다섯이 그 가운데 약 30분(`bite-verify-docs.py` 8분 32초 ·
+  `bite-gates.sh` 18분 37초)이었다. 이 조각은 로컬을 줄이지 않는다(하지 않을 일 3) — 기다리는 것은
+  CI 다.
+- **수트는 이미 같은 일을 한다** — 감사자 수트는 입력 지문(`eval-key.py`)이 이미 통과했으면 다시 돌지 않는다(ADR 0021). 같은 원리가 변조 시험에는 없다.
+
+## 핵심 사용자와 시나리오
+
+- 사용자: 저자 한 명, 그리고 claude-kit 에서 조각을 여닫는 세션.
+- 시나리오: 세션이 착공 PR(마스터플랜 · 조각 폴더 · ADR)을 낸다 → CI gate 잡이 변조 시험의 지문을 내고 Actions 캐시에서 같은 지문을 찾는다 →
+  검사 코드가 `main` 과 같아 `main` 범위에서 찾는다 → `gates.sh` 가 검사와 자체 시험 열아홉만 돌리고, 변조 시험 다섯은 「같은 지문이 run … 에서
+  물었다」는 근거와 함께 건너뛴다 → gate 잡이 2분 안에 끝나고 PR 에 notice 한 줄이 남는다 → 다른 날 세션이 검사 하나를 고친 PR 을 낸다 → 지문이
+  새것이라 변조 시험까지 다 돌아 통과하고, 그 실행이 지문을 적는다 → 저자가 머지한다 → `main` 푸시가 머지된 PR 의 merge ref 에서 같은 지문을 찾아
+  변조 시험을 건너뛰고 `main` 범위에도 적는다.
+
+## 성공 기준
+
+1. **같은 지문이면 건너뛴다** — 이 조각의 닫는 PR(지문 밖 파일만 고친다)의 CI 「키 없이 도는 게이트」 스텝이 **2분 안**이고(지금 17분 9초), 그 로그에
+   변조 시험 다섯을 건너뛴 근거(통과한 실행의 URL · 커밋과 지문)가 찍히고, 끝 줄이 「열아홉 통과 · 변조 시험 다섯은 건너뛰었다」다.
+2. **건너뛰는 것은 변조 시험뿐이다** — 1 의 실행에서 `claude plugin validate` 둘과 열아홉이 다 통과를 찍는다. `gates.sh` 의 건너뛰는 묶음에 변조 시험이 아닌 줄을 옮긴 사본은
+   `bite-gates.sh` 의 시험에서 떨어진다.
+3. **지문이 바뀌면 다 돈다** — 설계 ⑥ 의 C(`eval.yml` 을 잇는 PR)의 첫 머리에서 변조 시험 다섯이 다 돌아 통과하고, 그 실행이 지문을 캐시에 적는다.
+   지문 시험(`bite-gates.sh`)이 설계 ③ 의 빼는 쪽 꼴마다 「그대로」, 넣는 쪽 꼴마다 「바뀐다」를 보고, 파이썬 · git 판이 지문에 든다.
+4. **`main` 푸시가 머지된 PR 의 통과를 읽는다** — C 의 머지 `main` 푸시가 머지된 PR 의 merge ref 에서 같은 지문을 찾아 변조 시험을 건너뛰고, 근거에 그
+   PR 번호가 찍히고, `main` 범위에 같은 키를 적는다.
+5. **로컬은 늘 다 돈다** — `gates.sh` 를 인자 없이 부르면 지금과 같이 스물넷이 돈다. CI 밖(`GITHUB_ACTIONS` 가 `true` 가 아님)에서
+   `--skip-bite` 를 주면 아무 검사도 돌리지 않고 종료 2 다. 근거가 비거나 모르는 인자도 종료 2 다.
+6. **비용** — route 수트는 이 조각에서 **한 번** 돈다(C 의 첫 머리 — `eval.yml` 을 고친다). 새 파일은 수트 지문 밖이다 — `eval-key.py route --list` ·
+   `full --list` 에 지문 스크립트가 없다. `gates.sh` 의 검사 수는 스물넷 그대로다.
+7. **게이트** — `./scripts/gates.sh` 가 이 조각의 PR 마다 CI gate 잡에서 통과한다.
+8. **감사 회차** — 닫기 전에 `audit-quality` 를 한 번 돌려 그 기록이 `docs/audit/` 의 부적합 대장에 등록되고, `## 닫으며` 가 회차와 판정을 든다.
+   부적합이 나오면 저자가 판정한다 — 이 조각에서 고칠지 조각 나눔으로 넘길지.
+
+## 하지 않을 일
+
+1. **변조 시험을 빠르게 하지 않는다** — 변조본을 함께 돌리거나 첫 실패에서 멈추는 일은 조각 나눔 「변조 시험 빠르게」로 넘긴다(ADR 0046 의 1). 지문이
+   바뀐 PR 은 지금처럼 17분 남짓, 로컬은 약 31분(클라우드 컨테이너)이다.
+2. **자체 시험(`scripts/test-*.py`)과 검사는 건너뛰지 않는다** — 건너뛰는 것은 `gates.sh` 가 부르는 변조 시험 다섯(`bite-*.py` 넷 · `bite-gates.sh`)뿐이다.
+   열아홉과 `claude plugin validate` 둘은 31초라 늘 돈다(ADR 0046 의 4).
+3. **로컬에서 건너뛰지 않는다** — 로컬 기록 파일도, 사람이 고르는 깃발도 두지 않는다(ADR 0046 의 3).
+4. **수트 지문의 규칙을 바꾸지 않는다** — `eval-key.py` 의 넣고 빼는 것 · 모드는 그대로다. 변조 시험의 지문은 따로 낸다(ADR 0046 의 5).
+5. **다른 PR 의 캐시를 믿지 않고 캐시 항목을 지우지 않는다** — `main` 이 믿는 것은 그 푸시를 머지 커밋으로 가진 PR 하나의 merge ref 뿐이다(ADR 0021 의 2 를
+   그대로 쓴다 — ADR 0046 의 6).
+6. **플러그인 폴더를 고치지 않는다** — `vibe-audit` · `vibe-slice` 의 판과 다른 레포에 심는 검사 둘(`verify-docs.py` · `verify-slice-gate.py`)이 그대로다.
+   다른 레포의 게이트는 이 조각과 상관없다.
+7. **verdict · eval 잡의 판정을 바꾸지 않는다** — 수트를 건너뛰는 조건과 verdict 의 규칙은 그대로다.
+
+## 제약
+
+- 스택: bash · python3 표준 라이브러리, GitHub Actions 캐시 · REST API — CI 의 `GITHUB_TOKEN` 하나. 새 액션 · 외부 CLI 를 들이지 않는다.
+- 원본: `main` `f0dc98e`. 근거: run 39761325720 의 gate 잡 로그(줄 시각), 이 세션의 로컬 측정, `main` 의 첫 부모 머지 60 의 바꾼 파일.
