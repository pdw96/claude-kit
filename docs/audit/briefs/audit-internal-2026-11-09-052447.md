+# 0077 — 감사 회차의 「바뀌는 것」은 `vibe-audit` README 의 담당 표와 시점 표에 대고, 새 장치의 꼴을 더하거나 고치는 조각은 닫기 전 `audit-internal` 을 상시 회차로 든다
+
+2026-11-08 · 결정함 · 1 · 2 는 저자가 조각 58 의 착공 세션에서 정했다(세션이 갈래마다 추천을 앞에 두고 물어, 저자가 둘 다 추천한 쪽을 골랐다). 3 ~ 7 은 세션이 정했고 착공 PR 에서
+저자가 본다
+
+## 맥락
+
+- **정의가 좁다** — 절차 지도 「감사 회차」는 감사자를 고르는 원천 셋 가운데 「바뀌는 것」을 「설계 ① 을 `vibe-audit` 의 README 「대략의 주기」 표에 댄 것」으로 정했다(ADR 0045 의 2 ·
+  `docs/procedure.md:62`). 그 표는 일의 때(앵커볼트 층 · 공개 API · 첫 배포 직전 · 조각 서너 개 · 장애 후)로 고르고, 바뀐 것의 종류(검사 · 평가셋 · 스킬 · 지도 · 작업 규칙)로 고르는 행이 없다.
+- **줄이 정의 밖으로 고른다** — 조각 39 ~ 56 의 감사 회차 줄 가운데 열여섯이 표에 없는 변경을 「바뀌는 것」으로 들어 `audit-quality` · `audit-internal` 을 골랐다(조각 58 설계 ③ A). 앞선
+  조각 35 ~ 38 · 44 · 45 는 같은 꼴을 「표의 어느 행에도 닿지 않는다」고 적었다. 감사 회차 36 · 38 의 「문서에 없어서」 B 가 두 번 짚었다.
+- **원천 없는 회차에 기댄 결정 셋** — ADR 0076 의 3 · ADR 0073 의 7 · 조각 56 설계 ② 가 키 없이 지키는 규칙을 「닫기 전 감사 회차가 본다」고 했다. 새 장치를 세운 조각에 `audit-internal`
+  회차를 세우는 원천이 셋 가운데 없다(감사 회차 37 OB-1). 그 감사가 「`CLAUDE.md` 규칙과 코드가 어긋나는가」로 보는 것은 `audit-internal` 의 몫이라 했고, 싼 길로 상시 회차 한 줄을 들었다.
+- **담당은 이미 한 자리에 있다** — `vibe-audit/README.md` 「감사자 6종」 표가 감사자마다 「무엇만 보는가」를 든다. 범위가 겹치지 않는다는 것은 그 표 아래 문장과 각 감사자의
+  「보지 않는 것」 절이 받친다.
+
+## 대안
+
+1. 「바뀌는 것」: **정의를 넓힌다 — 설계 ① 을 `vibe-audit` README 의 담당 표(「감사자 6종」의 「무엇만 보는가」)와 시점 표(「대략의 주기」)에 댄 것** / 「대략의 주기」 표에 행을 더한다
+   (검사 · 시험 · CI · 평가셋 → `audit-quality`, 작업 규칙 · 절차 · 틀 → `audit-internal`) / 정의는 그대로 두고 지난 줄들을 받아들인 관행으로 기록만.
+2. 원천 없는 회차: **`CLAUDE.md` 「새 장치는 새어 나간 결함에만」 줄에 상시 회차 — 닫기 전 `audit-internal`** / 넓힌 정의에 맡긴다(장치를 세운 조각은 담당 표로 `audit-quality` 가 걸린다) /
+   세 결정의 끝에 날짜 항목을 더해 「조각이 고를 때만 본다」로 좁힌다.
+3. 상시 회차의 문턱: **그 줄이 든 새 장치의 꼴을 더하거나 고치는 조각** / 새 장치를 세우는 조각만.
+4. `vibe-audit`: **그대로 — README 두 표 · 판 · 수트 지문** / 「감사 계획과 부적합 대장」 문단의 「아래 표는 그 원천 가운데 하나」를 두 표로 고치고 판을 올린다.
+5. `vibe-slice`: **지도만 고치고 두 스킬의 지도 링크를 다시 박지 않는다** / 링크를 다시 박고 판을 올린다.
+6. 지난 기록: **세 결정 · 조각 39 ~ 57 의 감사 회차 줄을 고치지 않는다** / 세 결정 끝에 날짜 항목으로 원천을 적는다.
+7. 감사 회차: **닫기 전 `audit-internal` 하나** / `audit-internal` · `audit-quality` 둘.
+
+## 결정
+
+굵은 쪽 일곱.
+
+- 1 — 저자가 정했다. 열여섯 줄이 든 변경은 다 담당 표의 한 행에 닿는다(설계 ③ A) — 줄들이 실제로 쓴 것이 담당이었다. 담당은 감사자의 범위를 아는 `vibe-audit` 쪽 지식이고 이미 한 자리에
+  있어, 지도는 그 표를 가리키기만 한다(ADR 0045 의 2 · ADR 0073 의 5). 시점 표에 종류의 행을 더하면 담당 표와 같은 말을 둘째 자리에 두고, `README.en.md` 의 옮김 표와 `vibe-audit` 판 ·
+  route 수트가 함께 움직인다(ADR 0057 의 2). 기록만 두면 다음 회차가 같은 「문서에 없어서」를 다시 낸다. 대가 — 담당에 대는 일은 한 줄을 읽는 판단이라, 경계의 변경은 세션이 가른다.
+- 2 — 저자가 정했다. 원천 셋째(그 레포의 상시 회차)가 이미 이 꼴을 받는 자리다(ADR 0045 의 2 — 강호쟁패의 「조각을 끝낼 때마다 `audit-internal`」). 새 실패 조건이 아니라 새 장치의 규칙에
+  걸리지 않는다. 넓힌 정의만으로는 `audit-quality` 가 걸리는데, 그 감사자는 「새 장치에 증거가 있는가」를 묻지 않는다(감사 회차 37 OB-1). 주장을 좁히면 원천은 그대로이고 규칙을 보는
+  눈이 우연에 남는다. 상시 회차는 이 저장소의 작업 규칙에 두고 다른 레포에 보내지 않는다 — ADR 0076 의 6 과 같은 까닭이다. 대가 — 그런 조각마다 회차 하나가 는다.
+- 3 — 「새 장치인가」를 가르는 사람이 그 조각을 쓴 세션이라, 문턱을 가름에 두면 가름이 틀린 조각(새 장치를 고침으로 읽은 조각)이 바로 회차를 받지 못한다(감사 회차 37 OB-1 「분류가
+  문제인 바로 그 사람이 스스로 고르는 꼴」). 더하거나 고친 것은 diff 에 보인다. 꼴의 목록은 같은 줄의 첫 「—」 뒤를 가리키고 옮겨 적지 않는다. 대가 — 있는 검사를 고치기만 하는 조각도
+  `audit-internal` 회차를 받는다.
+- 4 — 고칠 감사자 · 커맨드 · 표의 글이 없다. 「아래 표는 그 원천 가운데 하나」는 넓힌 뒤에도 참이다 — 담당 표를 함께 든다는 말이 없을 뿐이다. README 를 고치면 판을 올리는 앞선 예
+  (ADR 0057 의 3)를 따라 route 수트가 돈다. 대가 — 그 문단만 읽은 사람은 시점 표만 원천으로 안다.
+- 5 — 고칠 스킬 문구가 없다. 지도만 고친 커밋은 링크를 건드리지 않는다(ADR 0019 의 2 · ADR 0073 의 8). 대가 — 다른 레포는 링크가 다음에 박힐 때까지 옛 정의를 읽는다.
+- 6 — 기록은 그날의 결정이다(`docs/procedure.md` 「살아 있는 문서와 기록」). 세 결정은 「닫기 전 감사 회차가 본다」고만 했고 원천을 정하지 않았다 — 이 ADR 이 원천을 세울 뿐 그 결정을
+  바꾸지 않아 대체가 아니다. 어느 원천이 각 주장을 받치는지는 조각 58 설계 ③ B 와 닫는 PR 의 `## 닫으며` 가 든다.
+- 7 — 대장의 NC-41 이 고침으로 다음 `audit-internal` 회차를 기다린다(`docs/procedure.md` 「감사 회차」의 대장 원천). 바뀌는 것이 절차 지도 · `CLAUDE.md` 의 규칙 글이라 넓힌 정의로도
+  `audit-internal` 이다. 검사 · 변조본 · 평가셋이 바뀌지 않아 `audit-quality` 의 담당이 없다.
+
+대가 — 담당 표가 바뀌면(감사자가 늘거나 범위가 옮으면) 「바뀌는 것」이 함께 바뀐다. 그것이 한 자리에 둔 까닭이다.
+

+  사람(`CHECKLIST.md` 「요구사항 「제약」에 감사 회차가 있다」)과 리뷰가 본다.
+- **원천이 낸 후보를 다 돌리지 않는다** — 지도의 「줄이 고른다」 그대로다. 넓어진 정의가 후보를 늘려도 회차 수를 정하지 않는다.
+- **다른 레포는 다음 링크 재고정 때까지 옛 정의를 읽는다** — `vibe-slice` 의 두 스킬은 지도를 커밋으로 박았고, 지도만 고친 커밋은 링크를 건드리지 않는다(ADR 0019 의 2 · ADR 0077 의 5).
+- **`vibe-audit` README 의 「아래 표는 그 원천 가운데 하나(바뀐 것 → 감사자)입니다」(`vibe-audit/README.md:79`)는 그대로다** — 시점 표가 원천의 몫인 것은 참이고, 담당 표를 함께 든다는
+  말이 없을 뿐이다. 고치면 `vibe-audit` 판이 오르고 route 수트가 돈다(ADR 0057 의 2 · 3) — 하지 않을 일 1.
+- **상시 회차를 건너뛴 조각을 키 없이 막지 않는다** — 감사 회차 줄과 같다(ADR 0045 의 3).
+- **설계 ② 가 「다음 감사 회차가 본다」로 넘긴 일 일반** — 조각 나눔 「같은 목록의 경계」가 든다(하지 않을 일 7). 이 조각은 ③ B 의 셋만 원천에 닿게 한다.
+- **리뷰가 이 밖을 짚으면 범위 밖이다** — 요구사항 하지 않을 일.
