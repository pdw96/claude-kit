+# 0085 — 닫는 PR 의 글은 다음 조각의 회차가 본다 — 회차의 기준은 이 조각 앞의 마지막 회차가 감사한 커밋이다

+
+## 맥락
+
+- **닫는 PR 은 어느 회차의 diff 에도 들지 않는다** — 닫기 전 회차는 ⑥ 의 마지막 PR 이 머지된 뒤, 단계 6 에 들기 전에 돈다(`docs/procedure.md` 「감사 회차」의 「언제」). 그 회차의 결과를
+  `## 닫으며` 가 들므로 닫는 PR 은 회차 뒤에 선다. 다음 조각의 회차는 기준을 그 조각의 착공 전 `main` 에 둬 왔다. 회차 38 ~ 46 아홉 번의 브리핑 기준이 다 직전 조각의 닫는 PR 머지

+- **닿는 것은 판정 고침뿐이다** — 닫는 PR 이 실은 판정 고침(ADR 0073 의 2)은 대장의 「고침」이라 담당 회차가 재감사로 지금 파일을 본다(예: NC-41 은 회차 39, NC-51 · NC-52 는 회차 46).

+- **결정이 볼 수 없는 회차를 가리킨다** — ADR 0073 의 7 은 다섯 규칙(그 3 이 `## 닫으며` 의 근거)을 「`CHECKLIST.md` 와 닫기 전 `audit-internal` 회차가 본다」고 했다. 그 넘김은 조각을
+  들지 않아 그 넘김을 쓴 조각의 회차다(ADR 0083 의 3). 그 회차는 같은 조각의 `## 닫으며` 보다 앞이다.

+## 결정
+
+굵은 쪽 여섯.
+
+- 1 — 저자가 정했다. 회차를 늘리지 않고 커밋이 빠짐없이 어느 회차의 diff 에 든다 — 앞 회차가 감사한 커밋부터 지금까지를 보면 사이의 닫는 PR · 대장 등록 · 다른 조각의 일이 다 든다. 대장
+  판정으로만 보면 `## 닫으며` 의 근거가 틀려도 아무 회차도 보지 않는다 — 확인불가 일곱이 그 근거로 닫힌 지금, 닫는 세션이 스스로 댄 근거를 스스로 닫는 꼴이 남는다. 닫는 PR 머지 전 회차는
+  조각마다 회차가 늘고, 그 회차가 낸 고침을 누가 보는지가 같은 물음으로 돌아온다. 이 결정은 ADR 0073 의 7 이 「`## 닫으며` 의 근거」에 준 자리(닫기 전 회차)를 바꾸니 대체다(`docs/procedure.md`
+  「살아 있는 문서와 기록」). 대가 — 닫는 PR 의 글은 다음 조각의 회차까지 보지 않는 채로 `main` 에 있다. 다음 조각의 회차가 `audit-internal` 이 아니면 diff 에 들어도 담당이 아니다.
+- 2 — 대장 지나간 쪽의 회차 절 첫 줄은 그 회차가 감사한 커밋을 든다(`docs/audit/nc-ledger.md` 「등록하는 법」 1, 틀 `nc-ledger-history.md` 도 같다) — 세션이 git 역사를 짐작하지 않고 읽는
+  자리다. 이 조각의 회차가 여럿이면(어느 PR 의 머지 전 · 닫기 전) 다 같은 기준을 쓴다 — 둘째 회차가 첫째의 대상을 기준으로 삼으면 diff 가 비거나 이 조각의 앞 PR 이 빠진다. 「직전 조각의 닫는
+  PR 의 첫 부모」는 직전 조각이 회차를 돌지 않았으면 그 앞 조각의 닫는 PR 이 빠진다. 감사자마다 사슬을 두면 드물게 도는 감사자(`audit-secrets` 의 지난 회차는 31)의 diff 가 조각 수십 개로
+  는다. 대가 — 앞 조각들의 회차가 다른 감사자였으면 그 사이 글은 이 회차의 담당이 볼 몫만 본다.
+- 3 — 기준을 고르는 법은 회차를 고르는 법과 같은 자리가 든다(`docs/procedure.md` 「감사 회차」 — 「고르는 법은 여기 한 곳이 든다」). 커맨드는 「기준이 비어 있으면 짐작하지 말고 묻는다」를
+  지킨다 — 기준을 스스로 고르게 하면 그 약속이 바뀐다. 요구사항 틀에 칸을 더하면 틀의 모양(앵커볼트)이 바뀐다. 그래서 `vibe-audit` · `vibe-slice` 는 그대로이고, 지도만 고친 커밋은 두 스킬의
+  지도 링크를 건드리지 않는다(ADR 0019 의 2). 대가 — 다른 레포는 링크가 다음에 박힐 때까지 옛 「돌리는 법」을 읽는다.

+- 5 — 무는 검사는 새 실패 조건이다(`CLAUDE.md` 「새 장치는 새어 나간 결함에만」). 닫는 PR 의 글이 틀려 머지된 뒤 드러난 결함은 아직 없다 — 회차 39 B 는 「문서에 없어서」다. 대가 — 브리핑의
+  기준을 틀리게 준 회차를 키 없이 막지 못한다. 브리핑 머리의 「기준」 줄과 대장의 회차 절을 사람과 그 회차의 감사자가 본다.
+- 6 — 바뀌는 것이 지도의 규칙 글이라 담당 표로 `audit-internal` 이다. 새 기준이 이 조각에서 처음 무는 것을 보이려면 이 조각의 회차부터 새 기준을 쓴다 — 기준은 회차 46 이 감사한 `205bc09` 이고,
+  그 diff 에 조각 65 의 닫는 PR 이 든다. 대장에 `audit-internal` 몫으로 열린 줄은 없다. 검사 · 변조본 · 평가셋이 바뀌지 않아 `audit-quality` 의 담당이 없고, 실패 조건을 더하거나 고치지 않아

+- **다음 회차의 담당이 아니면 diff 에 들어도 보지 않는다** — 다음 조각의 회차가 `audit-quality` 뿐이면 `## 닫으며` 의 근거는 그 담당 밖이다. 다음 `audit-internal` 회차의 기준은 그보다 뒤라 그 글을
+  다시 담지 않는다(ADR 0085 의 2 의 대가). 이 한계는 이 조각의 감사 회차 줄이 범위로 든다(요구사항 「제약」 — 지도 「넘긴 일」의 조각 안의 회차).
+- **기준을 틀리게 준 회차를 키 없이 막지 않는다** — 브리핑 머리의 「기준」 줄과 대장의 회차 절은 사람(`CHECKLIST.md` 의 감사 회차 줄)과 그 회차의 감사자가 본다(ADR 0085 의 5). 이 넘김은 이 조각의
+  감사 회차 줄이 범위로 든다.
+- **지난 닫는 PR 은 본 회차 없이 남는다** — 조각 56 ~ 64 의 `## 닫으며` 근거(하지 않을 일 2).
+- **다른 레포는 링크가 박힐 때까지 옛 「돌리는 법」을 읽는다** — 두 스킬의 지도 링크를 다시 박지 않는다(ADR 0085 의 3).
+- **리뷰가 이 밖을 짚으면 범위 밖이다** — 요구사항 하지 않을 일.

+**정한 것**

+- 닫는 PR 의 글은 다음 조각의 회차가 본다 — 기준은 이 조각 앞의 마지막 회차가 감사한 커밋 — ADR 0085 의 1(저자). ADR 0073 의 7 의 「`## 닫으며` 의 근거」 몫을 대체한다

+

+# 조각 66 — 닫는 PR 의 글을 보는 회차 (2026-11-11 착공)
+
+요구사항이다 — **무엇을 · 왜.** 어떻게 · 경계는 같은 폴더의 `design.md`, 대안이 있던 결정은 ADR 0085.
+
+이 조각을 「다음 조각」으로 적은 닫힌 조각은 조각 65(상시 회차의 문턱)다 — 그 `## 닫으며 (2026-11-10)` 를 읽었다. 넘겨받은 것은 없다 — 회차 46 은 부적합 0 이고 NC-51 · NC-52 를 닫았으며,
+확인불가 셋은 그 절이 닫았고, 「문서에 없어서」 A · B 는 조각 나눔 「실패 조건의 경계 — 도구의 멈춤과 저장소 설정」으로 갔다. 이 줄의 근거는 조각 58 의 닫는 세션이 회차 39 「문서에 없어서」
+B 로 두었다. 의존은 `—` 다. 저자가 이 착공 세션에서 자리의 갈래를 정했다 — 세션이 추천한 쪽(ADR 0085 의 1). 착공은 `main`(`36843e0`) 위에서 연다. 이 착공 세션의 클론은 얕지 않았다(`git
+rev-parse --is-shallow-repository` → `false`).
+
+## 문제
+
+**닫는 PR 의 글은 어느 감사 회차도 보지 않는다.**
+
+- 닫기 전 회차는 ⑥ 의 마지막 PR 이 머지된 뒤, 단계 6 에 들기 전에 돈다(`docs/procedure.md` 「감사 회차」의 「언제」). 닫는 PR 은 그 회차의 결과를 들고 뒤에 선다. 다음 조각의 회차는 기준을
+  착공 전 `main` 에 둬 왔다 — 회차 38 ~ 46 아홉 번의 브리핑 기준이 다 직전 조각의 닫는 PR 머지 커밋이다(설계 ③ A).
+- 판정 고침만 대장 재감사로 닿는다(NC-41 → 회차 39, NC-51 · NC-52 → 회차 46). `## 닫으며` 의 근거(ADR 0073 의 3) · 「바로잡는 것」 · 확인불가를 닫은 근거는 아무 회차도 보지 않는다 —
+  확인불가 U-52 ~ U-58 일곱이 닫는 세션의 `## 닫으며` 근거로 닫혔다(`docs/audit/nc-ledger.md` 「확인불가」).
+- ADR 0073 의 7 은 그 근거를 「닫기 전 `audit-internal` 회차가 본다」고 했다. 그 회차는 같은 조각의 `## 닫으며` 보다 앞이다(감사 회차 39 「문서에 없어서」 B,
+  `docs/audit/records/audit-internal-2026-11-09-052447.md`).
+- 새어 나간 결함은 없다 — 닫는 PR 의 글이 틀려 머지 뒤 드러난 사례는 대장에 없다. 규칙 글이 볼 수 없는 회차를 가리키는 빈자리다.
+
+## 핵심 사용자와 시나리오
+
+- 사용자: 조각의 닫기 전 회차를 부르는 세션과, 그 회차의 `audit-internal`.
+- 시나리오: 세션이 ⑥ 의 마지막 PR 을 머지하고 닫기 전 회차를 부른다 → 지도 「감사 회차」의 「돌리는 법」을 읽고 대장 지나간 쪽의 마지막 회차 절 첫 줄에서 「감사한 커밋」을 꺼내
+  `/audit-brief <그 커밋>` 으로 브리핑을 만든다 → 브리핑 diff 에 앞 조각의 닫는 PR(`## 닫으며` · 마스터플랜 · 판정 고침)이 이 조각의 PR 들과 함께 든다 → 감사자가 앞 조각의 `## 닫으며` 근거를
+  저장소에 대어 본다.
+
+## 성공 기준
+
+1. **결정이 기록된다** — 착공 PR 이 ADR 0085 를 더하고, 그 ADR 이 1 을 이 착공 세션의 저자가 정한 것으로 들며 머리에 「ADR 0073 의 7 가운데 「`## 닫으며` 의 근거」 몫을 대체한다」를 든다.
+   같은 PR 이 ADR 0073 끝에 `## 대체 (2026-11-11)` 절과 「- 7 의 … 몫은 ADR 0085 가 대체했다 — …」를 덧붙인다.

+   마지막 회차 절 첫 줄에서 읽으며 앞 회차가 없으면 착공 전 기본 가지로 두고, (다) 이 조각의 회차가 다 같은 기준을 쓴다고 하고, (라) 그래서 앞 조각의 닫는 PR 이 diff 에 든다고 하며, (마)
+   ADR 0085 를 든다.

+## 하지 않을 일
+
+1. **검사를 세우지 않는다** — 브리핑의 기준을 무는 검사가 없다. 새 실패 조건이 없다(ADR 0085 의 5).
+2. **지난 닫는 PR 을 다시 감사하지 않는다 — 소급하지 않는다** — 조각 56 ~ 64 의 닫는 PR 과 그 조각들의 요구사항 · 감사 기록은 글자 그대로다. ADR 0073 은 끝에 대체 절만 덧붙인다(ADR 0085 의

+3. **「감사 회차」의 다른 항목을 고치지 않는다** — 「언제」 · 「어느 감사자」(원천) · 「결과」 · 「넘긴 일」과 단계 표는 그대로다. 「돌리는 법」 항목만 고친다.
