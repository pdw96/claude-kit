+## ② 보장하는 것 / 보장하지 않는 것
+
+**보장하는 것** — 다 B 가 싣는다.
+
+- **F 찾기** — 검사는 git 이 드는 마크다운(추적하는 것과, 추적 안 됐으나 무시되지 않는 것) 가운데 틀의 출처 줄(③ B1 — 커밋 자리가 16 진수)이 있는 파일을 살아 있는
+  쪽으로 읽고, 그 머리가 든 지나간 쪽의 경로(③ B2)를 읽는다. 출처 줄이 있는 파일이 둘 이상이거나, 지나간 쪽의 경로를 못 읽거나 그 파일이 없으면 떨어진다.
+  출처 줄이 있는 파일이 없으면 — 다른 레포 모드(`--repo <루트>`)는 「대장 없음」 PASS 로 종료 0, 이 저장소(인자 없이)는 떨어진다(ADR 0056 의 3).
+- **R 읽기** — 대장을 ③ B 의 닫힌 꼴로만 읽는다. 절 · 표 머리 · 다음 번호 줄 · 상태 낱말 문장을 못 찾거나, 표 줄의 칸 수가 머리와 다르거나, 표 본문 줄의 첫 칸이 번호가
+  아니면(틀의 자리표시 줄 `<n>` 을 남긴 것) 「못 읽음」으로 떨어진다. 빈 것끼리 견주어 지나가지 않는다 — 대장이 처음 선 빈 표는 지나가되, 표 머리가 없으면 떨어진다.
+- **K1 상태 낱말** — NC 표 둘(살아 있는 쪽 「부적합」 · 지나간 쪽 「닫힌 부적합」)의 줄마다 상태 칸이 굵게 열고 닫히며, 굵은 글이 대장 「닫는 규칙」의 상태 낱말 문장
+  (③ B8)이 든 낱말 하나로 시작하고 그 뒤가 끝 · 공백 · `(` · `—` 다. 낱말은 검사에 박지 않고 그 대장의 문장에서 읽는다 — 문장에 「닫힘」과 「열림 — 저자 판정 대기」가
+  없으면 R 로 떨어진다(ADR 0056 의 4).
+- **K2 줄이 사는 표** — 살아 있는 쪽 「부적합」 표에 상태가 「닫힘」인 줄이 없고, 지나간 쪽 「닫힌 부적합」 표에 「닫힘」이 아닌 줄이 없다(틀 「등록하는 법」 8).
+- **K3 번호** — 「부적합」 절에 다음 번호 줄(③ B4)이 하나다. NC 번호는 두 표를 가로질러 한 번씩이고, 1 부터 다음 번호 앞까지 빠짐이 없고, 다음 번호 이상이 없다. 확인불가(U)
+  번호도 같은 규칙을 「확인불가」 표 하나와 다음 번호 줄의 U 로 본다. 상한은 표가 아니라 다음 번호 줄에서 읽는다(틀 「등록하는 법」 7). 예외 목록을 두지 않는다(ADR 0056 의 5).
+- **K4 회차 절** — 살아 있는 쪽에 `## 회차 ` 로 여는 머리가 없고, 지나간 쪽의 회차 절마다 빈 줄을 건너뛴 첫 줄이 감사한 커밋 줄(③ B9 — SHA 나 「모름」)이다(틀 「등록하는 법」 1).
+- **N 실패 줄** — `FAIL [<규칙 ID>] <파일>:<줄> …` 꼴로 찍고 종료 1. ID 는 F · R · K1 ~ K4 의 실패 갈래마다 하나다 — 줄마다가 아니다. PASS 줄은 읽은 NC · U · 회차 절의
+  수를 찍는다. 쓰는 법이 틀린 인자는 종료 2.
+- **B 변조본** — `bite-gates.sh` 의 새 절이 ADR 0054 의 세 규칙을 따른다 — (가) 돈 변조본 · 대조군 수를 기대한 수와 견주고, (나) 종료 1 이고 기대한 ID 의 실패 줄이 있을
+  때만 물었다로 세고, (다) 대조군은 종료 0 과 PASS 줄을 본다. 검사 코드에서 읽은 ID 집합과 변조본이 기대한 ID 집합을 견주고, 한 ID 의 변조본을 다 지운 목록이 그
+  대조에서 그 ID 하나로 떨어진다(조각 42 의 「ID 마다 변조본」 절과 같은 꼴).
+- **S 다른 레포 길** — 스킬 `slice-docs` 의 「PR 을 내기 전에」가 `verify-ledger.py --repo .` 를 부르고 0 인지 본다. `sync-slice.sh` 는 스킬 폴더째 심으므로 새 검사도
+  간다 — `test-sync-slice.py` 가 심은 사본이 원본과 바이트 그대로인지(Y1), 틀로 세운 임시 레포에서 통과하고 한 자리를 어긋내면 떨어지는지(Y2) 본다.
+- **G 목록** — `gates.sh` 의 `checks` 에 한 줄, `test-gates.py` 의 `CHECKS` 에 한 이름. 둘을 함께 고친다(ADR 0049). 게이트 수와 스킬의 검사 수를 적은 문장은
+  `verify-counts.py` 의 닻이 문다 — 고치지 않으면 B 가 제 게이트로 떨어진다.
+- **V 판** — `vibe-slice` 0.9.0. 두 `SKILL.md` 의 절차 지도 링크는 지도를 고친 B 의 커밋으로 다시 박는다(`verify-map-pin.py`). `verify-budget.py` 가 천장 안이다.
+- **T 시간** — CI gate 잡의 「키 없이 도는 게이트」 스텝이 9 분 안이다. 새 검사는 파일 읽기와 `git ls-files` 한 번이고, 새 절은 검사 사본을 변조본 수만큼 부른다.
+
+**보장하지 않는 것(알려진 한계)**
+
+- **줄의 뜻** — 재감사가 닫지 않았는데 「닫힘」인 줄, 담당이 틀린 줄, 지나간 쪽으로 옮기며 글자가 바뀐 줄, 회차 절의 SHA 가 그 회차가 실제로 본 커밋인지(요구사항
+  하지 않을 일 2). ERP 의 시험도 같은 자리를 「못 보는 부류」로 적었다.
+- **마크다운의 변형** — 검사는 마크다운을 해석하지 않고 ③ B 의 꼴을 글자로 읽는다. 코드 블록 · 인용 · 들여쓰기 안의 `## 회차` 는 머리로 읽혀 거짓 양성을 낼 수 있고,
+  HTML 주석 안의 줄도 읽는다. 그런 꼴을 막는 제약은 두지 않았다(요구사항 하지 않을 일 1) — 걸리면 대장의 글을 고친다.
+- **확인불가의 상태 말** — 틀이 정하지 않아 묻지 않는다. U 는 번호(K3)만 본다.
+- **출처 줄이 없는 대장** — 틀을 베끼지 않고 선 대장(ERP)이나 출처 줄을 지운 대장은 다른 레포 모드에서 「대장 없음」으로 지나간다.
+- **원본 틀이 바뀐 뒤의 옛 사본** — 베낀 대장은 그 레포의 문서이고 저절로 따라가지 않는다(ADR 0044 의 2). 틀의 절 제목 · 표 머리 · 다음 번호 줄을 바꾸면 옛 꼴로 베낀
+  레포에서 새 검사가 R 로 떨어진다 — 상태 낱말은 대장 자신에서 읽어 이 한계 밖이다(ADR 0056 의 결과).
+- **다른 레포에서 PR 을 막는 것** — 스킬이 부를 때만 문다. 머지를 막지 않는다(조각 9 와 같다).

+## 성공 기준
+
+1. **검사가 선다** — 새 검사가 `vibe-slice` 스킬 `slice-docs` 의 `scripts/` 에 있고, 이 저장소의 `gates.sh` 가 `checks` 에서 부른다. `main` 트리에서 PASS 이고 PASS
+   줄이 읽은 NC · 확인불가 · 회차 절의 수를 찍는다. `test-gates.py` 의 고정 목록과 `gates.sh` 의 수 낱말이 함께 바뀐다(ADR 0049).
+2. **규칙 넷을 문다** — 설계 ② 의 넷(상태 낱말 · 줄이 사는 표 · 번호 · 회차 절)마다 그것을 어긴 대장 사본이 그 규칙의 ID 로 떨어진다. `7a6f3e6` 의 꼴(굵게 하지
+   않은 「열림 — 저자 판정 대기」)도 그 가운데 하나다.
+3. **무는 것** — 변조본 절이 조각 41 의 세 규칙을 따른다((가) 센 수 · (나) 그 규칙의 ID 로만 물었다 · (다) 대조군의 종료 0 과 PASS 줄, ADR 0054). 검사가 찍을 수 있는
+   규칙 ID 마다 그 ID 를 기대한 변조본이 있음을 정적으로 대조한다. 대조군은 이 저장소의 대장 · 틀을 처음 베낀 빈 대장 · 대장이 없는 레포 셋이다.
+4. **다른 레포에서 돈다** — 스킬 `slice-docs` 의 「PR 을 내기 전에」가 새 검사를 부르고, `sync-slice.sh` 가 심은 사본이 원본과 바이트 그대로이며 틀로 세운 임시 레포의
+   대장에서 통과하고 한 자리를 어긋내면 떨어진다. `vibe-slice` 판이 0.9.0 이고 `claude plugin validate` 가 두 플러그인을 통과한다.
+5. **시간** — CI gate 잡의 「키 없이 도는 게이트」 스텝이 **9 분 안**이다(기준 — 조각 42 의 #160 [run 40675837919](https://github.com/pdw96/claude-kit/actions/runs/40675837919) 7 분 28 초).
+6. **게이트** — 구현 PR 의 CI gate 잡이 변조 시험까지 통과하고, 작업트리에서 인자 없는 `./scripts/gates.sh` 가 끝 줄 「스물여덟 다 통과」로 끝난다. 수트 지문이
+   바뀌는 그 PR 의 route 수트가 통과한다.
+7. **감사 회차** — 닫기 전에 `audit-quality` · `audit-internal` 을 돌려 `docs/audit/` 의 부적합 대장에 등록하고, 그 등록이 새 검사를 지나며, `## 닫으며` 가 회차를 든다.

+## 하지 않을 일
+
+1. **틀에 없는 규칙을 물지 않는다** — 낮음은 이슈로(ADR 0044 의 7 이 뺐다) · 사본 특화 대기의 W 표 · 「아직 아무도 보지 않은 것」 표(감사 계획의 일)를 무는 ERP
+   의 시험 넷과, 대장의 마크다운 변형(HTML · 들여쓴 울타리 · Setext 머리)을 막는 제약은 원본에 올리지 않는다. 확인불가 표의 상태 말도 틀이 정하지 않아 묻지 않는다.
+2. **줄의 뜻을 판정하지 않는다** — 재감사가 닫지 않았는데 「닫힘」으로 적은 줄, 담당이 틀린 줄, 옮기며 글자가 바뀐 줄은 문장을 읽어야 가른다. 검사는 모양만 본다.
+3. **ERP 를 고치지 않는다** — ERP 의 대장은 틀보다 먼저 선 모양이고 ERP 의 시험이 문다. 틀의 출처 줄이 없는 대장은 이 검사가 「대장 없음」으로 지나간다(`INTENT.md` Not 4).
+4. **틀의 규칙을 바꾸지 않는다** — 닫는 규칙 · 등록하는 법의 뜻은 그대로다. 틀에서 고치는 것은 검사가 대장을 찾는 법을 머리 주석에 적는 것뿐이다.
+5. **감사자 · 커맨드 · 검사기의 본문을 고치지 않는다** — `vibe-audit` 는 그대로이고 판도 그대로다.
+6. **조각 나눔의 다른 줄을 다루지 않는다** — 「가르지 못한 결함 다섯」 · 「항목 10 과 머리의 어긋남」 · 「가르지 못한 빈 갈래 둘」 · 「모델이 모르는 판」 · 「감사자
+   README 의 모호한 수」.

+**보지 않는 것.** 줄의 뜻(재감사 없는 닫힘 · 담당 · 옮기며 바뀐 글자) · 확인불가의 상태 말 · 마크다운의 변형(코드 블록 · 인용 · 주석
+안의 줄도 글자로 읽는다) · 출처 줄이 없는 대장.
+
+표준 라이브러리만 쓴다.
+"""
+import os
+import pathlib
+import re
+import subprocess
+import sys
+
+USAGE = "사용법: python3 verify-ledger.py [<루트> | --repo <루트>]"
+# B1 — 틀을 베낀 대장의 출처 줄. 틀 자신의 줄은 커밋 자리가 `<커밋>` 이라 이 꼴이 아니다.
+ORIGIN = re.compile(r"^- 베낀 틀: claude-kit `vibe-slice/skills/slice-docs/templates/nc-ledger\.md` @ `[0-9a-f]{4,40}`")
+# B2 — 살아 있는 쪽 머리 문단에서 지나간 쪽의 경로를 여는 글. 그 뒤 첫 백틱 토막이 경로다.
+PAST = "**지나간 것**(닫힌 부적합 · 회차 절)은 "
+TICK = re.compile(r"`([^`\n]+)`")
+# B3 — 절. 몸은 다음 `## ` 앞까지.
+LIVE_SECS = ("닫는 규칙", "부적합", "확인불가")
+CLOSED_SEC = "닫힌 부적합"
+ROUND = "회차 "
+# 틀의 회차 절 모양 — 첫 회차 전에는 틀이 이 절을 남기게 한다(지나간 쪽 틀의 머리). 회차가 아니라 모양이라 세지 않는다.
+ROUND_SHAPE = "회차 <n> "
+# B4 — 다음 번호 줄. `**다음 번호` 로 여는 줄은 다 이 꼴이어야 한다.
+NEXT_OPEN = "**다음 번호"
+NEXT = re.compile(r"^\*\*다음 번호: NC-([0-9]+) · U-([0-9]+)\*\*\s*$")
+# B5 — 표 머리.
+NC_HEAD = ("NC", "무엇", "낸 회차", "담당", "심각도", "상태", "판정과 근거")
+U_HEAD = ("U", "무엇", "낸 회차", "담당", "판정하려면", "누가 줄 수 있나", "멈춘 회차", "상태")
+STATUS_AT = NC_HEAD.index("상태")
+SEP = re.compile(r"^\|(?:\s*:?-+:?\s*\|)+\s*$")
+CELL = re.compile(r"(?<!\\)\|")
+# B8 — 상태 낱말 문장. 「닫는 규칙」 절에서 이 글 뒤로 첫 마침표까지(문단 안에서는 줄을 넘는다)를 ` · ` 로 가른다.
+WORDS_OPEN = "**상태 칸은 이 절이 정한 말로 연다** — "
+CLOSED = "닫힘"
+WAITING = "열림 — 저자 판정 대기"
+# B7 — 굵은 글이 낱말 하나로 시작하고 그 뒤가 끝 · 공백 · `(` · `—` 다.
+AFTER_WORD = re.compile(r"$|[\s(—]")
+# B9 — 회차 절의 첫 줄.
+AUDITED = re.compile(r"^- \*\*감사한 커밋\*\*: (?:`[0-9a-f]{4,64}`|모름)(?=$|[\s(—·,])")
+
+
+class Report:
+    def __init__(self, root):
+        self.root = root
+        self.bad = []
+
+    def fail(self, rid, path, line, msg):
+        rel = path.relative_to(self.root).as_posix() if isinstance(path, pathlib.Path) else path
+        where = f"{rel}:{line}" if line else rel
+        self.bad.append(f"FAIL [{rid}] {where} {msg}")
+
+
+def listed(root):
+    """git 이 드는 마크다운 — 추적하는 것과, 추적 안 됐으나 무시되지 않는 것. 루트가 git 맨 위가 아니면 None."""
+    try:
+        top = subprocess.run(["git", "-C", str(root), "rev-parse", "--show-toplevel"],
+                             capture_output=True, text=True, encoding="utf-8", errors="replace")
+        if top.returncode != 0 or os.path.realpath(top.stdout.strip()) != os.path.realpath(root):
+            return None
+        out = subprocess.run(["git", "-C", str(root), "ls-files", "-co", "--exclude-standard", "-z"],
+                             capture_output=True)
+    except OSError:
+        return None
+    if out.returncode != 0:
+        return None
+    names = out.stdout.decode("utf-8", "replace").split("\0")
+    return sorted({n for n in names if n.endswith(".md")})
+
+
+def sections(lines):
+    """`## ` 머리마다 (제목, 머리 줄 번호, 몸 [(줄 번호, 글)]). 머리 앞의 줄은 제목 None 으로."""
+    out, cur = [], [None, 0, []]
+    for i, ln in enumerate(lines, 1):
+        if ln.startswith("## "):
+            out.append(cur)
+            cur = [ln[3:].rstrip(), i, []]
+        else:
+            cur[2].append((i, ln))
+    out.append(cur)
+    return out
+
+
+def one(r, path, secs, title):
+    """제목이 꼭 한 번인 절의 (머리 줄 번호, 몸). 없거나 겹치면 R 을 찍고 None."""
+    found = [s for s in secs if s[0] == title]
+    if len(found) != 1:
+        at = " · ".join(str(s[1]) for s in found)
+        r.fail("R", path, None, f"`## {title}` 절이 {len(found)} 번이다{f'(줄 {at})' if at else ''} — 꼭 한 번이어야 읽는다")
+        return None
+    return found[0][1], found[0][2]
+
+
+def cells(text):
+    return [c.strip() for c in CELL.split(text.rstrip())[1:-1]]
+
+
+def table(r, path, sec, head):
+    """절의 표 — 머리가 `head` 이고 그 뒤 구분 줄, 몸은 이어진 `|` 줄. 몸 [(줄 번호, 칸들)]. 못 읽으면 R 을 찍고 None."""
+    at, body = sec
+    rows = [(i, ln) for i, ln in body if ln.startswith("|")]
+    if not rows:
+        r.fail("R", path, at, f"표 머리 `| {' | '.join(head)} |` 를 못 찾았다")
+        return None
+    i0 = next(k for k, (i, ln) in enumerate(body) if ln.startswith("|"))
+    hi, hl = body[i0]
+    if tuple(cells(hl)) != head or not hl.rstrip().endswith("|"):
+        r.fail("R", path, hi, f"표 머리가 `| {' | '.join(head)} |` 가 아니다")
+        return None
+    if i0 + 1 >= len(body) or not SEP.match(body[i0 + 1][1]) or len(cells(body[i0 + 1][1])) != len(head):
+        r.fail("R", path, hi + 1, "표 머리 뒤에 칸 수가 같은 구분 줄이 없다")
+        return None
+    got, k, ok = [], i0 + 2, True
+    while k < len(body) and body[k][1].startswith("|"):
+        i, ln = body[k]
+        cs = cells(ln)
+        if not ln.rstrip().endswith("|") or len(cs) != len(head):
+            r.fail("R", path, i, f"표 줄의 칸이 {len(cs)} 이다 — 머리와 같은 {len(head)} 이고 `|` 로 닫아야 읽는다")
+            ok = False
+        elif not re.fullmatch(r"[0-9]+", cs[0]):
+            r.fail("R", path, i, f"표 줄의 첫 칸 {cs[0]!r} 이 번호가 아니다 — 틀의 자리표시 줄은 줄째 지운다")
+            ok = False
+        else:
+            got.append((i, cs))
+        k += 1
+    for i, ln in body[k:]:
+        if ln.startswith("|"):
+            r.fail("R", path, i, "표가 끊겼다 — 절 안의 표 밖에 `|` 로 여는 줄이 있다")
+            ok = False
+    return got if ok else None
+
+
+def status_words(r, path, sec):
+    """B8 — 「닫는 규칙」 절의 상태 낱말. 못 읽으면 R 을 찍고 None."""
+    at, body = sec
+    hits = [k for k, (i, ln) in enumerate(body) if WORDS_OPEN in ln]
+    if len(hits) != 1:
+        r.fail("R", path, at, f"상태 낱말 문장(`{WORDS_OPEN.strip()}`)이 {len(hits)} 번이다 — 꼭 한 번이어야 읽는다")
+        return None
+    k = hits[0]
+    i0 = body[k][0]
+    text = body[k][1].split(WORDS_OPEN, 1)[1]
+    while "." not in text and k + 1 < len(body) and body[k + 1][1].strip():
+        k += 1
+        text += " " + body[k][1].strip()
+    if "." not in text:
+        r.fail("R", path, i0, "상태 낱말 문장이 마침표 없이 문단에서 끝난다")
+        return None
+    words = [w.strip() for w in re.sub(r"\s+", " ", text.split(".", 1)[0]).split(" · ")]
+    if not all(words):
+        r.fail("R", path, i0, f"상태 낱말 문장에 빈 낱말이 있다 — {words}")
+        return None
+    for need in (CLOSED, WAITING):
+        if need not in words:
+            r.fail("R", path, i0, f"상태 낱말 문장에 낱말 「{need}」 없이는 읽지 않는다 — 줄이 사는 표와 판정 전 상태를 가르는 낱말이다")
+            return None
+    return sorted(words, key=len, reverse=True)
+
+
+def status_of(cell, words):
+    """B7 — 상태 칸이 여는 낱말. 굵게 열고 닫지 않았거나 낱말로 시작하지 않으면 None."""
+    if not cell.startswith("**"):
+        return None
+    end = cell.find("**", 2)
+    if end < 0:
+        return None
+    bold = cell[2:end]
+    for w in words:
+        if bold.startswith(w) and AFTER_WORD.match(bold[len(w):]):
+            return w
+    return None
+
+
+def judge(root, repo):
+    r = Report(root)
+    names = listed(root)
+    if names is None:
+        r.fail("F", ".", None, "루트가 git 작업 트리의 맨 위가 아니다 — 대장을 git 이 드는 파일에서 찾는다")
+        return r, None
+    lives = []
+    for n in names:
+        p = root / n
+        try:
+            text = p.read_text(encoding="utf-8")
+        except (OSError, UnicodeDecodeError):
+            continue
+        if any(ORIGIN.match(ln) for ln in text.split("\n")):
+            lives.append(n)
+    if not lives:
+        if repo:
+            return r, "none"
+        r.fail("F", ".", None, "틀의 출처 줄(`- 베낀 틀: claude-kit …nc-ledger.md @ `<커밋>``)이 있는 마크다운이 없다 — 이 저장소는 대장이 있어야 한다")
+        return r, None
+    if len(lives) > 1:
+        r.fail("F", ".", None, f"틀의 출처 줄이 있는 마크다운이 {len(lives)} 이다 — {' · '.join(lives)}. 살아 있는 쪽은 하나다")
+        return r, None
+    live = root / lives[0]
+    lt = live.read_text(encoding="utf-8").split("\n")
+    lsecs = sections(lt)
+    head = "\n".join(ln for _, ln in lsecs[0][2])
+    past = None
+    if PAST in head:
+        m = TICK.search(head.split(PAST, 1)[1])
+        past = m.group(1) if m else None
+    if not past:
+        r.fail("F", live, None, f"머리 문단에서 지나간 쪽의 경로(`{PAST.strip()}` 뒤 첫 백틱 토막)를 못 읽었다")
+        return r, None
+    hp = root / past
+    if (pathlib.PurePosixPath(past).is_absolute() or ".." in pathlib.PurePosixPath(past).parts
+            or not hp.is_file() or past == lives[0]):
+        r.fail("F", live, None, f"지나간 쪽 `{past}` 이 저장소 맨 위에서부터의 경로로 있는 다른 파일이 아니다")
+        return r, None
+    try:
+        ht = hp.read_text(encoding="utf-8").split("\n")
+    except (OSError, UnicodeDecodeError) as e:
+        r.fail("F", hp, None, f"지나간 쪽을 읽지 못했다 — UTF-8 문서여야 한다({type(e).__name__})")
+        return r, None
+    hsecs = sections(ht)
+
+    # R — 절 · 상태 낱말 · 다음 번호 · 표
+    rules, open_, unk = (one(r, live, lsecs, t) for t in LIVE_SECS)
+    closed = one(r, hp, hsecs, CLOSED_SEC)
+    words = status_words(r, live, rules) if rules else None
+    nexts = []
+    if open_:
+        for i, ln in open_[1]:
+            if ln.startswith(NEXT_OPEN):
+                m = NEXT.match(ln)
+                if not m:
+                    r.fail("R", live, i, "다음 번호 줄이 `**다음 번호: NC-<n> · U-<m>**` 꼴이 아니다")
+                else:
+                    nexts.append((i, int(m.group(1)), int(m.group(2))))
+        if not nexts and not any(ln.startswith(NEXT_OPEN) for _, ln in open_[1]):
+            r.fail("R", live, open_[0], "`## 부적합` 절에 다음 번호 줄(`**다음 번호: NC-<n> · U-<m>**`)이 없다")
+    nc_live = table(r, live, open_, NC_HEAD) if open_ else None
+    u_rows = table(r, live, unk, U_HEAD) if unk else None
+    nc_past = table(r, hp, closed, NC_HEAD) if closed else None
+
+    # K1 · K2 — 상태 낱말과 줄이 사는 표
+    if words is not None:
+        for path, rows, here in ((live, nc_live, "살아 있는 쪽 「부적합」"), (hp, nc_past, "지나간 쪽 「닫힌 부적합」")):
+            for i, cs in rows or []:
+                w = status_of(cs[STATUS_AT], words)
+                if w is None:
+                    r.fail("K1", path, i, f"NC-{cs[0]} 의 상태 칸 {cs[STATUS_AT][:40]!r} 이 굵게 연 상태 낱말이 아니다 — "
+                                          f"「닫는 규칙」의 낱말: {' · '.join(sorted(words, key=len))}")
+                elif (w == CLOSED) != (path == hp):
+                    r.fail("K2", path, i, f"NC-{cs[0]} 의 상태가 「{w}」인데 {here} 표에 있다 — "
+                                          f"닫힘은 지나간 쪽 「닫힌 부적합」, 그 밖은 살아 있는 쪽 「부적합」에 산다")
+
+    # K3 — 번호
+    if len(nexts) > 1:
+        r.fail("K3", live, nexts[1][0], f"다음 번호 줄이 {len(nexts)} 이다(줄 {' · '.join(str(n[0]) for n in nexts)}) — 하나여야 한다")
+    elif len(nexts) == 1:
+        at, nn, un = nexts[0]
+        # 번호는 1 부터다 — 빈 표에서 0 을 받으면 다음 등록이 NC-0 · U-0 을 준다(조각 43 설계 끝 「경계를 정했다」).
+        for kind, upto in (("NC", nn), ("U", un)):
+            if upto < 1:
+                r.fail("K3", live, at, f"다음 번호 {kind}-{upto} 이 1 보다 작다 — 번호는 1 부터다")
+    if len(nexts) == 1 and nc_live is not None and nc_past is not None and u_rows is not None:
+        at, nn, un = nexts[0]
+        for kind, rows, upto in (("NC", [(live, i, cs) for i, cs in nc_live] + [(hp, i, cs) for i, cs in nc_past], nn),
+                                 ("U", [(live, i, cs) for i, cs in u_rows], un)):
+            seen = {}
+            for path, i, cs in rows:
+                n = int(cs[0])
+                if n in seen:
+                    r.fail("K3", path, i, f"{kind}-{n} 이 두 번이다 — 앞의 줄은 {seen[n]}. 번호는 표를 가로질러 한 번씩이다")
+                    continue
+                seen[n] = f"{path.relative_to(root).as_posix()}:{i}"
+                if n < 1 or n >= upto:
+                    r.fail("K3", path, i, f"{kind}-{n} 이 다음 번호 {kind}-{upto} 앞의 번호가 아니다 — 줄을 더하면 다음 번호를 올린다")
+            lost = [n for n in range(1, upto) if n not in seen]
+            if lost:
+                r.fail("K3", live, at, f"{kind} 번호 {', '.join(map(str, lost))} 이 어느 표에도 없다 — 다음 번호 {kind}-{upto} 앞은 다 있어야 한다")
+
+    # K4 — 회차 절
+    for title, i, _ in lsecs[1:]:
+        if title.startswith(ROUND):
+            r.fail("K4", live, i, f"살아 있는 쪽에 회차 절 `## {title}` 이 있다 — 회차 절은 지나간 쪽 끝에 둔다")
+    rounds = 0
+    for title, i, body in hsecs[1:]:
+        if not title.startswith(ROUND) or title.startswith(ROUND_SHAPE):
+            continue
+        rounds += 1
+        first = next(((k, ln) for k, ln in body if ln.strip()), None)
+        if first is None or not AUDITED.match(first[1]):
+            r.fail("K4", hp, first[0] if first else i,
+                   f"회차 절 `## {title[:40]}` 의 첫 줄이 감사한 커밋 줄(`- **감사한 커밋**: `<sha>`` 나 `모름`)이 아니다")
+
+    if r.bad:
+        return r, None
+    return r, (lives[0], past, len(nc_live) + len(nc_past), len(u_rows), rounds)
+
+
+def main(argv):
+    repo = argv[:1] == ["--repo"]
+    args = argv[1:] if repo else argv
+    if len(args) > 1 or (repo and not args) or any(a.startswith("-") for a in args):
+        print(USAGE, file=sys.stderr)
+        return 2
+    # 부른 경로의 두 단 위 — 링크를 따라가지 않는다. `scripts/` 의 링크로 부르면 이 저장소다.
+    root = pathlib.Path(args[0]) if args else pathlib.Path(os.path.abspath(__file__)).parent.parent
+    if not root.is_dir():
+        print(USAGE, file=sys.stderr)
+        print(f"루트 `{root}` 가 폴더가 아니다", file=sys.stderr)
+        return 2
+    root = root.resolve()
+    r, got = judge(root, repo)
+    if r.bad:
+        for b in r.bad:
+            print(b)
+        return 1
+    if got == "none":
+        print("PASS verify-ledger.py — 대장 없음(틀의 출처 줄이 있는 마크다운이 없다 — 대장을 세우면 이 검사가 문다)")
+        return 0
+    live, past, nc, u, rounds = got
+    print(f"PASS verify-ledger.py — 대장 {live} · {past} 에서 NC {nc} · 확인불가 {u} · 회차 절 {rounds} 을 읽었다")
+    return 0
+
+
+if __name__ == "__main__":
+    # 출력은 콘솔 인코딩과 상관없이 UTF-8 이다 — cp949 콘솔에서 `—` 를 찍다 예외로 끝나지 않게(verify-docs.py 와 같다).
+    for stream in (sys.stdout, sys.stderr):
+        stream.reconfigure(encoding="utf-8")
+    sys.exit(main(sys.argv[1:]))
