+# 0048 — `eval.yml` 의 변조 시험 적기 · 건너뛰기 조건은 늘 도는 검사가 닫힌 목록으로 문다
+
+2026-10-25 · 결정함 · 1 과 6 의 「`eval.yml` 을 고친다」는 저자가 이 착공 세션에서 정했다(세션이 순서 없는 후보 여섯을 묻고 저자가 세션이 추천한 이 줄을
+골랐고, 수트 한 번의 비용을 물어 세션이 추천한 「고친다」를 골랐다). 2 ~ 5 와 6 의 나눔은 세션이 제안했고 착공 PR 에서 저자가 본다
+
+## 맥락
+
+`eval.yml` gate 잡은 변조 시험 다섯까지 다 돌아 통과한 실행만 변조 시험의 지문을 캐시에 적고, 같은 지문의 다음 실행은 그 근거로 변조 시험을 건너뛴다
+(ADR 0046). 적는 조건은 `eval.yml` 의 글 — 인자 없는 갈래의 `full=true` 와 적는 스텝의 `if` — 이고, 그것을 무는 것은 리뷰뿐이다. `audit-quality` 가 조각 35
+의 두 회차와 조각 36 의 회차 3 에서 같은 자리를 관찰 OB-1 로 냈고, 셋째 회차가 규칙을 세우거나 두지 않는다는 ADR 을 남기자고 제안했다
+(`docs/audit/records/audit-quality-2026-10-25-105619.md`). `gates.sh` 쪽의 같은 자리는 조각 36 이 `test-gates.py` 로 닫았다. 저장소는 표준 라이브러리만 쓰고
+(`CLAUDE.md` 「스택」), 파이썬 표준 라이브러리에 YAML 파서가 없다. `eval.yml` 은 수트 지문에 통째로 들어 고치면 route 수트가 돈다(`scripts/eval-key.py`).
+
+## 대안
+
+1. 무엇을: **검사를 세운다** / 두지 않는다는 결정을 이 ADR 로 남겨 관찰을 닫는다.
+2. 자리: **늘 도는 `checks` 묶음의 새 검사 `scripts/verify-eval-gate.py`** / `bite-gates.sh` 의 한 절(`bunch` 처럼) / `eval.yml` 의 따로 스텝.
+3. 모양: **판정에 드는 칸(조건 · 명령 · 입력)은 닫힌 목록을 글자 그대로, 알림 글 · 주석 · 스텝 이름 · 액션의 판은 자유** / 금지하는 꼴의 목록(`|| true` ·
+   `continue-on-error` · `always()` …) / 스텝 전체를 글자 그대로.
+4. 범위: **gate 잡의 머리와 첫 열한 스텝(체크아웃부터 변조 시험 지문을 적는 캐시 저장까지), 그리고 파일 전체의 `.gate-pass` · `gfp` 줄** / 적기 · 건너뛰기의
+   여덟 스텝만 / 수트 지문의 사슬과 verdict 까지.
+5. 읽는 법: **지금 쓰는 꼴만 읽는 줄 단위 읽기, 읽는 자리에 그 밖의 꼴이 오면 거절** / YAML 파서를 들인다 / 몇 줄을 정규식으로 찾는다.
+6. PR 나눔: **B 가 검사, C 가 `eval.yml` 의 주석(수트 한 번)** / 한 PR / `eval.yml` 을 고치지 않는다.
+
+## 결정
+
+굵은 쪽 여섯.
+
+- 1 은 세 회차가 같은 자리를 냈고, 그 자리가 무너지면 「물지 않는 검사는 게이트가 아니다」가 아무 빨강 없이 무너지기 때문이다 — 거짓 근거가 한 번 적히면
+  검사를 고친 다음 PR 이 변조 시험 없이 지나간다. 저자가 이 줄을 골랐다.
+- 2 는 건너뛰는 조건까지 물어야 하기 때문이다. `bite-gates.sh` 는 건너뛰는 실행에서 돌지 않아, 건너뛰는 조건을 거짓으로 만든 `eval.yml`(예: `HIT` 를 늘 참으로)이
+  바로 그 검사를 건너뛰게 한다. `checks` 는 두 갈래 다 돌고 로컬에서도 돈다. `eval.yml` 의 따로 스텝은 로컬에서 돌지 않고, `eval.yml` 을 고친 같은 PR 이 그
+  스텝도 함께 지울 수 있다. 조각 나눔의 줄이 든 「`bunch` 처럼」은 글을 읽는 법을 뜻하고 자리를 뜻하지 않는다고 읽었다. 대가 — 늘 도는 검사가 스물하나,
+  인자 없는 `gates.sh` 가 스물여섯이 된다.
+- 3 은 금지하는 꼴의 목록이 열린 목록이기 때문이다 — `|| true` 를 막아도 `| tee` · `set +e` · `if ! …` · `continue-on-error` 가 차례로 지나간다. 닫힌 목록은 모르는
+  꼴을 다 거절한다. 스텝 전체를 글자 그대로 두면 알림 글 하나를 고칠 때마다 검사를 고친다. 대가 — 판정에 드는 칸을 고치는 PR(예: `node-version` 을 올리기)은 검사의
+  목록도 함께 고친다. 그 PR 은 변조 시험 지문이 바뀌어 다 돌고, 리뷰가 두 쪽을 함께 본다. 목록이 `eval.yml` 과 검사 둘에 있는 것은 「같은 목록을 두 군데 두면
+  갈린다」(`CLAUDE.md`)의 꼴이지만, 갈리면 조용히 갈리지 않고 떨어진다 — 그것이 검사의 일이다.
+- 4 는 지문이 열한째 스텝에서 이미 캐시에 적히기 때문이다 — 그 뒤의 스텝은 적기를 바꾸지 못한다. 첫 셋(체크아웃 · 노드 · CLI 설치)을 넣는 것은 그 자리의
+  `run` 이 `gates.sh` 앞에서 작업트리를 바꿀 수 있어서다. 다른 자리가 근거 파일이나 지문을 쓰는 길은 파일 전체의 줄 찾기로 막는다. 수트 지문의 사슬은 같은
+  모양이지만 관찰이 나온 적이 없고, 고르는 조건(`success()` 를 쓴다)도 달라 이 검사의 목록을 두 배로 만든다 — 요구사항 하지 않을 일 2.
+- 5 는 파서를 들이지 않는 한 YAML 을 다 읽을 길이 없기 때문이다. 정규식으로 몇 줄만 찾으면 그 줄이 어느 스텝 · 어느 칸에 있는지를 모른다(같은 `if` 글이 T8 과
+  T7 에 둘 있다). 지금 쓰는 꼴만 읽으면 그 꼴 안에서는 자리를 알고, 앵커 · 흐름 꼴처럼 뜻이 이 읽기와 갈릴 수 있는 꼴은 읽은 척하지 않고 거절한다.
+- 6 은 수트를 부르는 바꿈을 주석뿐인 C 하나에 가두기 위해서다 — B 의 리뷰가 몇 회차를 돌아도 수트는 돌지 않는다. C 의 주석이 가리키는 검사는 B 로 먼저
+  머지되어 있다. 저자가 `eval.yml` 을 고치기로 했다 — 「열아홉」 두 줄은 조각 35 D 뒤로 틀렸고, `eval.yml` 을 고치는 사람이 그 조건을 무는 검사를 그 파일에서
+  알게 된다.

+  - A1 인자 없이는 저장소 맨 위의 `.github/workflows/eval.yml`, 경로 하나면 그 파일을 읽는다. 그 밖(③ A3)은 사용법을 찍고 종료 2.
+  - A2 맞으면 `PASS verify-eval-gate.py — …` 한 줄과 종료 0. 어긋나면 어긋난 자리마다 `FAIL [<이 절의 번호>] <스텝> · <칸> — <까닭>` 을 다 찍고 종료 1. 파일을
+    읽지 못해도 `FAIL` 과 종료 1.
+- Y **읽는 꼴.** 읽는 자리(워크플로 머리의 키 · gate 잡)는 ③ Y1 ~ Y5 의 꼴만 읽는다. Y6 의 꼴이 오면 그 줄을 찍고 떨어진다 — YAML 의 뜻이 이 읽기와 갈릴 수 있는
+  꼴이라, 읽은 척하지 않는다(ADR 0048 의 5).
+- H **머리.**
+  - H1 워크플로 머리의 키는 ③ H1 의 넷뿐이다 — `defaults` · `env` 가 오면 떨어진다(모든 스텝의 셸 · 환경을 바꾼다).
+  - H2 gate 잡의 키는 ③ H2 의 넷뿐이다 — `defaults` · `env` · `continue-on-error` · `if` · `container` 같은 것이 오면 떨어진다.
+- T **열한 스텝 — 적기와 건너뛰기의 사슬.**
+  - T1 **차례** — gate 잡의 스텝이 ③ T 의 열한으로 시작해 그 차례대로 이어진다. 사이에 다른 스텝이 끼거나 · 빠지거나 · 차례가 바뀌면 떨어진다. 열한 뒤의
+    스텝(수트 쪽)은 보지 않는다 — 변조 시험의 지문은 열한째에서 이미 캐시에 적혔다.
+  - T2 **칸** — 스텝마다 ③ T 의 칸만 갖는다. `continue-on-error` · `shell` · `working-directory` · `timeout-minutes` 같은 다른 칸이 오면 떨어진다. `name` 은 어느
+    스텝이든 있어도 없어도 된다.
+  - T3 **글** — `id` · `if` · `env` · `with` 의 값과 `run` 의 명령 줄이 ③ T 의 글과 글자 그대로 같다. `uses` 는 `@` 앞이 같다. 줄 앞뒤의 공백 · 빈 줄 · 주석 줄은
+    보지 않는다. `run` 의 알림 줄(F2)은 명령 줄에서 빼고 견준다.
+  - T3 이 닫는 것 — **적기**: `full=true` 를 적는 줄은 건너뛰지 않는 갈래에 한 번, 인자 없는 `./scripts/gates.sh` 바로 앞이다 · `./scripts/gates.sh` 의 두 줄은 그
+    줄 전체다(`||` · `|` · `;` · `&` 가 붙지 않는다) · 적는 스텝의 `if` 에 상태 함수가 없어 앞 스텝이 다 성공했을 때만 돈다 · 그 캐시 저장은 그 스텝의 성공에 걸린다 ·
+    `main` 범위에 다시 적는 길은 머지된 PR 판정의 적중에 걸린다. **건너뛰기**: 지문은 `gate-key.py` 가 낸 모양 맞는 것뿐이다 · 찾아보기는 지문이 있고
+    `workflow_dispatch` 가 아닐 때, `restore-keys` 없이 그 지문 하나로 · 건너뛰는 갈래는 두 적중 가운데 하나이고 근거 파일이 비지 않았을 때 · 건너뛸 때 근거를
+    `--skip-bite` 로 넘긴다.
+- F **자유로운 칸.** 다음만 바꾼 `eval.yml` 은 통과한다.
+  - F1 스텝 이름(`name`) · 주석 줄 · 빈 줄.
+  - F2 `run` 의 알림 줄 — 줄 전체가 `echo "<글>"` 이고, 글에 `$(` · 역따옴표 · `\` · 따옴표가 없으며 펼치는 것은 `$이름` · `${이름}` 뿐인 줄. 따옴표 뒤에 아무것도
+    없다 — `>` · `>>` 가 붙은 줄은 알림 줄이 아니라 명령 줄이다.
+  - F3 `uses` 의 판 — `@` 뒤가 `v<숫자>` 인 것.
+- G **갇힘.** 주석 밖에서 `.gate-pass` 나 `gfp` 를 든 줄은 파일 전체에서 열한 스텝 안에만 있다 — 다른 잡이나 열한 뒤의 스텝이 변조 시험의 근거 파일이나 지문을
+  쓰면 떨어진다.
+- V **문다 — `bite-gates.sh` 의 새 절.**
+  - V1 **변조본** — `eval.yml` 사본의 한 자리를 바꿔 `verify-eval-gate.py <사본>` 을 부른다. 종료 1 이고 `FAIL [` 줄을 찍었을 때만 「물었다」로 센다(조각 36 OB-4 —
+    0 이 아닌 종료를 다 세지 않는다). 바꿀 글이 `eval.yml` 에 꼭 한 번이 아니면 변조본을 돌리기 전에 종료 1 — 변조본이 `eval.yml` 을 따라 고쳐지게.
+  - V2 **대조군** — F 의 칸만 바꾼 사본이 `PASS` · 종료 0 이다. 하나라도 떨어지면 검사가 자유로운 칸까지 잡는 것이라 종료 1.
+  - V3 **인자** — ③ A3 의 꼴이 종료 2 이고 아무것도 견주지 않는다.
+
+**보장하지 않는 것(알려진 한계)**
+
+- **gate 스텝의 실패를 삼킨 `eval.yml` 의 그 CI 실행** — 새 검사는 그 실행의 `gates.sh` 안에서 돌므로, `./scripts/gates.sh || true` 인 `eval.yml` 의 CI 는 검사가
+  떨어져도 초록이고 지문을 적는다. 로그에 `FAIL [T3]` 줄은 남는다. 그 꼴은 로컬 `gates.sh` 가 떨어뜨리고(세션은 PR 을 내기 전에 돌린다 — 조각 36 이 15분 안으로
+  줄였다) 리뷰가 본다. `eval.yml` 안에 검사를 따로 두면 같은 PR 이 그 스텝도 함께 지울 수 있다(ADR 0048 의 2).
+- **열한 스텝이 부르는 것의 속** — `gates.sh`(그 자체 시험 `test-gates.py`) · `gate-key.py` · `eval-merged-pass.py`(각자의 변조 시험)가 든다. 액션의 동작(캐시의
+  `cache-hit` 는 키가 꼭 같을 때만 참)과 GitHub 의 기본 셸(`bash -e`)은 사실로 둔다.
+- **일부러 감춘 우회** — 열한 밖의 스텝이 변수로 지은 경로로 캐시를 쓰기, 저장소 변수 · 시크릿으로 셸을 바꾸기 같은 것. 모양 검사다 — 실수로 흔든 글을 문다.
+- **같은 뜻의 다른 글** — 닫힌 목록과 글자가 다르면 뜻이 같아도 떨어진다(예: `if` 의 따옴표를 바꾸기 · 줄을 둘로 나누기). 거짓 빨강 쪽이고, 그 PR 이 검사의 목록을
+  함께 고쳐 리뷰에 내놓는다. 액션의 판을 넘어 `with` 의 값(예: `node-version`)을 바꿀 때도 그렇다.
+- **검사를 지우거나 목록을 함께 고친 PR** — `gates.sh` 의 줄을 지우는 것은 조각 35 설계 끝 그대로(감사 OB-2), 목록과 `eval.yml` 을 함께 고친 PR 은 리뷰가 본다.
+- **수트 지문의 사슬 · verdict · `eval.yml` 이 GitHub 에서 받아들여지는지** — 요구사항 하지 않을 일 2 · 3.

+## ④ 결정

+**정한 것**

+# 조각 37 — `eval.yml` 적기 조건 검사 (2026-10-25 착공)
+
+요구사항이다 — **무엇을 · 왜.** 어떻게 · 경계는 같은 폴더의 `design.md`, 대안이 있던 결정은 ADR 0048.
+
+이 조각을 「다음 조각」으로 적은 닫힌 조각은 없다 — 조각 36 의 `## 닫으며 (2026-10-25)` 가 다음 조각을 정하지 않고 「다음 조각을 꺼내는 세션이 저자에게
+고르게 한다」고 적었다. 이 착공 세션이 그것을 읽고 순서 없는 후보 여섯을 저자에게 물었고, 저자가 이 줄을 골랐다(2026-10-25). 넘긴 것은 조각 36 의 OB-1
+하나 — 이 줄이다. 이 줄은 의존이 없다. 조각 나눔의 줄은 「`eval.yml` 을 고치면 route 수트가 한 번 돈다 — 그 PR 이 「열아홉」 두 줄도 함께 고칠 수 있다」고
+넘겼다 — 저자가 이 착공 세션에서 고치기로 정했다(ADR 0048 의 6). 이 착공 세션의 claude-kit 클론은 얕지 않았다(`git rev-parse --is-shallow-repository` →
+`false`).
+
+## 문제
+
+**변조 시험의 지문을 「물었다」로 적는 조건을 무는 것이 리뷰뿐이다.** `eval.yml` gate 잡은 변조 시험 다섯까지 다 돈 실행만 지문을 캐시에 적고(조각 35 ·
+ADR 0046), 같은 지문의 다음 PR 은 그 근거로 변조 시험을 건너뛴다. 그 조건은 `eval.yml` 의 글 두 자리뿐이다 — 「키 없이 도는 게이트」 스텝이 인자 없는
+갈래에서 `full=true` 를 적었다 · 그 스텝까지 성공했다(「변조 시험까지 통과한 지문을 적는다」 스텝의 `if`).
+
+- **세 번 나왔다** — 조각 35 의 닫기 전 `audit-quality` 두 회차와 조각 36 의 회차 3 이 같은 자리를 관찰 OB-1 로 냈다(셋째 `docs/audit/records/audit-quality-2026-10-25-105619.md`
+  「OB-1」). 셋째 회차는 「요구가 비어 있다는 신호」라며 규칙을 세우거나 두지 않는다는 ADR 을 남기자고 제안했다.
+- **거짓 근거가 적히는 길이 `eval.yml` 의 글로 좁혀졌다** — `gates.sh` 쪽은 조각 36 이 `test-gates.py` 의 T1′ · T5 로 닫았다(NC-2). 남은 길은 예를 들어 gate
+  스텝의 `./scripts/gates.sh` 뒤에 `|| true` 를 붙이기, 건너뛰는 갈래에서도 `full=true` 를 적기다. 그런 `eval.yml` 은 CI 가 초록이고, 그 실행이 적은 지문으로
+  검사를 고친 다음 PR 이 변조 시험 없이 지나간다 — 「물지 않는 검사는 게이트가 아니다」(`CLAUDE.md`)가 조용히 무너진다.
+- **건너뛰는 조건도 같다** — 「같은 지문이 이미 물었는가」의 `if`, 「키 없이 도는 게이트」의 `HIT` 와 근거 파일 조건이 바뀌어 근거 없이 건너뛰어도 아무것도
+  떨어지지 않는다.
+- **낡은 수** — `eval.yml` 주석 두 줄이 늘 도는 검사를 「열아홉」이라 적는다. 조각 35 D 뒤로 스물이고, 이 조각 뒤로 스물하나다. `eval.yml` 을 고치면 route 수트가
+  돌아(수트 지문 `eval-key.py`) 조각 35 · 36 이 고치지 않고 넘겼다.
+
+## 핵심 사용자와 시나리오
+
+- 사용자: 저자 한 명, 그리고 claude-kit 에서 `eval.yml` 을 고치는 세션.
+- 시나리오: 세션이 gate 잡의 스텝을 손본다(예: 캐시 액션의 판을 올리다 적기 스텝의 `if` 를 건드린다) → PR 을 내기 전에 로컬에서 `./scripts/gates.sh` 를 돌린다 →
+  늘 도는 묶음의 새 검사가 「변조 시험까지 통과한 지문을 적는다」의 `if` 가 닫힌 목록과 다르다고 그 스텝과 칸을 찍고 떨어진다 → 세션은 바꾼 것이 적기 조건을
+  흔드는지 보고, 흔들지 않는 바꿈이면 검사의 목록을 함께 고쳐 리뷰에 내놓는다 → 알림 글이나 주석만 고쳤다면 처음부터 떨어지지 않는다.

+## 성공 기준
+
+1. **검사가 선다** — `scripts/verify-eval-gate.py` 가 `gates.sh` 의 `checks` 묶음에 있고, `main` 의 `eval.yml` 에 `PASS` 를 찍는다. 늘 도는 검사는 스물하나,

+## 하지 않을 일
+
+1. **적기 조건을 바꾸지 않는다** — 셋째 회차의 다른 제안(실행이 낸 양성 근거 — 예: `gates.sh` 의 끝 줄 — 를 적기에 요구한다)은 하지 않는다. C 는 `eval.yml` 의
+   주석만 고친다. 검사는 지금의 조건을 그대로 닫힌 목록으로 든다.
+2. **수트 지문의 사슬은 묻지 않는다** — `.eval-pass` 를 적고 읽는 스텝 · eval 잡 · verdict 잡은 새 검사 밖이다. 같은 모양의 관찰이 나오면 그때 조각 나눔에 줄을
+   더한다.
+3. **YAML 을 다 읽지 않는다** — 파서를 들이지 않는다(`CLAUDE.md` 「스택」). 새 검사는 `eval.yml` 이 지금 쓰는 꼴만 읽고, 읽는 자리에 그 밖의 꼴이 오면 거절한다.
+   `eval.yml` 이 GitHub 에서 도는지는 GitHub 이 본다.
+4. **`gates.sh` 의 판정을 바꾸지 않는다** — `checks` 에 한 줄과 수(스물하나 · 스물여섯)만. `bites` · 인자 · `test-gates.py` 는 그대로다.
+5. **플러그인 폴더를 고치지 않는다** — 이 검사는 이 저장소의 CI 를 본다. 다른 레포는 `eval.yml` 이 없어 `vibe-slice` 에 싣지 않는다.

+                '$GITHUB_SERVER_URL/$GITHUB_REPOSITORY/actions/runs/$GITHUB_RUN_ID ($GITHUB_SHA)" > .gate-pass/run.txt',
+            ]}),
+    ("T8", {"uses": "actions/cache/save", "if": "steps.gmerged.outputs.hit == 'true'",
+            "with": {"path": ".gate-pass", "key": "${{ steps.gfp.outputs.key }}"}}),
+    ("T9", {"id": "gates",
+            "env": {"KEY": "${{ steps.gfp.outputs.key }}",
+                    "HIT": "${{ steps.gseen.outputs.cache-hit == 'true' || steps.gmerged.outputs.hit == 'true' }}"},
+            "run": [
+                'if [ "$HIT" = true ] && [ -s .gate-pass/run.txt ]; then',
+                'why="같은 지문($KEY)이 이미 물었다 — $(head -n 1 .gate-pass/run.txt)"',
+                './scripts/gates.sh --skip-bite "$why"',
+                "else",
+                'if [ "$HIT" = true ]; then',
+                "fi",
+                'echo "full=true" >> "$GITHUB_OUTPUT"',
+                "./scripts/gates.sh",
+                "fi",
+            ]}),
+    ("T10", {"id": "gpass", "if": "steps.gates.outputs.full == 'true' && steps.gfp.outputs.key != ''",
+             "run": [
+                 "mkdir -p .gate-pass",
+                 'echo "$GITHUB_SERVER_URL/$GITHUB_REPOSITORY/actions/runs/$GITHUB_RUN_ID ($GITHUB_SHA)" > .gate-pass/run.txt',
+             ]}),
+    ("T11", {"uses": "actions/cache/save", "if": "steps.gpass.outcome == 'success'",
+             "with": {"path": ".gate-pass", "key": "${{ steps.gfp.outputs.key }}"}}),
+]
+
+KEY = re.compile(r"([A-Za-z_][A-Za-z0-9_-]*):(?: (.*))?")
+BAD_HEAD = re.compile(r"[&*!{\[>|%@`]")   # Y6 — 앵커 · 별칭 · 태그 · 흐름 꼴 · 블록 꼴 · 예약 글자로 여는 값
+FREE_ECHO = re.compile(r'echo "(?:[^"`\\$]|\$[A-Za-z_][A-Za-z0-9_]*|\$\{[A-Za-z_][A-Za-z0-9_]*\})*"')  # F2
+VERSION = re.compile(r"v[0-9]+")  # F3
+GUARDED = (".gate-pass", "gfp")   # G
+
+
+class Unread(Exception):
+    """Y — 읽는 꼴 밖의 줄. (줄 번호, 까닭)"""
+
+
+def indent(line):
+    return len(line) - len(line.lstrip(" "))
+
+
+def skip(line):
+    s = line.strip()
+    return not s or s.startswith("#")
+
+
+class Reader:
+    """gate 잡의 줄을 읽는다 — 키 · 값 · 블록 · 스텝 목록만. lines 는 (줄 번호, 글)이고 그 밖의 꼴은 Unread."""
+
+    def __init__(self, lines):
+        self.lines = lines
+        self.i = 0
+
+    def peek(self):
+        while self.i < len(self.lines) and skip(self.lines[self.i][1]):
+            self.i += 1
+        return self.lines[self.i] if self.i < len(self.lines) else None
+
+    def mapping(self, ind):
+        out = {}
+        while (cur := self.peek()) is not None:
+            no, line = cur
+            if indent(line) < ind:
+                break
+            if indent(line) != ind:
+                raise Unread(no, "알 수 없는 들여쓰기")
+            m = KEY.fullmatch(line[ind:].rstrip())
+            if not m:
+                raise Unread(no, "`키: 값` 꼴이 아니다(따옴표 키 · `<<:` · 흐름 꼴 따위)")
+            key, val = m[1], m[2]
+            if key in out:
+                raise Unread(no, f"같은 키 `{key}` 가 둘이다")
+            self.i += 1
+            if val is None or val == "":
+                nxt = self.peek()
+                if nxt is not None and indent(nxt[1]) > ind:
+                    if indent(nxt[1]) != ind + 2:
+                        raise Unread(nxt[0], "알 수 없는 들여쓰기")
+                    out[key] = self.steps(ind + 2) if nxt[1].lstrip().startswith("- ") else self.mapping(ind + 2)
+                else:
+                    out[key] = None
+            elif val == "|":
+                out[key] = self.block(no, ind)
+            elif BAD_HEAD.match(val):
+                raise Unread(no, f"`{key}` 의 값이 읽지 않는 꼴로 연다 — {val[:1]!r}")
+            elif " #" in val:
+                raise Unread(no, f"`{key}` 의 값 뒤에 주석이 있다")
+            else:
+                out[key] = val
+        return out
+
+    def block(self, at, ind):
+        """`run: |` 아래 줄들 — 첫 줄의 들여쓰기보다 얕은 줄이 오면 끝난다(YAML 의 블록 꼴). 빈 줄은 블록에 든다."""
+        body, deep = [], None
+        while self.i < len(self.lines):
+            no, line = self.lines[self.i]
+            if not line.strip():
+                body.append("")
+                self.i += 1
+                continue
+            if deep is None:
+                deep = indent(line)
+                if deep <= ind:
+                    raise Unread(at, "`|` 블록이 비었다")
+            if indent(line) < deep:
+                break
+            body.append(line[deep:])
+            self.i += 1
+        if deep is None:
+            raise Unread(at, "`|` 블록이 비었다")
+        return body
+
+    def steps(self, ind):
+        out = []
+        while (cur := self.peek()) is not None:
+            no, line = cur
+            if indent(line) < ind:
+                break
+            if indent(line) != ind or not line[ind:].startswith("- "):
+                raise Unread(no, "스텝 목록에서 `- ` 로 열지 않는 줄")
+            # 「- 키: 값」 줄을 두 칸 깊은 매핑의 첫 줄로 읽는다
+            self.lines[self.i] = (no, " " * (ind + 2) + line[ind + 2:])
+            start = no
+            step = self.mapping(ind + 2)
+            end = self.lines[self.i - 1][0] if self.i else start
+            step["_lines"] = (start, end)
+            out.append(step)
+        return out
+
+
+def commands(run):
+    """`run` 의 명령 줄 — 알림 줄(F2) · 주석 · 빈 줄을 빼고 줄 앞뒤 공백 없이."""
+    lines = run if isinstance(run, list) else [run]
+    return [s for s in (l.strip() for l in lines) if s and not s.startswith("#") and not FREE_ECHO.fullmatch(s)]
+
+
+def sig(step):
+    """차례(T1)를 가르는 얼굴 — id, 없으면 액션 이름, 그도 없으면 run 스텝."""
+    if step.get("id"):
+        return ("id", step["id"])
+    if step.get("uses"):
+        return ("uses", str(step["uses"]).split("@")[0])
+    return ("run",)
+
+
+def check_steps(steps, fail):
+    for n, (tag, spec) in enumerate(SPEC):
+        if n >= len(steps):
+            fail("T1", f"{tag}", f"gate 잡의 스텝이 {len(steps)} 개뿐이다 — 열한으로 시작해야 한다")
+            return
+        step = steps[n]
+        where = f"{tag}({step.get('name') or step.get('id') or step.get('uses') or 'run'} · {step['_lines'][0]}행)"
+        if sig(step) != sig(spec):
+            fail("T1", where, f"{n + 1} 째 스텝이 {sig(spec)} 여야 하는데 {sig(step)} 다 — 스텝이 끼었거나 빠졌거나 차례가 바뀌었다")
+            return
+        have = set(step) - {"name", "_lines"}
+        if have != set(spec):
+            extra, miss = sorted(have - set(spec)), sorted(set(spec) - have)
+            fail("T2", where, f"칸이 다르다 — 더한 칸 {extra} · 없는 칸 {miss}")
+        for k in sorted(set(spec) & have):
+            got, want = step[k], spec[k]
+            if k == "uses":
+                name, _, ver = str(got).partition("@")
+                if name != want:
+                    fail("T3", f"{where} · uses", f"`{want}` 여야 하는데 `{name}` 다")
+                elif not VERSION.fullmatch(ver):
+                    fail("T3", f"{where} · uses", f"판이 `v<숫자>` 가 아니다 — `{ver}`")
+            elif k == "run":
+                g = commands(got)
+                if g != want:
+                    at = next((i for i, (a, b) in enumerate(zip(g, want)) if a != b), min(len(g), len(want)))
+                    a = g[at] if at < len(g) else "(없음)"
+                    b = want[at] if at < len(want) else "(없음)"
+                    fail("T3", f"{where} · run", f"명령 줄 {at + 1} 이 다르다 — 지금 `{a}` · 목록 `{b}`")
+            elif isinstance(want, dict):
+                if not isinstance(got, dict) or got != want:
+                    fail("T3", f"{where} · {k}", f"값이 다르다 — 지금 {got!r} · 목록 {want!r}")
+            elif got != want:
+                fail("T3", f"{where} · {k}", f"값이 다르다 — 지금 `{got}` · 목록 `{want}`")
+
+
+def judge(text):
+    """실패 (번호, 자리, 까닭) 의 목록과 알림 줄의 수. 목록이 비었으면 통과."""
+    bad = []
+    fail = lambda code, where, why: bad.append((code, where, why))
+    lines = text.split("\n")
+
+    # H1 · Y — 워크플로 머리의 키
+    head = []
+    for no, line in enumerate(lines, 1):
+        if skip(line) or indent(line):
+            continue
+        m = KEY.fullmatch(line.rstrip())
+        if not m:
+            return [("Y", f"{no}행", "워크플로 머리의 줄이 `키:` 꼴이 아니다")], 0
+        if "\t" in line:
+            return [("Y", f"{no}행", "탭이 있다")], 0
+        if m[1] in head:
+            return [("Y", f"{no}행", f"머리의 키 `{m[1]}` 가 둘이다")], 0
+        head.append(m[1])
+    if sorted(head) != sorted(HEAD_KEYS):
+        fail("H1", "워크플로 머리", f"키가 {HEAD_KEYS} 여야 하는데 {head} 다")
+
+    # gate 잡의 자리 — jobs: 아래 「  gate:」 한 줄부터 다음 잡이나 머리의 키까지
+    starts = [no for no, line in enumerate(lines, 1) if line.rstrip() == "  gate:"]
+    jobs = [no for no, line in enumerate(lines, 1) if line.rstrip() == "jobs:"]
+    if len(starts) != 1 or len(jobs) != 1 or starts[0] < jobs[0]:
+        return bad + [("Y", "jobs", "jobs: 아래 「  gate:」 한 줄을 찾지 못했다")], 0
+    a = starts[0]
+    b = next((no for no in range(a + 1, len(lines) + 1)
+              if not skip(lines[no - 1]) and indent(lines[no - 1]) <= 2), len(lines) + 1)
+    body = [(no, lines[no - 1]) for no in range(a + 1, b)]
+    for no, line in body:
+        if "\t" in line:
+            return bad + [("Y", f"{no}행", "gate 잡에 탭이 있다")], 0
+    try:
+        job = Reader(body).mapping(4)
+    except Unread as e:
+        no, why = e.args
+        return bad + [("Y", f"{no}행", why)], 0
+
+    # H2
+    if sorted(job) != sorted(GATE_KEYS):
+        fail("H2", "gate 잡", f"키가 {GATE_KEYS} 여야 하는데 {list(job)} 다")
+    steps = job.get("steps")
+    if not isinstance(steps, list):
+        fail("T1", "gate 잡", "steps 가 스텝 목록이 아니다")
+        return bad, 0
+
+    check_steps(steps, fail)
+
+    # G — 열한 스텝 밖에서 근거 파일이나 지문을 쓰는 줄
+    lo = steps[0]["_lines"][0]
+    hi = steps[min(len(steps), len(SPEC)) - 1]["_lines"][1]
+    for no, line in enumerate(lines, 1):
+        if lo <= no <= hi or skip(line):
+            continue
+        for g in GUARDED:
+            if g in line:
+                fail("G", f"{no}행", f"열한 스텝 밖에서 `{g}` 를 쓴다 — {line.strip()[:80]}")
+
+    free = sum(1 for s in steps[:len(SPEC)] if "run" in s
+               for l in (s["run"] if isinstance(s["run"], list) else [s["run"]]) if FREE_ECHO.fullmatch(l.strip()))
+    return bad, free
+
+
+def main(argv):
+    if len(argv) > 1 or (argv and argv[0].startswith("-")):
+        print(USAGE, file=sys.stderr)
+        return 2
+    path = pathlib.Path(argv[0]) if argv else WORKFLOW
+    try:
+        text = path.read_text(encoding="utf-8")
+    except (OSError, UnicodeDecodeError) as e:
+        print(f"FAIL [A2] {path} — 읽지 못했다: {e}")
+        return 1
+    bad, free = judge(text)
+    if bad:
+        for code, where, why in bad:
+            print(f"FAIL [{code}] {where} — {why}")
+        return 1
+    print(f"PASS verify-eval-gate.py — 머리의 키 넷 · gate 잡의 키 넷 · 첫 열한 스텝의 차례 · 칸 · 글이 닫힌 목록과 같고, "
+          f"`.gate-pass` · `gfp` 는 그 안에만 있다(알림 줄 {free} 은 자유)")
+    return 0
+
+
+if __name__ == "__main__":
+    for stream in (sys.stdout, sys.stderr):
+        stream.reconfigure(encoding="utf-8")
+    sys.exit(main(sys.argv[1:]))
