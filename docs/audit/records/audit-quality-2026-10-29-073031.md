  - `:258-259` 를 지운 검사를 생각해 봅니다. 대장에서 다음 번호 줄을 통째로 지우면 `nexts` 가 비고, K3 블록 둘이 다 건너뛰어 PASS 입니다. 그래도 R 의 다른 변조본이 ID 를 채우므로 절도 `rgap` 도 초록입니다. 설계 ② R 「빈 것끼리 견주어 지나가지 않는다」가 바로 이 갈래인데, 어긋내 본 근거가 없습니다.
  - 상태 낱말 문장의 줄 넘기기는 「PR B 에서 정한 것」이 정했습니다. 그러나 틀(`templates/nc-ledger.md:40`)과 이 저장소 대장(`nc-ledger.md:31`)의 문장이 다 한 줄이라, 이 고리를 지워도 아무것도 바뀌지 않습니다.

  - **규칙을 문서에 세우자고 제안합니다.** 길은 둘입니다.
    - 설계 ② 「보장하는 것」의 실패 갈래마다(ID 가 아니라 문장마다) 변조본 하나를 요구하는 줄을 ADR 0054 를 대체하는 ADR 이나 `docs/procedure.md` 의 설계 칸에 두는 것
    - 「ID 단위로 충분하다」를 ADR 로 결정해 이 관찰을 닫는 것
  - 이 검사에서 가장 싼 고침은 `:1894` 옆에 다음 번호 줄을 지우는 변조본 하나(`lbite R`)입니다. 줄 넘기기는 고정 대장의 문장을 두 줄로 나눈 대조군 하나입니다.
