- 규칙:

  - `CHECKLIST.md:9` — 「(가) 절 끝에서 돈 변조본 · 대조군의 수를 기대한 수와 견준다(끝 줄에 글자로 박은 수가 없다)」
- 실제:
  - `scripts/bite-gates.sh:1487` 은 「bites 묶음은 변조 시험 다섯뿐(**변조본 둘**이 떨어짐)」이라 찍는다.
    - 이 「둘」은 「gates.sh 의 bites 묶음」 절(`:1414-1453`, `sclose 2 1`)의 변조본 수다.
    - 그 절에는 끝 줄이 따로 없다. 이 줄은 다음 절(「gates.sh 의 인자」, `:1458`)을 닫은 뒤에 찍힌다. 그래서 그때의 `$SB` 는 이미 다음 절의 수(7)다.
  - `:1583` 은 「**대조군 둘**(차례 · 주석)과 진짜 gates.sh 가 PASS 줄로 지나감」이라 찍는다.
    - 이 「둘」은 「test-gates.py(자유로운 것)」 절(`:1569-1577`, `sclose 0 2`)의 대조군 수다.
  - 두 글자 수는 기준에도 있었다 — 「변조본 둘이 떨어짐」(브리핑 `:1694`) · 「대조군 둘(차례 · 주석)이 지나가고」(`:1846`).
    - PR B 는 같은 줄의 「일곱」을 `$SB` 로 바꿨다(`:1694` → `:1696`). 이 둘은 남겼다.
  - 성공 기준 2 가 이름으로 든 넷은 다 견준 수로 바뀌었다(`requirements.md:36-37`).
    - 「여덟」 → `:1248` 의 `$NSEC`
    - 「아홉」 → `:1530` 의 `$SB`
    - 「일곱」 → `:1487` 의 `$SB`
    - 「열둘」 → `:1410` 의 `$SK`

- 어느 쪽을 고칠 문제인가: 사람이 결정 — 둘 중 하나다.
  - 코드 — 두 절의 수를 다음 `sopen` 전에 받아 두고 끝 줄에서 찍는다.
