## ② 보장하는 것 / 보장하지 않는 것

**보장하는 것**

- **A 걷기 줄과 원천이 같은 말을 한다** — `CLAUDE.md` 의 줄이 ADR 0076 의 7(소급 금지)을 그대로 들고, 그 ADR 이 따로 고르라고 남긴 걷는 법을 ADR 0092 의 1 로 메운다. 대체가 아니다.
- **B 기록이 지금과 맞는다** — ADR 0091 의 3 을 지금 결정으로 읽는 사람이 대체 절에서 ADR 0092 로 간다.
- **C 은퇴한 감사자의 열린 줄이 고아가 되지 않는다** — 은퇴를 정한 조각이 담당을 옮기는 자리가 대장 틀에 있다. 틀을 베낀 다른 레포도 다음에 베낄 때 같은 글을 받는다.
- **D 새 실패 조건이 없다** — 스크립트 · 케이스 · 게이트 줄이 그대로다.

**보장하지 않는 것(알려진 한계)**

- **걷기 줄을 무는 검사는 없다** — 걷는 PR 이 ADR 에 이름을 들었는지는 사람과 닫기 전 `audit-internal` 회차가 본다.
- **이미 틀을 베낀 레포의 대장은 바뀌지 않는다** — 틀의 「닫는 규칙」은 베낄 때 따라간다. 사본 레포는 하지 않을 일 5.
- **「앵커볼트 결정으로 잴 대상이 사라진」의 경계는 판단이다** — 조각 72 의 `gap-unowned` 처럼 잴 대상이 남았는데 걷는 경우는 이 줄이 아니라 ADR 이 그 까닭을 따로 적는다(ADR 0092 의 2).
- **리뷰가 이 밖을 짚으면 범위 밖이다** — 요구사항 하지 않을 일.
