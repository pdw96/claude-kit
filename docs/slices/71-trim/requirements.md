# 조각 71 — 덜어내기 (2026-11-15 착공)

요구사항이다 — **무엇을 · 왜.** 어떻게 · 경계는 같은 폴더의 `design.md`, 대안이 있던 결정은 ADR 0090.

이 조각을 「다음 조각」으로 적은 닫힌 조각은 없다 — 조각 70 의 다음 조각은 「닫는 PR 의 회차와 git 근거」다. 그래서 들어가는 조건의 「`## 닫으며` 를 읽었다」는 `없음`(ADR 0012). 의존은 `—` 다.
이 줄은 저자가 이 착공 세션에서 외부 검토의 결론을 들고 더했다(2026-11-15). 저자가 「은퇴 후보를 측정으로 가른다」는 방향을 승인했다 — 실제로 이름을 빼는 일은 측정 결과를 본 뒤 다시 묻는다
(ADR 0090 의 1). 착공은 `main`(`8b6c81e`) 위에서 연다. 이 세션의 클론은 얕지 않았다.

이 조각의 범위는 세 단계다 — (1) 되돌릴 자리(태그) · (2) 결정 기록 · (3) 측정. 감사자 은퇴 · 파일 삭제는 이 조각의 일이 아니다.

## 문제

**지키는 장치와 기록이 지키는 대상보다 훨씬 크고, 그 대상의 앞섬은 좁다.**

- **찾는 능력에서 앞섬이 없다** — 담당 감사자가 예전에 놓친 결함으로 만든 여섯 케이스(데이터 · 계약)에서 `vibe-audit` 17/18, 플러그인 없음 18/18, `pr-review-toolkit` 18/18 이다
  (`README.md` 「무엇이 다른가」 · `docs/eval-log/2026-11.md` 「다른 플러그인과 맞대기 — 조각 51 PR C」).
- **앞섬은 함정 두 케이스뿐이다** — 저장소가 스스로 정한 범위를 존중하는가(`trap-slice-scope` · `trap-local-dev-password`). 회차당 원값은 `vibe-audit` $0.21 · 플러그인 없음 $0.13.
- **쌓인 것** — `git log` 첫 커밋 2026-09-16 부터 두 달에 조각 70 · ADR 89. `docs/` 는 9,825,219 바이트(`du -sb docs`, `8b6c81e`) — `docs/audit/` 5.3MB · `docs/slices/` 2.3MB ·
  `docs/eval-log/` 1.5MB · `docs/adr/` 0.56MB. 지키는 본체(감사자 여섯 · 커맨드 · 두 스킬 · 틀)는 181,987 바이트다(`cat vibe-audit/agents/*.md vibe-audit/commands/*.md
  vibe-slice/skills/*/SKILL.md vibe-slice/skills/*/templates/* | wc -c`).
- **가설** — 앞섬의 까닭은 감사자 여섯이라는 구조가 아니라 「레포 맥락을 아느냐」다. 그렇다면 맥락 한 줄을 레포에 둔 다른 도구가 같은 몫을 낸다. 이 가설을 잰 적이 없다 — 지금까지의 팔은
  `vibe-audit` · 플러그인 없음 · 경쟁 플러그인이고, 맥락을 레포에 둔 팔은 없다.

## 핵심 사용자와 시나리오

- 사용자: 이 저장소의 저자 — 무엇을 남기고 무엇을 은퇴시킬지 정하는 사람.
- 시나리오: 저자가 은퇴 후보를 고르려 한다 → 이 조각이 되돌릴 자리(태그 명령)를 준비하고, 미리 박은 판정 기준을 ADR 에 적고, 맥락 한 줄 팔을 같은 재료 · 같은 요청 · 같은 심판으로 잰다 →
  저자가 PR 본문 맨 위의 판정표를 보고 「무엇을 은퇴시킬지」에 답한다 → 그 답이 다음 조각(은퇴)을 연다.

## 성공 기준

1. **결정이 기록된다** — 착공 PR 이 ADR 0090 을 더하고, 그 ADR 이 (가) 은퇴 후보를 측정으로 가른다는 방향을 저자가 승인했음 · (나) 판정 기준 셋 · (다) 이 측정이 「새 장치는 새어 나간
   결함에만」 규칙 밖이라는 것(ADR 0076 의 5)을 든다.
2. **팔이 선다** — `./scripts/run-compare.sh none-ctx` · `./scripts/run-compare.sh pr-review-toolkit-ctx --from <클론>` 이 돈다. 두 팔의 플러그인 · 요청 본문 · 수트 모델 · 심판 · 도구
   허용 · 비용 천장은 바탕 팔(`none` · `pr-review-toolkit`)과 같고, 다른 것은 픽스처 끝에서 `CLAUDE.md` 에 `compare/context.md` 를 더하는 것 하나다.
3. **측정한다** — 함정 둘(`trap-slice-scope` · `trap-local-dev-password`)과 결함 찾기 여섯(`recall-*`)을 두 새 팔로 케이스마다 3 회 돌린다. 모자란 회차 · 채점 못 한 회차가 있으면 그 수를 적는다.
4. **기록한다** — `docs/eval-log/2026-11.md` 끝에 날짜를 박은 항목이 팔 × 케이스 표 · 회차당 원값 · 손 대조 · 한계를 든다. 결과 폴더는 자격 훑기가 0 건이면 압축본으로 싣는다.
5. **판정표가 나온다** — PR 본문 맨 위에 판정 기준 셋마다 측정값 · 판정이 있고, 다음 결정으로 「무엇을 은퇴시킬지」를 묻는 질문 하나가 있다.
6. **되돌릴 자리** — 태그 `v-archive-2026-11` 를 `main`(`8b6c81e`)에 찍는 명령이 PR 본문에 있고, 찍거나 푸시하지 않았다(`git ls-remote --tags origin v-archive-2026-11` 가 빈 출력).
7. **본체가 그대로다** — `git diff --stat 8b6c81e <머리> -- vibe-audit vibe-slice .claude-plugin` 이 빈 출력이다.

## 하지 않을 일

1. **감사자 · 스킬 · docs 파일을 지우거나 옮기지 않는다** — 은퇴는 판정표를 본 저자의 답 뒤에 다른 조각이 한다.
2. **사본 레포(ERP · 강호쟁패)를 고치지 않는다**(`INTENT.md` Not 4).
3. **글자 예산 천장을 바꾸지 않는다**(ADR 0004).
4. **측정 장치를 새로 세우지 않는다** — `gates.sh` 의 줄 · 변조본 · 검사 · eval 케이스를 더하지 않는다. 러너의 새 팔은 PR 을 떨어뜨리지 않는 측정이다(ADR 0076 의 5).
5. **README 「무엇이 다른가」를 고치지 않는다** — 주장을 어떻게 둘지는 은퇴 결정과 함께 저자가 정한다.
6. **태그를 푸시하지 않는다** — 명령만 준비한다. 푸시는 저자 확인 뒤다.
7. **의도(`INTENT.md`)를 고치지 않는다** — 감사자 수가 바뀌는 것은 은퇴 조각의 「범위 변경」이다.

## 제약

- 스택: bash · python3 표준 라이브러리. 러너는 `scripts/run-compare.sh` 하나를 고친다.
- 원본: `main` `8b6c81e`. 경쟁 커밋 `anthropics/claude-plugins-official` `a7ba5b9`(러너가 박는다).
- 비용: 저자 승인 약 **$15**(새 팔 둘 × 여덟 케이스 × 3 회). CLI 판이 지난 측정(2.1.316 · 2.1.317)과 달라, 함정 둘에 한해 `vibe-audit` · `pr-review-toolkit` 의 같은 날 기준선을 더 잰다(약 $4).
  러너 천장($12 · $5)에 닿지 않게 함정과 결함 찾기를 따로 부른다.
- 자격: 측정 전용 자격(`EVAL_OAUTH_TOKEN`)이 환경에 없다(ADR 0071). 하네스 팔은 이 클라우드 세션의 자격으로 돈다 — 저자가 이 세션에서 승인했다(2026-11-15). 잠긴 하네스 밖 팔은 부르지 않는다.
- 기간: 측정과 착공 PR 은 이 세션. 닫기는 저자의 은퇴 결정 뒤.
- PR: 착공 PR(결정 문서)을 머지한 뒤 측정 PR(러너 · 측정 기록)을 머지한다(ADR 0090 의 5). 측정은 착공 PR 보다 먼저 돌았다.
- 리뷰 한도: 3 회차. 넘기면 소유자가 판정한다.
- 감사 회차: 닫기 전 — `audit-quality`(바뀌는 것 — 측정 러너 `scripts/run-compare.sh` 의 새 팔 둘과 `compare/context.md`: 바탕 팔과 같은 깃발을 쓰는가, 측정값이 판정에 쓰일 만한가. 담당 — 평가셋)
