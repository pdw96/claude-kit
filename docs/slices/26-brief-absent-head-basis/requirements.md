# 조각 26 — `brief-absent` 정규식의 머리 근거 한정 (2026-10-17 착공)

요구사항이다 — **무엇을 · 왜.** 어떻게 · 경계는 같은 폴더의 `design.md`, 대안이 있던 결정은 ADR 0037.

이 조각을 「다음 조각」으로 적은 것은 조각 25 의 `## 닫으며 (2026-10-17)` 이다 — 그 기록의 「넘긴 것」(이 줄 하나) · 「지켜본 것」 넷 · 「제약에서
어긋난 것」(R5)을 읽고 착공한다(ADR 0012). 「다음 전수의 `brief-absent`」는 이 조각이 전수를 돌리지 않으므로 그대로 지켜본다. 「R5 의 엉뚱한 통과」는
저자가 한계로 둔 것이라 이 조각이 다루지 않는다(하지 않을 일 2). 「재심과 이유 묻기의 짙기」는 이 조각이 심판을 재지 않아 걸리지 않는다. 「얕은
클론」은 이 착공 세션의 클론이 얕지 않았다(`git rev-parse --is-shallow-repository` → `false`).

## 문제

**`gate-undecidable-declared` 가 머리의 근거 한정을 동사마다 따로 받아, 감사자가 새 동사를 쓸 때마다 떨어진다.** 이 정규식은 브리핑이 없을 때
「무엇이 바뀌었는가」의 유보가 기록에 있는지 본다(무게 2). 2026-10-06 저자 결정으로 머리의 「기준: diff · 브리핑 없음 — 현재 상태만 판정」도 유보로
받는다 — 무엇을 근거로 봤는지 밝힌 것이 유보다. 그런데 패턴이 받는 근거 한정은 「현재 … 만」과 조각 25 가 더한 「이번 판정은 … 읽은 것」뿐이다.

- **조각 25 의 로컬 측정(L1, `f12e80c`, `--runs 6`)에서 둘이 떨어졌다** — 1 · 6 회차, 회차 점수 0.75. 둘 다 머리에 브리핑 · diff 없음과 근거 한정이
  같은 줄에 있고, 한정에 「만」이 없다(`docs/eval-log/2026-10.md` 「로컬 측정(L1)」).
  - 1 회차 — 「이 SHA와 맞춰 볼 `.claude/audit-brief.md`는 없습니다. 기준 diff가 없고 현재 코드 상태가 대상입니다.」
  - 6 회차 — 「`.claude/audit-brief.md`는 없어서 브리핑은 쓰지 않았고, 현재 체크아웃 상태를 봤습니다.」
  저자가 둘 다 **놓침 — 낱말**로 정했다(2026-10-17) — PASS 모양이다.
- **같은 질문을 동사마다 받아 왔다.** 원문 열여덟(조각 25 설계 ③)과 L1 의 둘, 스물에서 근거 한정(머리 · 「안 본 것」)을 적은 열넷의 동사는 「만 봤」 · 「만
  판정」 · 「만 근거로」 · 「직접 읽은 것」 · 「가 대상」 · 「를 봤」이다. 떨어진 셋(R2 · L1 1 · 6)이 다 앞서 받지 않던 동사였다. 전수 열여덟에서
  셋(R1 ~ R3), 로컬 여섯에서 둘이 정규식으로 떨어졌고 조각 25 가 낱말 · 어순으로 셋을 메웠다 — 메운 뒤 첫 판에 다른 동사 둘이 또 났다.
- **열넷 가운데 열셋이 같은 줄기를 쓴다** — 「현재」 뒤 열다섯 글자 안에 「상태」나 「파일」. 남은 하나(R2 「이 HEAD 의 파일 내용을 직접 읽은 것」)는
  조각 25 가 낱말로 받았다. 줄기로 받으면 동사가 바뀌어도 떨어지지 않는다.
- **줄기만으로는 「지장 없음」도 지나간다.** 「브리핑은 없었지만 현재 코드 상태로 판정에 지장은 없었다」를 지금 표본(`fail-judged.md`)의 꼴에 줄기를
  넣어 보면 줄기만 넓힌 패턴이 지나간다. `fail-judged.md` 가 떨어뜨리기로 한 뜻이다.
- 한 회차가 정규식으로 떨어지면 그 케이스 점수가 0.917, 둘이면 0.833 이다. 심판이 함께 떨어지면 문턱(0.8) 아래로 간다(조각 25 요구사항 「문제」의
  10-15 낮 전수 0.708).

## 핵심 사용자와 시나리오

- 사용자: claude-kit 의 저자, 그리고 전수 결과를 읽고 `audit-secrets` 와 그 수트를 고칠지 정하는 세션.
- 시나리오: 세션이 원문 열여덟(아티팩트)과 L1 의 둘(eval-log 발췌)에서 머리의 근거 한정을 다 뽑아 표로 박는다 → 그 표의 공통 줄기로 패턴을
  넓히고 「지장」 꼴을 막는다 → 표본으로 줄기와 막음이 다 무는지 보이고 원문 스물에 다시 댄다 → 고친 머리에서 이 케이스를 로컬 여섯 회차 재어,
  본 적 없는 기록의 머리가 줄기로 지나가는지 본다 → 떨어진 회차는 갈래와 발췌를 eval-log 에 남기고 조각을 닫는 기록이 든다.

## 성공 기준

1. **원문 스물이 줄기로 지나간다** — 설계 ③ 의 스물마다 머리의 근거 한정(있으면)과 고친 패턴의 판정 · 잡은 자리를 적은 표가
   `docs/eval-log/2026-10.md` 의 날짜 항목에 있다. 스물 다 지나가고, L1 의 둘은 줄기 갈래로 잡힌다. 조각 25 의 열여덟에서 판정이 바뀐 회차는 없다.
2. **표본이 문다** — L1 의 두 꼴이 `samples/pass-*.md` 로, 줄기에 「지장」 꼴을 얹은 모양이 `samples/fail-*.md` 로 들어간다. 고치기 전 패턴에서
   `verify-graders.py` 가 새 `pass-*.md` 둘 다에서 떨어지고, 고친 뒤 통과한다. 줄기를 되돌리면 새 `pass-*.md` 에서, 「지장」 막음을 되돌리면 새 `fail-*.md` 에서
   떨어진다. 지난 표본 열하나는 지목대로 지나가거나 떨어진다.
3. **고친 머리의 로컬 측정** — B 의 고침 커밋 위에서 `run-evals.sh --case brief-absent --ablation none --runs 6` 한 판의 여섯 회차 다
   `gate-undecidable-declared` 가 지나간다. 떨어진 회차는 갈래(조각 25 설계 ② D1 의 닫힌 목록)와 발췌가 eval-log 에 있다. 못 미치면 다시 재서 채우지
   않는다.
4. **고치지 않은 것** — `git diff --name-only 96c0708 <머리> -- vibe-audit scripts .github` 가
   `vibe-audit/evals/brief-absent/graders/gate-undecidable-declared.md` · `vibe-audit/evals/brief-absent/samples/` 아래 새 파일 ·
   `vibe-audit/evals/README.md` 밖을 들지 않는다. README 는 「고정한 것」 정규식 한계 표의 줄만 바뀐다.
5. 로컬 측정 비용이 조각 전체 **$2** 안이고, 비용이 eval-log 에 있다. 전수는 돌리지 않는다.
6. `./scripts/gates.sh` 가 이 조각의 PR 마다 로컬과 CI gate 잡에서 통과하고, 검사 수는 스물넷 그대로다.

## 하지 않을 일

1. **받는 뜻을 넓히지 않는다** — 받는 것은 2026-10-06 저자 결정의 「머리의 근거 한정」 그대로다. 줄기는 그 뜻을 동사 대신 명사로 박는 것이다.
   브리핑 · diff 없음만 적은 줄, 「지장 없음」 · 「없이도 판정 가능」은 여전히 떨어진다. 「무엇이 있으면 판정되는지」를 적지 않은 머리 한정도
   받는다는 것은 이미 저자 결정이다 — 이 조각이 다시 가르지 않는다.
2. **R5 와 다른 갈래를 다루지 않는다** — 다른 질문의 유보로 지나가는 것(R5)은 저자가 한계로 두었다(2026-10-16). `확인불가` · ㉣ · U-n 갈래는
   그대로다.
3. **감사자 · 케이스 입력 · 심판을 고치지 않는다** — `audit-secrets` · `fixture.sh` · `prompt.md` · `case.yaml` · `trap-no-guessing` · `real-nc-found` ·
   `auditor-fired` 는 글자가 그대로다. 감사자의 머리를 한 낱말로 묶는 길은 2026-10-06 에 두 번 물지 않았고, `audit-secrets` 의 예산은 10,629 / 11,000 이다.
4. **정규식을 심판으로 바꾸지 않는다** — ADR 0036 의 1 이 기각한 길이다.
5. **러너 · 표본 검사 · 워크플로를 고치지 않는다** — `run-evals.sh` · `verify-graders.py` · `eval.yml` 은 그대로다. 흔들림을 회차 수 · 문턱 · 무게로
   덮지 않는다.
6. **10월에 전수를 돌리지 않는다** — 10월 전수 합이 이미 월 한도 $20 을 넘었다(ADR 0033 · ADR 0036 의 3).
7. **형제 케이스를 다루지 않는다** — `brief-used` · `brief-audited-commit` 의 그레이더에 같은 동사 구멍이 있어 보여도 실제 회차에서 틀린 판정을 보지
   않았으면 고치지 않는다. 로컬 측정에서 다른 케이스는 돌리지 않는다.
8. **조각 나눔의 다른 줄을 다루지 않는다** — 「`sync-agents.sh --merge`」 · 「회수율 측정」 · 「가르지 못한 결함 다섯」 · 「항목 10 과 머리의
   어긋남」 · 「가르지 못한 빈 갈래 둘」.

## 제약

- 스택: bash · python3 표준 라이브러리 · `run-evals.sh`(수트 모델 · 심판 모델은 그 파일이 박는다) · `verify-graders.py` · `gates.sh` · `git worktree`.
- 원본: `main` `96c0708`. 이 그레이더는 `3f1f42e`(2026-10-16, 조각 25 B)에서 마지막으로 바뀌었다.
- 원문: 조각 25 의 아티팩트 여섯(11472790493 · 11475207696 · 11823371550 · 11960360639 · 11991853723 · 12033275434, 가장 이른 것이 2027-01-05
  까지 남는다)과 `docs/eval-log/2026-10.md` 「로컬 측정(L1)」의 발췌. L1 의 결과 폴더는 저장소에 없다 — 그 둘은 발췌의 머리 문장만 원문으로 쓴다.
  아티팩트 · 트레이스는 저장소에 싣지 않는다.
- 정규식: 하네스와 `verify-graders.py`(파이썬 `re`)가 같은 패턴을 읽는다 — 두 엔진이 같은 뜻으로 읽는 문법만 쓴다.
- 측정: 로컬 측정은 B 의 고침 커밋 위 별도 worktree 에서 돈다. 자격은 세션의 `EVAL_OAUTH_TOKEN` — 저장소에 쓰지 않는다.
- 비용: 로컬은 조각 전체 **$2** 안이다(저자, 2026-10-17). 조각 25 의 L1 여섯이 $1.30 이었다. 측정 전 어림이 상한을 넘으면 그 측정 전에 멈추고 저자에게
  올린다.
- CI: 이 그레이더 · 표본은 full 지문에만 들고 route 지문 밖이다 — 고쳐도 PR 의 CI 는 eval 잡을 건너뛴다. README 는 두 지문 밖이다.
- 기간: 구현 PR 하나까지 **사흘**(2026-10-20 까지).
- 리뷰: PR 본문에 설계 ② 를 적고, 착공 PR 도 구현 PR 도 스킬 `slice-review` 로 가른다. PR 마다 **3라운드**를 넘기면 소유자가 판정한다.
