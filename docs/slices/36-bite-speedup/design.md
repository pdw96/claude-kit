## ② 보장하는 것 / 보장하지 않는 것

**보장하는 것** — I · F · P 는 B 가, N 은 C 가 싣는다.

- I **`.gitignore`.**
  - I1 `.gate-pass/` 한 줄. 작업트리에 `.gate-pass/run.txt` 를 둔 채 `verify-slice-gate.py`(작업트리 모드)가 그 파일을 바꾼 파일로 세지 않는다 — B 의 PR
    본문에서 `진행` 조각이 없는 임시 사본으로 보인다.
- F **`scripts/test-verify-docs.py` 의 두 인자.**
  - F1 **인자** — `[--first] [--repo-only] [<검사 경로>]`, 앞의 둘은 어느 순서든 한 번씩. 그 밖(모르는 `-` 인자 · 같은 깃발 둘 · 경로 둘)은 사용법을 찍고
    종료 2. 인자 없이는 지금과 같다.
  - F2 **`--first`** — 꼴을 지금의 차례대로 돌다가 처음 어긋난 꼴에서 멈추고, 그 한 줄을 지금과 같은 모양(`  - <줄>`)으로 찍고 `FAIL` 줄과 함께 종료 1.
    어긋난 꼴이 없으면 끝까지 돌아 지금과 같은 `PASS` 줄(같은 수)과 종료 0 — 바른 검사에는 깃발이 없을 때와 출력이 같다.
  - F3 **`--repo-only`** — 다른 레포 모드의 꼴(`repo_mode`)만 돈다. 이 저장소 모드의 바탕을 베끼지 않는다. `PASS` 줄은 다른 레포 모드의 수만 든다.
  - F4 **판정은 그대로** — 꼴 · 차례 · 꼴마다의 판정 · 「준비 실패」 줄은 두 깃발에 상관없이 같다. 깃발은 어느 꼴을 돌지와 언제 멈출지만 바꾼다.
- P **함께 돌리기 — 두 변조 시험의 문서 대조 변조본.**
  - P1 **`bite-verify-docs.py`** — 변조본을 다 만든 뒤 `test-verify-docs.py --repo-only --first <사본>` 을 CPU 수(`os.cpu_count()`)만큼 함께 돌린다. 「물었다」의
    판정(종료 1 · 「준비 실패」 없음 · 다른 레포 모드의 판정 줄 하나 이상)은 그대로다. 결과는 변조본의 차례대로 찍는다.
  - P2 **`bite-gates.sh` 의 문서 대조 절** — 변조본 마흔다섯을 먼저 다 만들고(자리가 꼭 한 번이 아니면 그 자리에서 종료 1 — 지금과 같다), `test-verify-docs.py
    --first <사본>` 을 CPU 수(`nproc`)만큼 함께 돌린다. 판정(자체 시험이 지나가면 물지 않았다)은 그대로다.
  - P3 **다 모아 떨어진다** — 물지 않은 변조본이 하나라도 있으면 그 이름을 다 `::error::` 로 찍고 종료 1. 지금처럼 첫 것에서 멈추지 않는다 — 함께 돌아 한
    번에 다 보인다.
  - P4 **대조군** — 두 변조 시험이 변조본 앞에 (가) 바른 검사에 깃발을 단 자체 시험을 불러 종료 0 · `PASS` 를 보고 (나) 바꾸지 않은 검사를 변조본 하나로 함께
    돌리는 길에 넣어 「물지 않았다」로 세는지 본다. (가) 는 늘 1 로 끝나는 `--first` · `--repo-only` 가 모든 변조본을 「물었다」로 만드는 것을, (나) 는 함께
    돌리는 길이 결과를 잃는 것을 막는다. 어긋나면 변조본을 돌리기 전에 종료 1.
  - P5 **제자리는 흔들지 않는다** — 함께 도는 것은 임시 폴더의 사본을 읽는 자체 시험뿐이다. `bite-gates.sh` 의 제자리 흔들기(hold · undo)는 차례대로 그대로다.
- N **NC-2 — `scripts/test-gates.py` · `bite-gates.sh` 끝 절.**
  - N1 **T1′** — `GITHUB_ACTIONS=true` 에 인자 없이 부르고 T1 과 같은 단언(종료 0 · 부르는 것이 다 한 번씩 · 변조 시험 다섯이 맨 뒤)을 건다. CI 가 쓰는 꼴이다.
  - N2 **T5** — 변조 시험 다섯마다 그 하나만 1 로 끝나는 가짜를 세우고, 두 인자 없는 꼴(T1 · T1′) 모두에서 `gates.sh` 가 0 이 아닌 종료여야 한다.
  - N3 **변조본 넷** — `bite-gates.sh` 끝 절에 감사가 든 어긋냄 — ① 건너뛰는 분기에 `|| [ "${GITHUB_ACTIONS:-}" = true ]` ①′ `bites` 호출을
    `[ "${GITHUB_ACTIONS:-}" = true ] || bites` ② `bites || true` ③ `./scripts/bite-gates.sh || true` — 의 `gates.sh` 사본이 `test-gates.py` 에서 다 떨어진다.
    ① · ①′ 은 T1′ 이, ② · ③ 은 T5 가 문다.

**보장하지 않는 것(알려진 한계)**

- **어느 꼴이 물었는지** — `--first` 는 첫 어긋난 꼴만 찍는다. 변조본이 떨어진다는 것만 보고, 꼴마다의 물림은 바른 검사의 자체 시험과 리뷰가 든다(지금도
  변조 시험은 그 줄을 버린다 — `>/dev/null`).
- **시간의 상한** — 성공 기준 1 · 2 의 숫자는 4 코어의 숫자다. 러너의 코어가 줄면 그만큼 느려진다. 시간을 무는 검사는 두지 않는다.
- **함께 돌 때 자원** — 동시 수는 CPU 수 그대로이고 바꾸는 인자나 환경변수를 두지 않는다. 디스크 · 메모리 한도에 걸리면 그 실행이 떨어진다 — 거짓 초록은
  나지 않는다(떨어진 자체 시험은 「물었다」로 세지만, 준비 실패 · 예외는 `bite-verify-docs.py` 가 지금처럼 가르고, `bite-gates.sh` 는 지금도 가르지 않는다).
- **`bite-gates.sh` 의 문서 대조 절이 「물었다」로 세는 까닭** — 지금처럼 0 이 아닌 종료면 무엇이든 물었다로 센다. 그 절을 `bite-verify-docs.py` 처럼
  좁히지 않는다(하지 않을 일 1 의 판정 그대로).
- **검사 줄을 통째로 지운 `gates.sh`** — 조각 35 설계 끝 그대로(감사 OB-2).

## ④ 결정

**정한 것**

- 줄이는 길은 첫 실패에서 멈추기와 함께 돌리기 둘 다다. ADR 0047 의 1.
- 첫 실패에서 멈추기는 자체 시험의 깃발이고, 변조 시험이 부를 때만 단다 — 바른 검사에는 끝까지 돈다. ADR 0047 의 2.
- 함께 도는 것은 한 변조 시험 안의 문서 대조 변조본뿐이고, 동시 수는 CPU 수다. ADR 0047 의 3.
- `bite-verify-docs.py` 는 다른 레포 모드만 돌린다(`--repo-only`). ADR 0047 의 4.
- PR 나눔 — B 가 빠르게 하는 일과 `.gitignore`, C 가 NC-2. ADR 0047 의 5.

**열어 둔 것**

없음 — 1 은 저자가 이 착공 세션에서 정했고(2026-10-23), 2 ~ 5 는 세션이 제안해 착공 PR 에서 저자가 본다.

## ⑤ 검증 계획

시험을 세우는 조각이다(자체 시험의 깃발 · 대조군 · `test-gates.py` 의 꼴 · 변조본을 더한다). 꼴 하나하나와 변조본의 대응은 B · C 의 PR 본문이 든다.

- **시험 규칙**
  - R1 새 깃발은 거절 시험 하나 이상과 변조본 하나 이상을 든다 — ③ A3 의 꼴마다 종료 2(B 의 PR 본문에서 손으로), F2 · F3 은 P4 의 대조군 (가) 가 바른
    검사로, 변조본 일흔하나가 어긋난 검사로 본다.
  - R2 함께 돌리는 길마다 대조군 (나) 하나 — 바꾸지 않은 검사가 「물지 않았다」로 떨어진다. 그 대조군을 지운 사본은 리뷰가 본다(대조군이 대조군을 무는
    사슬은 세우지 않는다).
  - R3 `test-gates.py` 의 새 꼴(T1′ · T5)은 `bite-gates.sh` 끝 절의 변조본 하나 이상이 문다 — ③ G 의 꼴마다(N3).
- V1 **성공 기준 1** — B 첫 머리의 gate 잡 로그(스텝 시간 · 두 변조 시험의 줄 시각)를 B 의 PR 본문과 닫는 기록에 싣는다.
- V2 **성공 기준 2** — B 의 작업트리에서 인자 없는 `./scripts/gates.sh` 를 끝까지 돌려 시간과 끝 줄을 PR 본문에 싣는다(백그라운드).
- V3 **성공 기준 3** — B 의 로그에서 두 변조 시험의 「물었다」 수(26 · 45)와 대조군 줄. 바른 검사에 `--first` 를 단 자체 시험의 `PASS` 줄이 깃발 없는 것과
  같은지 로컬에서 견준다.
- V4 **성공 기준 4** — C 의 로컬과 CI 에서 `test-gates.py` PASS 와 끝 절의 「변조본 …이 다 떨어짐」 줄. 감사가 든 넷을 손으로 재현해 PR 본문에 싣는다.
- V5 **성공 기준 5** — B 의 PR 본문에 `.gate-pass/run.txt` 를 둔 임시 사본의 `verify-slice-gate.py` 결과.
- V6 **성공 기준 6 · 7** — 각 PR 의 CI(eval 잡이 수트 지문이 같아 건너뜀 · gate 잡 통과). A 와 닫기는 지문 밖 문서만 고쳐 변조 시험을 건너뛴다.
- V7 **성공 기준 8** — C 가 머지된 뒤 `main` 에서 기준 `a959096` 으로 `audit-quality` 를 돌리고 닫는 PR 의 대장에 등록한다.
- 단계 5 — 배포처는 이 저장소의 CI 다. 보이는 것은 V1 의 실행이다. 되돌리는 길은 B · C 를 되돌리는 것이다 — 변조본과 판정이 그대로라 되돌려도 무는 힘은
  같고 시간만 돌아온다.
