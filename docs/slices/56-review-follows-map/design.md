## ② 보장하는 것 / 보장하지 않는 것

**보장하는 것**

- **A 같은 말** — ③ A 의 넷 자리가 넓힘 ADR(소유자가 정한 것)과 닫는 PR 의 판정 고침을 기준으로 받는다. 넓힌 몫 · 판정 고침을 「안」으로 가르지 않는다. ⑥ 밖의 보장을 조각 나눔의 줄로만
  넘기는 글이 남지 않는다.
- **B 가리킨다** — 넓힘의 조건(⑥ 줄 · 하지 않을 일 번호 · 소유자)과 판정 고침의 조건(대장의 「고침」 판정)은 지도 한 자리가 든다. 스킬은 지도의 단계 3 · 「닫는 PR」 단락을 가리키고 그 조건을
  옮겨 적지 않는다(ADR 0075 의 4).
- **C 뜻은 그대로** — 예산을 맞추려 줄인 문장은 같은 갈래 · 같은 처리를 말한다. 줄인 문장마다 옛 글 · 새 글을 PR A 본문 표에 든다.
- **D 천장 안** — `SKILL_ON_INVOKE_MAX` 4500 그대로, `slice-review` ≤ 4500.
- **E 프로필 한 자리** — 「이미 있는 프로필에서 고치는 것」은 스킬 `slice-docs` 한 자리다. 틀 머리 주석은 그 줄을 가리킨다.
- **F 지도 링크** — 두 스킬이 지금 지도와 같은 내용의 커밋을 박는다(M5 PASS).
- **G 지도 · `vibe-audit` 그대로** — 요구사항 성공 기준 7.

**보장하지 않는 것(알려진 한계)**

- **스킬과 지도의 말이 갈리는 것을 무는 검사는 없다** — 사람(`CHECKLIST.md`)과 닫기 전 `audit-internal` 회차가 본다.
- **사본 레포의 스킬** — `sync-slice.sh` 로 심은 다른 레포의 사본은 그 레포가 다시 심을 때까지 옛 글이다(하지 않을 일 6).
- **틀 머리의 다른 목록** — 인터뷰 물음 · 혼자 · 여럿은 스킬 · 지도와 겹친 채다(하지 않을 일 3).
- **리뷰가 이 밖을 짚으면 범위 밖이다** — 요구사항 하지 않을 일.

## ④ 결정

**정한 것**

- 지도가 앞선다 — 스킬이 넓힘 ADR 과 닫는 PR 의 판정 고침을 기준으로 받는다 — ADR 0075 의 1(저자)
- 글자 천장 안에서 — 다른 문장을 줄인다 — ADR 0075 의 2(저자)
- 프로필 쌍은 스킬 `slice-docs` 가 첫 자리 — ADR 0075 의 3(저자)
- 스킬은 지도를 가리키고 조건을 옮겨 적지 않는다 — ADR 0075 의 4
- 지도 링크는 지금 지도와 같은 커밋을 같은 PR 의 한 커밋에 — ADR 0075 의 5
- 판 0.9.4 — ADR 0075 의 6
- 감사 회차 `audit-internal` · `audit-quality` — ADR 0075 의 7

**열어 둔 것**

없음 — 넷 자리와 줄일 문장의 글은 PR A 가 쓰고 리뷰가 본다. 줄인 문장의 옛 · 새는 PR A 본문이 든다(② C).
