설계다 — **어떻게 · 경계.** 무엇을 · 왜는 같은 폴더의 `requirements.md`.

## ② 보장하는 것 / 보장하지 않는 것

**보장하는 것**

- **A 예외 · 밖 행이 앞선다** — 첫 행과 예외 · 밖 행에 함께 걸리는 자리는 예외 · 밖 행의 가름을 받고 묻지 않는다고 표 아래 문장이 든다(ADR 0088 의 1).
- **B 묻는 자리가 좁다** — 「두 행에 걸리는 자리」는 첫 행 밖의 행 둘이 다른 가름을 내는 자리다. 같은 가름이면 묻지 않는다(ADR 0088 의 1).
- **C 답은 꼴로** — 저자의 답이 있는 행의 꼴에 들면 그 행의 꼴 · 예 칸을 넓히고, 새 꼴이면 행을 더한다고 표 아래 문장이 든다(ADR 0088 의 2).
- **D 지난 자리가 맞는다** — ③ 의 행이 다 새 구절로 가름이 하나로 나고, 고칠 자리 · 답할 거리가 없다(하지 않을 일 2 · 5).
- **E 이 ADR 이 대체 규칙을 지킨다** — ADR 0088 의 1 · 2 의 결정 줄이 ADR 0082 의 1 을 들고 「대체가 아니다 — <까닭>」을 적는다(요구사항 성공 기준 1).
- **F 장치가 늘지 않는다** — 요구사항 성공 기준 5.

**보장하지 않는 것(알려진 한계)**

- **열거를 예외 · 밖의 꼴로 읽어 「안」을 피하는 것을 막지 않는다** — 어느 꼴인가는 글의 쓰임을 가르는 판단이다. 리뷰와 감사 회차가 본다(ADR 0088 의 1 의 대가 · 5). 이 넘김은 이 조각의 감사
  회차 줄이 범위로 든다.
- **행의 꼴 · 예 칸이 답마다 길어질 수 있다** — ADR 0088 의 2 의 대가.
- **표 밖의 꼴과 첫 행 밖의 행 둘이 다른 가름을 내는 자리는 여전히 판단이다** — 저자에게 묻는 길은 그대로다(ADR 0082 의 1).
- **리뷰가 이 밖을 짚으면 범위 밖이다** — 요구사항 하지 않을 일.

## ③ 받는 입력

검사 장치가 아니다 — 구절을 대어 볼 대상을 닫힌 목록 둘로 든다. 뽑은 법: 감사 회차 44 의 「문서에 없어서」 A · 항목 20 · OB-53 이 든 자리와 조각 63 설계 ③ 의 열 자리에서, 첫 행이나
다른 행에 함께 걸리는 것을 골랐다(착공 `03e2962`). 저장소의 두 벌을 다 훑지 않았다 — 구절이 행 사이를 정하는 것이라 있는 행에 걸린 자리로 대어 보면 된다.

## ④ 결정

**정한 것**

- 예외 · 밖 행이 첫 행보다 앞서고, 두 행에 걸린다는 것은 첫 행 밖의 행 둘이 다른 가름을 낼 때다 — ADR 0088 의 1(저자)
- 답은 꼴로 적는다 — ADR 0088 의 2(저자)
- 자리는 `CLAUDE.md` 표 아래 문장, 표의 행 · 열은 그대로 — ADR 0088 의 3
- `vibe-audit` · `vibe-slice` 그대로 — ADR 0088 의 4
- 검사를 세우지 않는다 — ADR 0088 의 5
- 감사 회차 `audit-internal` 하나, 지도 「돌리는 법」의 기준으로 — ADR 0088 의 6

**열어 둔 것**

없음 — 구절의 글은 PR A 가 쓰고 리뷰가 본다. 글이 들 것은 ① · ② A ~ C · ③ 이 닫는다.

## ⑤ 검증 계획

시험을 세우지 않는다 — 규칙의 문구다. 있는 검사와 `git` · `grep` · ③ 에 대어 본다.

| 보장 | 무엇으로 보이나 |
|---|---|
| A 예외 · 밖 행이 앞선다 | 표 아래 문장에 「첫 행보다 앞선다」가 있다. `git diff` 의 덩이가 그 문장 안 |
| B 묻는 자리가 좁다 | 같은 문장에 「첫 행 밖의 행 둘이 다른 가름」이 있다 |
| C 답은 꼴로 | 같은 문장에 「있는 행의 꼴」 · 「새 꼴」이 있다. `git diff <착공 머지> <A 머지> -- CLAUDE.md` 에 표의 줄(`  \|` 로 여는 줄)이 없다 |
| D 지난 자리 | ③ A · B 의 행마다 PR A 본문에 한 줄씩 — 구절이 내는 것. `git diff <착공 머지> <A 머지> -- docs/master-plan.md docs/adr docs/slices` 빈 출력 |
| E 대체 규칙 | `grep -n '대체가 아니다 — ADR 0082 의 1' docs/adr/0088-*.md` 가 결정 1 · 2 의 줄에서 하나씩 |
| F 늘지 않는다 | 요구사항 성공 기준 5 의 명령과 `eval-key.py route` · `full` 의 출력 |

- **게이트** — `./scripts/gates.sh` 를 PR 마다 돌리고 끝 줄을 PR 본문에 든다. `python3 scripts/verify-docs.py` · `python3 scripts/verify-counts.py` · `python3 scripts/verify-map-pin.py` 가
  PASS 다(절 제목 · 새 수 없음 · 링크 그대로).
