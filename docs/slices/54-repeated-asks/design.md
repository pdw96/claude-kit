## ② 보장하는 것 / 보장하지 않는 것

**보장하는 것**

- **A 한 규칙은 한 자리** — 다섯 규칙 가운데 이 저장소의 것(1 · 5)은 `CLAUDE.md` 에, 일반 절차의 것(2 · 3 · 4)은 `docs/procedure.md` 에 하나씩 산다. `CHECKLIST.md` · `CLAUDE.md` 의 다른
  줄은 그 자리를 가리키고 규칙을 옮겨 적지 않는다 — 이 조각이 세우는 규칙 5 를 이 조각이 먼저 지킨다.
- **B 앵커볼트는 그대로** — 「앵커볼트」 절의 항목 수와 글이 착공 전과 같다. 검사가 읽는 글은 「가변」에 들고, 그 줄이 「바꾸면 같은 PR 이 그 검사를 고친다」를 든다.
- **C 기록은 덧붙이기만** — PR B 가 ADR 에 더하는 것은 끝의 날짜 절뿐이다. ③ B 밖의 ADR 은 바뀌지 않는다.
- **D 규칙은 앞으로만** — 새 규칙 2 · 3 은 이 조각의 PR 부터 걸린다. 지난 `## 닫으며` · 설계 · PR 본문은 바뀌지 않는다. 규칙 4 만 지난 ADR 에 덧붙인다(ADR 0073 의 9).
- **E 도구는 그대로** — 요구사항 성공 기준 8.

**보장하지 않는 것(알려진 한계)**

- **다섯 규칙을 무는 검사는 없다** — 어겨도 키 없이 떨어지지 않는다. 사람(`CHECKLIST.md`)과 다음 `audit-internal` 회차가 본다(하지 않을 일 1).
- **다른 레포는 옛 절차를 읽는다** — `vibe-slice` 의 두 스킬은 지도를 `86d27cc` 로 박았다. 그 링크가 다음에 박힐 때(`vibe-slice/` 를 고치는 조각) 새 단계 3 · 6 과 대체 규칙이 간다(하지 않을
  일 2).
- **③ B 밖의 대체 쌍** — 머리 · 결과에 「대체」를 적지 않았고 감사 기록도 들지 않은 대체가 더 있을 수 있다. 그 ADR 은 대체 줄 없이 남는다(하지 않을 일 6).
- **알려진 두 벌 셋** — 규칙 5 를 어긴 채로 남는다. 조각 나눔 「같은 목록의 두 벌 셋」이 맡는다(하지 않을 일 3).
- **감사자가 다른 까닭으로 같은 물음을 올릴 수 있다** — 규칙의 글이 그 사례에 닿지 않으면 감사자는 다시 「문서에 없어서」에 올린다. 그때는 성공 기준 7 의 미달로 적는다.
- **리뷰가 이 밖을 짚으면 범위 밖이다** — 요구사항 하지 않을 일 4 의 물음들.

## ④ 결정

**정한 것**

- 검사가 읽는 글은 앵커볼트가 아니다 — 바꾸면 같은 PR 이 검사를 고친다 — ADR 0073 의 1(저자)
- 닫는 PR 은 대장에 저자 판정이 있는 고침을 싣고, 구현 PR 은 새 ADR 로 ⑥ · 하지 않을 일을 넓힌다 — ADR 0073 의 2(저자)
- 성공 기준의 근거는 저장소 안 `## 닫으며` 에, PR 몫의 대응표는 PR 본문에 — ADR 0073 의 3(저자)
- 대체 ADR 은 양쪽에 적는다 — 새 ADR 머리와 앞 ADR 끝의 날짜 절 — ADR 0073 의 4(저자)
- 같은 목록의 원칙은 저장소 전체에 걸리고, 있는 셋은 조각 나눔 줄로 넘긴다 — ADR 0073 의 5(저자)
- 규칙의 자리 — 1 · 5 는 `CLAUDE.md`, 2 · 3 · 4 는 `docs/procedure.md`, 사람이 볼 줄은 `CHECKLIST.md` — ADR 0073 의 6
- 새 검사를 세우지 않는다 — ADR 0073 의 7
- `vibe-slice` 판을 올리지 않는다 — ADR 0073 의 8
- 지난 대체는 ③ B 만 — 열한 쌍은 앞 ADR 쪽에, 적지 않은 넷은 양쪽에 — ADR 0073 의 9

**열어 둔 것**

없음 — 규칙의 글은 PR A 가 쓰고 리뷰가 본다. 앞 ADR 에 덧붙이는 절의 꼴은 ADR 0073 의 4 가 든다.

## ⑤ 검증 계획

- **V1 규칙의 자리(PR A)** — PR A 의 diff 가 ① 의 세 파일만 고치고, `CLAUDE.md` 「앵커볼트」 절의 diff 가 빈다(`git diff <착공 머지> <A 머리> -- CLAUDE.md` 에서 그 절 안의 덩이가 없다). 다섯 규칙마다
  사는 줄(파일:줄)을 PR A 본문 표에 대고, 같은 규칙을 다른 파일에 옮겨 적지 않았는지 `CHECKLIST.md` 줄마다 가리키는 절을 든다. 닫으며가 그 표의 핵심 줄을 든다.
- **V2 덧붙이기만(PR B)** — `git diff --numstat <A 머지> <B 머리> -- docs/adr` 의 줄마다 지운 줄 칸이 0 이고, 바뀐 파일이 ③ B 의 앞 ADR 열다섯 자리(파일 열넷)와 「적지 않은 넷」의 새 ADR 가운데 그 밖의 셋(0060 · 0065 · 0070 — 0061 은 앞 ADR 이기도 하다)으로
  열일곱 파일이다. 출력을 PR B 본문과 닫으며에 든다.
- **V3 도구 · 수트** — 요구사항 성공 기준 8 의 명령을 PR 마다 본문에 든다.
- **V4 게이트** — `./scripts/gates.sh` 를 PR 마다 돌린다. 이 조각은 검사를 세우지 않아 변조본이 없다.
- **V5 감사** — 닫기 전 `audit-internal` 회차의 「문서에 없어서」 절을 다섯 물음에 대어 성공 기준 7 을 판정한다.
