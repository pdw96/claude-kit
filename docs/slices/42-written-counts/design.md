## ② 보장하는 것 / 보장하지 않는 것

**보장하는 것**

- **D 닻** — 검사는 닫힌 닻 목록을 든다. 닻 하나는 (파일 · 수를 하나 잡는 꼴 · 그 꼴이 그 파일에 나오는 횟수 · 원천 셈의 이름)이다. 닻마다 그 파일에서 꼴을 찾아
  나온 횟수를 적은 횟수와 견주고, 잡은 수 낱말을 읽어 원천 셈의 값과 견준다. ③ A 의 「기계로」 문장은 다 닻을 가진다.
- **S 원천 셈** — 원천은 닫힌 이름 목록이다(③ A 의 셈 종류 셋 — 파일 수 · 코드의 목록 길이와 상수 · 표의 줄 수). 셈마다 값을 저장소의 파일에서 다시 센다 —
  닻이 수를 들고 있지 않는다. 셈이 0 이거나 읽을 자리를 못 찾으면 「원천을 못 셈」으로 떨어진다(빈 것끼리 견주어 지나가지 않게).
- **L 수 낱말** — 한국어 수 낱말(하나 ~ 아홉 · 열 · 스물 · 서른 · … 과 그 합성, 「한 · 두 · 세 · 네」 꼴)과 아라비아 숫자를 읽는다. 읽지 못한 낱말은 「수 낱말을
  못 읽음」으로 떨어진다 — 0 으로 읽어 지나가지 않는다.
- **E 끝 줄** — `bite-gates.sh` · `bite-*.py` · `test-*.py` 에서 절을 닫는 끝 줄(`echo` · `print` 로 찍는 줄 가운데 ④ 열어 둔 것의 꼴)에 견준 값(셸 · 파이썬 변수)이
  아닌 수 낱말이 있으면 떨어진다. 견준 원천이 있는 낱말(「변조 시험 다섯」 ↔ `FIVE`)은 닻을 가져 이 규칙에서 빠진다. B 는 지금 끝 줄의 갈래 수 낱말을 다 뺀다.
- **F 지금 틀린 자리** — ③ B 의 틀린 6 문장과 모호한 4 문장, ③ A 의 D(측정 · 지난 일이 원천)는 고친 수 · 원천을 가리키는 글 · 날짜나 커밋을 박은 지난 일 ·
  지움 가운데 하나가 된다. 어느 쪽으로 했는지는 그 PR 본문이 문장마다 든다.
- **N 실패 줄의 규칙 ID** — 검사는 실패 줄을 `FAIL [<규칙 ID>] <파일>:<줄> …` 꼴로 찍는다. ID 는 실패의 갈래(적힌 수 ≠ 원천 · 닻이 낡음 · 원천을 못 셈 · 수 낱말을
  못 읽음 · 끝 줄의 수 낱말 따위)마다 하나다 — 닻마다가 아니다.
- **R 규칙마다 변조본** — `bite-gates.sh` 의 새 절이 ADR 0054 의 세 규칙을 따른다 — (가) 돈 변조본 · 대조군 수를 기대한 수와 견주고, (나) 실패 종료이고 기대한 ID 가
  실패 줄에 있을 때만 물었다로 세고, (다) 대조군은 종료 0 과 PASS 줄을 본다. 검사 코드에서 읽은 ID 집합과 변조본이 기대한 ID 집합을 견주고, 한 ID 의 변조본을
  다 지운 목록이 그 대조에서 떨어진다(조각 41 「PR B 에서 정한 것」의 꼴).
- **W 규칙 글** — `CHECKLIST.md` 에 확인 항목 한 줄. `CLAUDE.md` 는 고치지 않는다(③ C — 그 줄은 이미 변조본의 규칙을 든다).
- **G 목록** — `gates.sh` 의 `checks` 에 한 줄, `test-gates.py` 의 `CHECKS` 에 한 이름. 둘을 함께 고친다(ADR 0049). `gates.sh` · `eval.yml` · `docs/architecture.md`
  의 검사 수 낱말은 새 검사가 닻으로 문다 — 고치지 않으면 C 가 제 검사로 떨어진다.
- **T 시간** — CI gate 잡의 「키 없이 도는 게이트」 스텝이 9 분 안이다. 새 검사는 파일 읽기와 glob 뿐이고, 새 변조본 절은 검사 사본을 몇 번 부른다.

**보장하지 않는 것(알려진 한계)**

- **닻 없는 새 문장** — 검사는 닻이 든 문장만 본다. 수를 새로 적으면서 닻을 더하지 않은 PR 은 지나간다 — `CHECKLIST.md` 와 리뷰가 본다(ADR 0055 의 5).
- **닻과 문장을 함께 고친 PR** — 문장의 수와 닻의 꼴을 함께 틀리게 고치면 지나간다. 닻은 수가 아니라 원천의 이름을 들므로, 수만 틀리게 고친 문장은 떨어진다.
- **수가 아닌 수 낱말** — 차례(「넷째 칸」) · 단계(「6 단계」) · 정해진 이름(「판정은 넷이다」 같은 절 제목)은 원천과 견주지 않는다. 끝 줄 훑기(E)도 ④ 의 꼴에
  맞는 줄만 본다.
- **뜻이 맞는지** — 닻은 「그 문장의 그 수가 그 원천의 값」이라는 사람의 판단을 고정한다. 문장의 뜻이 바뀌어 다른 원천을 세야 하는데 꼴이 그대로면 지나간다.
- **기록과 측정** — 요구사항 하지 않을 일 1 · 2.
