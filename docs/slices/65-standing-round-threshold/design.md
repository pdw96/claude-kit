앵커볼트는 건드리지 않는다 — `CLAUDE.md` 의 절 제목이 그대로이고 바뀌는 것은 「작업 방식」 한 줄의 문장이다. 「가변」의 「검사가 읽는 글」은 둘이 닿는다 — `scripts/verify-docs.py` 는

토막 · 닻을 건드리지 않는다. 지도를 고치지 않아 `scripts/verify-map-pin.py` 의 링크도 그대로다. 스크립트 · 플러그인 · CI · 시스템 구조(`docs/architecture.md`)는 그대로다.

## ② 보장하는 것 / 보장하지 않는 것

**보장하는 것**

- **A 문턱은 실패 조건이다** — 무엇이 떨어지는가의 규칙을 더하거나 고치는 조각은 감사 회차 줄에 닫기 전 `audit-internal` 을 상시 회차로 든다. 그 꼴이 첫 「—」 뒤에 이름이 있든 없든
  같다(ADR 0084 의 1).
- **B 예시 밖 꼴도 diff 로 선다** — 회차는 「새 장치인가」를 저자에게 물은 답에 기대지 않는다. 「저자에게 묻는다」는 증거가 필요한지를 묻는 자리로 그대로 남는다(ADR 0084 의 1).
- **C 규칙이 그대로인 줄은 밖, 규칙의 고침은 안** — 있는 규칙이 요구하는 대상 줄과 그 규칙이 맞추라는 값은 문턱 밖이다. 읽는 글의 변경 · 오검 · 놓침의 고침은 규칙을 고치니 안이다(ADR
  0084 의 2 · ADR 0077 의 3 의 대가 그대로).
- **D 한 자리** — 문턱은 `CLAUDE.md` 그 줄의 끝 문장 한 자리에 있고 지도 · `CHECKLIST.md` 는 고치지 않는다(ADR 0084 의 3, 요구사항 성공 기준 3).
- **E 대체가 양쪽에 있다** — ADR 0084 머리와 ADR 0077 끝의 대체 절(요구사항 성공 기준 1).
- **F 장치가 늘지 않는다** — 요구사항 성공 기준 5.

**보장하지 않는 것(알려진 한계)**

- **경계의 읽기는 판단이다** — 대상 줄인가 규칙의 고침인가, 측정인가 실패 조건인가는 diff 를 읽는 세션이 가른다. 걸리는 줄이 있으면 고침으로 읽는다(ADR 0084 의 2 의 대가). 틀린 읽기를
  무는 검사는 없다 — 사람(`CHECKLIST.md` 의 감사 회차 줄)이 본다. 그 조각의 닫기 전 회차가 담당 표로 서는 때에만 감사가 잡는다(ADR 0084 의 5). 이 문장 자체가 그렇게 읽히는지는 이
  조각의 감사 회차 줄이 범위로 든다(요구사항 「제약」 — 지도 「넘긴 일」의 조각 안의 회차).
- **회차를 건너뛴 조각을 키 없이 막지 않는다** — 감사 회차 줄과 같다(조각 58 설계 ②).
- **지난 줄의 글은 옛 문턱을 든다** — 조각 58 ~ 64 의 감사 회차 줄과 ADR 0077 의 본문은 그대로다(하지 않을 일 3). 새 문턱으로 대도 회차가 비는 조각은 없다(③ B).
- **원천 셋째 예시만 읽은 사람은 이 저장소의 문턱을 모른다** — 지도의 예시(「검사를 더하거나 고치는 조각은 …」)는 그대로다(ADR 0084 의 3 의 대가).
- **다른 레포는 이 문턱을 받지 않는다** — 상시 회차는 이 저장소의 작업 규칙이다(ADR 0077 의 2).
- **리뷰가 이 밖을 짚으면 범위 밖이다** — 요구사항 하지 않을 일.

## ③ 받는 입력

검사 장치가 아니다 — 문장을 대어 볼 대상을 닫힌 목록 둘로 든다.

**A 꼴** — 뽑은 곳: `CLAUDE.md` 「새 장치는 새어 나간 결함에만」 줄(착공 `383a82e`)의 첫 「—」 뒤 · 「막지 않는다」 문장 · 「측정은 밖」 문장, 감사 회차 37 OB-4 의 이름 없는 꼴, 회차 39
「문서에 없어서」 A. 첫 「—」 뒤의 꼴은 이름을 다시 적지 않고 한 행으로 든다. 이 밖의 꼴이 나오면 그것을 만나는 조각이 「무엇이 떨어지는지가 바뀌었나」로 가르고, 갈리지 않으면 저자에게
묻는다.

| 꼴 | 어디서 | 옛 문턱(ADR 0077 의 3) | 새 문턱(ADR 0084) |
|---|---|---|---|
| 첫 「—」 뒤의 꼴을 더한다 | `CLAUDE.md` 그 줄 | 안 | 안 — 예시 |
| 첫 「—」 뒤의 꼴을 고친다(있는 검사의 규칙 글) | 같은 줄 · ADR 0077 의 3 의 대가 | 안 | 안 |
| 있는 eval 케이스의 새 그레이더 · 정규식(과 그것이 요구하는 표본) | 회차 37 OB-4 | 정해지지 않음 | 안 — 무엇이 떨어지는지가 바뀐다 |
| 문턱 · 천장 조이기(예: `scripts/verify-budget.py` 의 천장 상수) | 회차 37 OB-4 | 정해지지 않음 | 안 — 같다 |
| 문턱 · 천장 늦추기 | 위의 거울 | 정해지지 않음 | 안 — 고침이다 |
| 있는 규칙이 요구하는 대상 줄(닻 · 고정 목록의 이름 · 원천 표의 행) | 같은 줄 「막지 않는다」 | 정해지지 않음 | 밖 — 규칙이 그대로 |
| 규칙이 맞추라는 값(예: `vibe-audit/evals/budget.txt` 스냅숏) | 조각 60 PR A(`e25797b`) | 정해지지 않음 | 밖 — 떨어지는 기준이 그대로 |
| 있는 규칙을 같은 것을 물게 하는 고침(읽는 글의 변경 · 오검 · 놓침) | 같은 줄 「막지 않는다」 | 안(고친다) | 안 — 규칙을 고친다 |
| 떨어뜨리지 않는 측정(`compare/` · `run-compare.sh` · 러너의 보고 칸) | 같은 줄 「측정은 밖」 · ADR 0076 의 5 | 밖 | 밖 — 실패 조건이 아니다 |
| 글만 고친 커밋(커맨드 · README · 판) | 조각 60 | 밖 | 밖 — 실패 조건이 아니다(읽는 글이 바뀌면 같은 PR 이 검사를 고치고, 그 고침이 안이다) |

**B 지난 조각** — 뽑은 법: `git log --oneline 02997ae..383a82e -- scripts .github vibe-audit vibe-slice compare`(ADR 0077 이 선 뒤). 두 커밋이다.

| 커밋 | 조각 | 고친 것 | 새 문턱 | 그 조각의 회차 |
|---|---|---|---|---|
| `e25797b` | 60 PR A | 커맨드 `audit-brief.md` · 판 · 예산 스냅숏 | 밖 — A 의 「규칙이 맞추라는 값」 · 「글만」 | 닫기 전 `audit-internal`(회차 41) |
| `bc1316b` | 60 닫기 | evals README · 판 | 밖 — 「글만」 | 같음 |

어느 행도 새 문턱에서 회차를 더 부르지 않는다 — 소급할 것이 없다(ADR 0084 의 4).

## ④ 결정

**정한 것**

- 문턱은 실패 조건을 더하거나 고치는 조각, 첫 「—」 뒤는 그 예시 — ADR 0084 의 1(저자). ADR 0077 의 3 을 대체한다
- 규칙이 그대로인 대상 줄 · 값은 밖, 규칙의 고침은 안 — ADR 0084 의 2
- `CLAUDE.md` 그 줄의 끝 문장 한 자리, 지도 · `CHECKLIST.md` · `vibe-audit` · `vibe-slice` 그대로 — ADR 0084 의 3
- 소급하지 않는다 — ADR 0084 의 4
- 검사를 세우지 않는다 — ADR 0084 의 5
- 감사 회차 `audit-internal` 하나 — ADR 0084 의 6

**열어 둔 것**

없음 — 문장의 글은 PR A 가 쓰고 리뷰가 본다. 글이 들 것은 ① · ② A ~ D · ③ A 가 닫는다.

## ⑤ 검증 계획

시험을 세우지 않는다 — 규칙의 문구다. 있는 검사와 `git` · `grep` · ③ 에 대어 본다.

| 보장 | 무엇으로 보이나 |
|---|---|
| A 문턱은 실패 조건 | PR A 본문에 고친 문장. 「실패 조건을 더하거나 고치는」과 근거 ADR 0084 가 있다. `git diff` 의 덩이가 「새 장치는 새어 나간 결함에만」 줄 하나 |
| B 예시 밖도 선다 | 문장이 첫 「—」 뒤를 예시로 두고, 「저자에게 묻는다」 문장이 글자 그대로 남았다(`git diff` 에 그 문장이 없다) |
| C 대상 줄 밖 · 고침 안 | 문장이 대상 줄의 밖과 고침의 안을 들거나 「막지 않는다」 문장을 가리킨다. ③ A 의 행마다 PR A 본문에 「안」 · 「밖」 한 줄씩 — 표의 「새 문턱」과 같다 |
| D 한 자리 | `grep -rn '상시 회차다' CLAUDE.md docs/procedure.md CHECKLIST.md AGENTS.md README.md` → `CLAUDE.md` 한 줄. `git diff --stat 383a82e <A 머지> -- docs/procedure.md CHECKLIST.md` 빈 출력 |
| E 대체가 양쪽에 | `grep -n '0077 의 3 을 대체한다' docs/adr/0084-*.md` · `grep -n '3 은 ADR 0084 가 대체했다' docs/adr/0077-*.md` 가 한 줄씩 |
| F 늘지 않는다 | 요구사항 성공 기준 5 의 명령과 `eval-key.py route` · `full` 의 출력 |

- **게이트** — `./scripts/gates.sh` 를 PR 마다 돌리고 끝 줄을 PR 본문에 든다. `python3 scripts/verify-docs.py` · `python3 scripts/verify-counts.py` · `python3 scripts/verify-map-pin.py` 가
  PASS 다(절 제목 · 새 수 없음 · 링크 그대로).
