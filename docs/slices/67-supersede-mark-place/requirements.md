# 조각 67 — ADR 대체 표기의 자리 (2026-11-11 착공)

요구사항이다 — **무엇을 · 왜.** 어떻게 · 경계는 같은 폴더의 `design.md`, 대안이 있던 결정은 ADR 0086.

이 조각을 「다음 조각」으로 적은 닫힌 조각은 조각 66(닫는 PR 의 글을 보는 회차)이다 — 그 `## 닫으며 (2026-11-11)` 를 읽었다. 넘겨받은 것은 NC-53 이다 — 대장에서 「고침」이고 닫는 것은 다음
`audit-internal` 회차라 이 조각의 닫기 전 회차가 본다. 확인불가 U-59 ~ U-61 은 그 절이 닫았고, 「문서에 없어서」 A · B 는 조각 나눔 「닫는 PR 의 회차와 git 근거」로, C 는 「넘김의
「다음」과 넘긴 감사자」의 덧붙임으로 갔다. 이 줄의 근거는 조각 61 의 닫는 세션이 회차 42 「문서에 없어서」 A · B 로 두었다. 의존은 `—` 다. 저자가 이 착공 세션에서 자리의 갈래 둘을
정했다 — 둘 다 세션이 추천한 쪽(ADR 0086 의 1 · 2). 착공은 `main`(`7fa1d9e`) 위에서 연다. 이 착공 세션의 클론은 얕지 않았다(`git rev-parse --is-shallow-repository` → `false`).

## 문제

**ADR 의 대체 표기에 지도가 정하지 않은 자리가 둘 있다.**

- **늦은 대체 표기** — 지도 「살아 있는 문서와 기록」은 새 ADR 쪽을 「머리에 「ADR NNNN 의 k 를 대체한다」」로만 정한다(ADR 0073 의 4). 머지할 때 머리에 적지 않은 새 ADR 은 머리를 고칠 수
  없어, 새 ADR 끝에 `## 대체 (<YYYY-MM-DD>)` 를 두고 「k 는 ADR NNNN 의 j 를 대체한다 — … 머지할 때 머리에 적지 않아 덧붙인다」로 적어 왔다 — 여섯 ADR(설계 ③ A). 그 꼴은 기록에만 있고,
  같은 제목이 앞 ADR 쪽(「대체했다」)과 새 ADR 쪽(「대체한다」)에 함께 쓰인다.
- **결정 줄이 없는 메움** — 지도는 대체가 아닌 메움 · 넓힘이면 「새 ADR 의 그 결정 줄에」 까닭을 적으라 한다(ADR 0080 의 2). ADR 0080 은 ADR 전체가 앞 결정을 메워 그 번호를 드는 결정 줄이
  없었고, 결정 절 끝 문단에 적었다(설계 ③ B). 지도의 글과 조각 61 설계의 글(「결정 아래」 · 「결정 끝」)이 자리를 다르게 말한다.
- **사람이 보는 줄도 자리를 다시 적는다** — `CHECKLIST.md` 의 대체 줄은 「새 ADR 머리와 앞 ADR 끝의 날짜 절 양쪽에」 · 「그 결정 줄에」로 지도의 자리를 다시 적는다. 자리를 넓히면 그 줄이
  지도와 갈린다.
- 새어 나간 결함은 없다 — 감사 회차 42 「문서에 없어서」 A · B 다(`docs/audit/records/audit-internal-2026-11-09-151813.md`). 같은 회차의 NC-49(꼴의 틀림)는 고쳐 닫혔다.

## 핵심 사용자와 시나리오

- 사용자: 앞 ADR 을 대체하거나 메우는 ADR 을 쓰는 세션과, 그 ADR 을 대어 보는 `audit-internal` 회차.
- 시나리오: 세션이 머지된 ADR 이 앞 ADR 의 결정을 바꿨다는 것을 뒤늦게 안다 → 지도 「살아 있는 문서와 기록」을 읽고 새 ADR 끝에 `## 대체 (<날짜>)` 와 「- k 는 ADR NNNN 의 j 를 대체한다 —
  … 머지할 때 머리에 적지 않아 덧붙인다」를, 앞 ADR 끝에 「- j 는 ADR MMMM 의 k 가 대체했다 — …」를 덧붙인다 → 다른 세션이 ADR 전체로 앞 결정을 메우는 ADR 을 쓰고 「## 결정」 절 끝 한
  문단에 「대체가 아니다 — <까닭>」을 적는다 → 감사자가 지도의 구절에 대어 판정한다.

## 성공 기준

1. **결정이 기록된다** — 착공 PR 이 ADR 0086 을 더하고, 그 ADR 이 1 · 2 를 이 착공 세션의 저자가 정한 것으로 든다. 1 · 2 의 결정 줄이 각각 ADR 0073 의 4 · ADR 0080 의 2 를 번호로 들고
   「대체가 아니다 — <까닭>」을 적는다(이 조각이 정하는 규칙을 이 ADR 이 먼저 지킨다).
2. **지도가 두 자리를 든다** — PR A 뒤 `docs/procedure.md` 「살아 있는 문서와 기록」의 기록 행이 (가) 머리에 적지 못한 대체는 새 ADR 끝에도 같은 제목 `## 대체 (<YYYY-MM-DD>)` 의 날짜 절을
   두고 「- k 는 ADR NNNN 의 j 를 대체한다 — <바뀐 몫>. 머지할 때 머리에 적지 않아 덧붙인다」로 적는다고 하고, (나) 그 번호를 드는 결정 줄이 없으면 「## 결정」 절 끝 한 문단에 「대체가
   아니다 — <까닭>」을 적는다고 하며, (다) ADR 0086 을 든다.
3. **자리는 지도 한 곳** — PR A 뒤 `CHECKLIST.md` 의 대체 줄에 「새 ADR 머리와」 · 「그 결정 줄에」가 없고 그 줄이 `docs/procedure.md` 「살아 있는 문서와 기록」을 가리킨다. `git diff --stat
   7fa1d9e <A 머지> -- vibe-audit vibe-slice CLAUDE.md` 가 빈 출력이다.
4. **지난 사례가 지도에 맞는다** — 설계 ③ A 의 여섯 행과 ③ B 의 행마다 PR A 뒤의 지도 구절로 자리 하나가 나고, 그 자리가 실제 자리와 같다. PR A 본문이 행마다 한 줄씩 든다.
5. **장치가 늘지 않는다** — `git diff --stat 7fa1d9e <각 머지> -- scripts .github vibe-audit vibe-slice compare` 가 빈 출력이다. 수트 지문(`scripts/eval-key.py route` · `full`)이 `7fa1d9e`
   과 같다.
6. **게이트** — `./scripts/gates.sh` 가 이 조각의 PR 마다 작업트리와 CI gate 잡에서 통과한다. `python3 scripts/verify-docs.py` · `python3 scripts/verify-counts.py` ·
   `python3 scripts/verify-map-pin.py` 가 PASS 다.
7. **감사 회차** — 닫기 전 감사 회차를 돌려 `docs/audit/` 의 대장에 등록했다.

## 하지 않을 일

1. **검사를 세우지 않는다** — ADR 의 대체 절 · 「대체가 아니다」의 자리를 무는 검사가 없다. 새 실패 조건이 없다(ADR 0086 의 5).
2. **지난 ADR 을 고치지 않는다 — 소급하지 않는다** — ADR 0060 · 0061 · 0065 · 0070 · 0077 · 0078 · 0080 은 글자 그대로다(ADR 0086 의 4). 이 조각은 대체 절을 어디에도 덧붙이지 않는다 — ADR
   0086 은 앞 ADR 을 대체하지 않는다.
3. **대체의 문턱을 바꾸지 않는다** — 「앞 ADR 의 결정 문장을 지금 결정으로 읽으면 틀리게 되면 대체」(ADR 0080 의 1)와 「근거로만 드는 인용은 밖」은 그대로다. 자리만 정한다.
4. **`vibe-audit` · `vibe-slice` 를 고치지 않는다** — 스킬 · 틀 · 감사자 문구 · 판 · 수트 지문 · 사본 · 두 스킬의 지도 링크가 그대로다(ADR 0086 의 3).
5. **다른 자리를 고치지 않는다** — `CLAUDE.md` · `AGENTS.md` · `README.md` 와 지도의 다른 절, `CHECKLIST.md` 의 다른 줄은 그대로다.
6. **조각 나눔의 다른 줄을 다루지 않는다** — 「닫는 PR 의 회차와 git 근거」 · 「목표 칸 덧붙임과 이름 칸」 · 「넘김의 「다음」과 넘긴 감사자」 · 「실패 조건의 경계 — 도구의 멈춤과 저장소 설정」 등.

## 제약

- 스택: 마크다운. 스크립트를 고치지 않는다.
- 원본: `main` `7fa1d9e`.
- 비용: **$0** — 측정이 없다. 수트 지문은 `vibe-audit/` 만 읽는다(`scripts/eval-key.py` 머리) — 이 조각은 그 밖이다.
- 기간: 닫기까지 **사흘**(2026-11-14 까지).
- 리뷰: 착공 PR 도 구현 PR 도 스킬 `slice-review` 로 가른다. PR 마다 **3라운드**를 넘기면 소유자가 판정한다.
- 감사 회차: 닫기 전 — `audit-internal`(바뀌는 것 — 절차 지도 「살아 있는 문서와 기록」의 규칙 글과 `CHECKLIST.md` 의 대체 줄: 지도의 두 구절 · ADR 0086 · 설계 ② 가 같은 말을 하는가, 구절이 같은
  칸의 문턱(ADR 0080)과 ADR 0073 의 4 의 꼴과 갈리지 않는가, 설계 ③ 의 행마다 자리 하나가 나는가, ADR 0086 자신이 두 구절을 지키는가. 대장이 이 조각에 기대는 것 — NC-53(고침) 재감사.
  기준은 지도 「돌리는 법」대로 회차 47 이 감사한 커밋 `8088a8b` 라 조각 66 의 닫는 PR 도 이 회차가 본다(ADR 0085). 이 조각이 넘긴 일 — 자리를 무는 검사가 없어 이 회차가 본다(설계 ②)).
  `audit-quality` 는 고르지 않는다 — 검사 · 변조본 · 평가셋이 바뀌지 않고, 실패 조건을 더하거나 고치지 않아 상시 회차도 걸리지 않는다.
