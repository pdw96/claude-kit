# 조각 52 — 차별점으로 좁히기 (2026-11-02 착공)

요구사항이다 — **무엇을 · 왜.** 어떻게 · 경계는 같은 폴더의 `design.md`, 대안이 있던 결정은 ADR 0069.

이 조각을 「다음 조각」으로 적은 닫힌 조각은 조각 51(다른 플러그인과 맞대기)이다 — 그 `## 닫으며 (2026-11-02)` 를 읽었다. 넘겨받은 일은 마스터플랜의 이 조각 줄이 든다 —
NC-29(러너가 정답지를 `--plugin-dir` 밖에 두고 `claude-security` 팔을 다시 잰다), NC-28 의 둘째 제안(결과를 세션 밖에 남기는 길), 회차 26 의 OB-3 · OB-2 · OB-1, 「안 본 것」의
`audit-secrets` 몫(하네스 밖 팔에 넘기는 자격 · `dontAsk`)과 `audit-internal` 몫(러너 머리 주석의 종료 문장). 저자가 이 착공 세션에서 셋을 정했다 — 「같다」 축의 감사자는 그대로
두고 README 에서 주장하지 않는다, README 의 주장은 「저장소 규칙의 효력 범위를 가린다」, `claude-security` 팔만 다시 재고 천장은 $8(ADR 0069 의 1 ~ 3). 착공은 `main`(`4db2666`)
위에서 연다. 이 착공 세션의 클론은 얕지 않았다(`git rev-parse --is-shallow-repository` → `false`).

## 문제

**맞대기가 판정을 냈는데 그것을 쓸 자리가 없다.** 조각 51 이 축마다 data · contract · secrets 같다, internal 앞선다를 냈다(`docs/eval-log/2026-11.md` 「조각 51 PR C」).
README 는 여전히 「목적별로 범위를 좁힌 감사자 6종」만 말하고, 무엇이 다른지는 어디에도 없다. 다음 조각 「공개 확산」이 그 주장을 받아 영어 README 를 쓴다.

- **앞섬은 한 곳에 모였다** — 함정 두 케이스(6 회차)에서 `vibe-audit` 5/6 · 플러그인 없음 0/6, `pr-review-toolkit` 은 `trap-slice-scope` 0/3. 떨어진 회차는 다 닫힌
  조각 · 옛 문서 · 로컬 전용 값을 고칠 결함으로 냈다. internal 의 차 +3 은 `trap-slice-scope` 한 케이스에서 다 나왔다.
- **「같다」는 좁힐 근거가 아니다** — data · contract 판정은 회수율 여섯에서만 나왔고, 회수율은 감사자가 **예전에 놓친** 결함으로 만든 케이스다(조각 39). 플러그인 없음도
  18/18 이라 「감사자만의 몫이 이 묶음에 없다」까지는 말하지만, 두 축에 함정 케이스가 없어 감사자 문구의 어느 줄이 쓸모없는지는 말하지 않는다.
- **secrets 판정은 전제 위에 섰다(NC-29)** — 하네스 밖 `claude-security` 팔이 정답지(`case.yaml` · `graders/found.md`)가 든 플러그인 폴더를 `--plugin-dir` 로 받았다. 그 팔을
  넣으면 −1 같다, 빼면 +2 앞선다. 주 세션 트레이스 여섯에는 그 경로가 0 건이지만 하위 에이전트 · 연구원의 호출은 트레이스에 실리지 않는다.
- **잃는 것** — README 가 잰 근거 없이 넓게 말하거나(「더 잘 잡는다」), 잰 앞섬을 말하지 못한다. secrets 의 판정이 한계를 단 채로 「공개 확산」에 넘어간다.

## 핵심 사용자와 시나리오

- 사용자: 저자 한 명, 그리고 「공개 확산」을 착공하는 세션.
- 시나리오: 세션이 러너를 고쳐 정답지를 하네스 밖 팔에 건네지 않게 한다 → 가짜 `claude` 로 넘긴 폴더에 정답지가 없음을 보인다(비용 0) → 측정 기계에서
  `./scripts/run-compare.sh claude-security --from <클론>` 을 한 번 돌린다(여섯 회차 · 천장 $8) → 회차마다 세션 기록(하위 에이전트 포함)에서 정답지 낱말이 나온 수를 본다 →
  eval-log 에 secrets 축 판정을 다시 적고 NC-29 를 처분한다 → 루트 README 에 「저장소 규칙의 효력 범위를 가린다」를 숫자와 한계와 함께 세운다 → 「공개 확산」이 그 절을 옮긴다.

## 성공 기준

1. **정답지를 건네지 않는다** — `claude-security` 팔이 `--plugin-dir` 로 넘기는 폴더에 `compare/` · `case.yaml` · `found.md` 가 없다. 가짜 `claude` 로 러너를 돌려 넘긴 폴더의
   목록을 PR B 본문에 보인다.
2. **새는 길을 센다** — 하네스 밖 팔은 회차마다 그 회차의 임시 HOME 에 남은 세션 기록(하위 에이전트 포함)을 결과 폴더에 남기고, 정답지 낱말(설계 ③ B 의 닫힌 목록)이 나온
   회차 수를 끝 표에 찍는다. 가짜 `claude` 가 그 낱말을 쓴 기록을 남기면 그 수가 1 로 찍히는 것을 PR B 본문에 보인다.
3. **다시 잰다** — `claude-security` 두 케이스 × 3 회차, 모자란 칸 없이, 측정 합 **$8 안**. 여섯 회차를 사람이 다 읽어 심판과 갈린 회차를 표에 적는다.
4. **판정을 다시 적는다** — `docs/eval-log/2026-11.md` 에 새 항목 — 케이스 × 팔 표의 `claude-security` 칸 · secrets 축 판정(ADR 0066 의 4 그대로) · 정답지 낱말이 나온 회차 수 ·
   비용 · 수트 모델 · CLI 판 · 경쟁 커밋. 재료가 조각 51 측정과 같다는 것 — 이 팔이 읽는 재료(설계 ⑤ 「재료 견주기」의 경로)의 `git diff --stat ba1f955 <측정 커밋>` 이 비어 있다(회차 26 OB-3).
5. **결과가 남는다** — 결과 폴더를 `docs/eval-log/compare-<날짜>.tar.xz` 로 싣고, 싣기 전에 자격 앞머리 · `sk-ant-` · `ghp_` · `github_pat_` 를 훑어 0 건이다(NC-28 의 길).
6. **README 의 주장이 선다** — 루트 `README.md` 에 절 하나가 「저장소 규칙의 효력 범위(닫힌 조각 · 옛 문서 · 로컬 전용 값)를 고칠 결함으로 올리지 않는다」를 함정 두 케이스의
   팔마다 맞힘 · 재료 · 수트 모델 · 경쟁 커밋 · 표본 크기와 함께 들고, data · contract · secrets 는 「같다」였다는 것과 그 한계를 적고, eval-log 를 가리킨다. 그 절은
   `claude-security` 를 상대로 앞선다고 말하지 않는다.
7. **감사자 · 수트는 그대로다** — `vibe-audit/` · `scripts/run-evals.sh` 의 diff 가 비고, 이 조각의 PR 마다 `eval-key.py route` · `full` 이 `main` 과 같다.
8. **게이트** — `./scripts/gates.sh` 가 이 조각의 PR 마다 CI gate 잡에서 통과한다.
9. **감사 회차** — 닫기 전 감사 회차를 돌려 `docs/audit/` 의 대장에 등록했다. NC-29 는 판정을 받는다.

## 하지 않을 일

1. **감사자 문구를 고치지 않는다** — 「같다」 축(data · contract · secrets)의 체크 항목도 그대로다(ADR 0069 의 1). 수트 지문이 바뀌지 않는다.
2. **다른 세 팔을 다시 재지 않는다** — `vibe-audit` · 플러그인 없음 · `pr-review-toolkit` 의 측정은 조각 51 그대로 쓴다. 하네스 팔의 Bash 읽기 전용 오류(회차 26 OB-1)는 그
   팔들을 다시 잴 때의 일이다.
3. **재료를 고치지 않는다** — `compare/` 의 케이스 · 그레이더 · 프롬프트 · `arms.tsv` 와 출처 픽스처. 고치면 조각 51 의 다른 팔과 견줄 수 없다.
4. **경쟁 쪽을 권하거나 깎지 않는다** — README 는 `claude-security` 를 상대로 한 주장을 하지 않고, 「그 축은 다른 플러그인을 쓰라」도 적지 않는다.
5. **새 검사 · 변조본 · 게이트를 세우지 않는다** — 러너의 정답지 낱말 세기는 측정 도구의 한 칸이고 게이트에 들지 않는다(마스터플랜 「새 장치는 새어 나간 결함에만」).
6. **영어 README · 설치 경로를 손대지 않는다** — 「공개 확산」의 일이다. 이 조각은 한국어 README 에 절 하나만 더한다.
7. **하네스 밖 팔에 격리를 더하지 않는다** — 자격 · `dontAsk` 는 받아들이고 적는다(ADR 0069 의 5).

## 제약

- 스택: bash · python3 표준 라이브러리 · `claude plugin eval` 과 `claude -p`(맞대기 러너 `scripts/run-compare.sh` 로만 부른다 — `CLAUDE.md` 「금지」).
- 원본: `main` `4db2666`. 경쟁 쪽: `anthropics/claude-plugins-official` `a7ba5b93db0c7c8d17f3f1d25853adca79598a1a`(읽기 전용 클론).
- 측정 기계: `bubblewrap` · `socat` 설치, 위 커밋의 클론, 자격은 `EVAL_OAUTH_TOKEN` 을 `CLAUDE_CODE_OAUTH_TOKEN` 으로 넘긴다 — 저장소에 쓰지 않는다.
- 비용: 조각 전체 **$8** 천장 — 러너가 `claude-security` 팔에 `$8` 을 건다(지난 측정 여섯 회차 $4.09). 넘을 것 같으면 멈추고 저자에게 올린다. 11 월 합은 이미 약 $66.1 이고, 저자가
  알고 정했다(2026-11-02). 수트 지문을 바꾸지 않아 route 수트가 돌지 않는다.
- 기간: 닫기까지 **사흘**(2026-11-05 까지).
- 리뷰: 착공 PR 도 구현 PR 도 스킬 `slice-review` 로 가른다. PR 마다 **3라운드**를 넘기면 소유자가 판정한다.
- 감사 회차: 닫기 전 — `audit-quality`(대장이 이 조각에 기대는 것 — NC-29 의 기한이 이 조각을 닫기 전 `audit-quality` 회차이고, NC-28 이 고침 상태로 그 회차를 기다린다. 바뀌는 것이
  러너 · 측정이다) · `audit-secrets`(대장이 이 조각에 기대는 것 — 회차 26 「안 본 것」의 몫, 하네스 밖 팔에 넘기는 자격 · `dontAsk`) · `audit-internal`(대장이 이 조각에 기대는 것 —
  회차 26 「안 본 것」의 몫, 러너 머리 주석의 종료 문장. 바뀌는 것이 README 의 주장이라 eval-log 와 맞는지 본다).
