## ② 보장하는 것 / 보장하지 않는 것

**보장하는 것**

- **A 한 자리** — 브리핑 · 기록 작업본의 경로 목록은 `vibe-audit/scripts/verify-brief.py` 의 `DEFAULT_EXCLUDE` 한 자리다. `verify-counts.py` 에 그 경로 글자가 없다(성공 기준 2).
- **B 같은 집합** — 지금 트리에서 `verify-counts.py` 가 훑는 파일 집합이 착공 전과 같다. 첫 자리의 항목마다 그 경로 자체이거나 그 아래를 뺀다 — 지금의 앞부분 견주기(`/` 로 끝나는 폴더 둘 ·
  파일 하나)와 같은 경로를 뺀다. PASS 줄의 「훑은 파일 N」이 착공 전과 같다.
- **C 훑는 트리에서 읽는다** — `verify-counts.py <루트>` 는 `<루트>/vibe-audit/scripts/verify-brief.py` 를 읽는다 — 그 검사 파일 옆이 아니다. 사본 변조본이 사본의 목록을 본다.
- **D 실행하지 않는다** — 그 파일을 불러오거나 돌리지 않는다. 맨 위 대입 하나를 읽는다.
- **E 말없이 넘어가지 않는다** — 파일이 없거나 · 못 읽거나 · 구문이 틀리거나 · 맨 위 대입 `DEFAULT_EXCLUDE` 가 없거나 · 그 값이 문자열만 든 비지 않은 튜플이 아니면 `FAIL [U5]` 로 끝난다. 옛
  목록이나 빈 목록으로 넘어가지 않는다.
- **F 무는 것이 있다** — 변조본 둘(`U5` · 읽는 고리)이 기대한 ID 로 떨어지고, 대조군 셋이 PASS 줄로 지나간다(성공 기준 3).
- **G 플러그인은 그대로** — 요구사항 성공 기준 7.

**보장하지 않는 것(알려진 한계)**

- **그 상수를 다른 뜻으로 쓰면 따라간다** — `DEFAULT_EXCLUDE` 에 작업본이 아닌 경로를 더하면 `verify-counts.py` 도 그 경로를 훑지 않는다. 그 상수의 뜻은 `verify-brief.py` 가 든다.
- **커맨드 본문과의 두 벌** — `/audit-brief` 커맨드가 같은 경로를 따로 적는다. 조각 나눔 「`/audit-brief` 커맨드의 제외 목록」이 맡는다(하지 않을 일 2).
- **프로필 쌍** — 규칙을 어긴 채 남는다. 「`slice-review` 를 새 단계 3 에 맞추기」가 맡는다(하지 않을 일 1).
- **다른 두 벌** — 이 조각이 찾지 않았다(하지 않을 일 4). 다음 `audit-internal` 회차가 본다.
- **훑는 길의 다른 동작** — git 이 실패할 때 폴더 길로 넘어가 무시된 파일까지 훑는 것(회차 20 OB-1)은 그대로다(하지 않을 일 6).
- **리뷰가 이 밖을 짚으면 범위 밖이다** — 요구사항 하지 않을 일.

## ③ 받는 입력

검사 장치의 입력이 하나 는다 — 훑는 트리의 `vibe-audit/scripts/verify-brief.py`. 받는 꼴은 지금 그 파일에서 뽑은 닫힌 목록이다.

| 꼴 | 지금 파일 | 받나 |
|---|---|---|
| 모듈 맨 위(들여쓰지 않은) 대입문 `DEFAULT_EXCLUDE = (<문자열>, …)` 하나 — 대상이 이름 하나 | `verify-brief.py:44` | 받는다 |
| 값은 튜플이고 항목이 다 문자열이고 하나 이상 — `ast.literal_eval` 로 읽는다 | `(".claude/audits", ".claude/briefs", ".claude/audit-brief.md")` | 받는다 |
| 항목 끝의 `/` | 지금 없다 | 떼고 받는다 — 경로 맞춤이 그 경로와 그 아래를 본다 |

그 밖은 거절한다 — `U5`. 파일이 없다 · UTF-8 로 못 읽는다 · 구문이 틀리다 · 그 이름의 맨 위 대입이 없거나 둘 이상이다 · 함수 안의 대입만 있다 · 덧붙임 대입(`+=`)이나 꼴 붙은 대입(`:`)이다 ·
값이 리터럴이 아니다(이름 · 호출 · 더하기) · 튜플이 아니다(리스트 · 문자열 하나) · 비었다 · 문자열이 아닌 항목이 있다 · 빈 문자열이나 `/` 로만 된 항목이 있다. 마지막 것은 비우면
모든 경로를 빼게 되어서다(`verify-brief.py:346` 의 빈 `--exclude` 거절과 같은 까닭).

경로 맞춤 — 훑는 파일의 저장소 기준 경로 `rel` 이 항목 `e` 와 같거나 `e + "/"` 로 시작하면 뺀다.

## ④ 결정

**정한 것**

- 프로필 쌍은 「`slice-review` 를 새 단계 3 에 맞추기」 줄로 넘긴다 — ADR 0074 의 1(저자)
- `verify-brief.py` 의 `DEFAULT_EXCLUDE` 가 첫 자리이고 `verify-counts.py` 가 읽는다 — ADR 0074 의 2(저자)
- 훑는 트리에서 `ast` 로 읽고, 못 읽으면 `U5` — ADR 0074 의 3
- 경로 맞춤은 그 경로 자체이거나 그 아래 — ADR 0074 의 4
- 정답지 낱말 쌍은 고치지 않는다 — ADR 0074 의 5
- 넷째 쌍(커맨드 본문)은 조각 나눔 줄로 둔다 — ADR 0074 의 6
- 변조본 둘 — `U5` 와 읽는 고리 — ADR 0074 의 7

**열어 둔 것**

없음 — 받는 꼴과 거절은 ③ 이, 변조본 둘의 모양은 ⑤ 가 든다. 실패 줄의 글은 PR A 가 쓰고 리뷰가 본다.

## ⑤ 검증 계획

시험을 세우는 조각이다 — 있는 `bite-gates.sh` 의 `verify-counts.py` 절에 변조본을 더한다. 시험 규칙은 그 절이 이미 진 규칙(조각 41 설계 ② N1 — 종료 1 과 기대한 ID 의 `FAIL [ID]` 줄 · 대조군은
PASS 줄 · 끝 줄이 견준 수를 찍는다)과 「ID 마다 변조본」(조각 42 설계 ② R — `rgap` 이 `r.fail("…` 의 ID 마다 `vbite` 를 찾는다)이다. 새 규칙을 두지 않는다.

| 보장 | 무엇으로 보이나 |
|---|---|
| A 한 자리 | 성공 기준 2 의 `git grep` 이 빈다. PR A 본문과 닫으며가 그 출력을 든다 |
| B 같은 집합 | 착공 전(`00c2de5`)과 PR A 머리에서 인자 없는 `python3 scripts/verify-counts.py` 의 PASS 줄을 견준다 — 「훑은 파일 N」이 같다. 「브리핑 작업본을 심은 사본」 대조군이 그대로 지나간다 |
| C 훑는 트리 | 변조본 (나)가 사본의 `verify-brief.py` 만 고치고 떨어진다 — 저장소의 것을 읽었다면 지나간다 |
| D 실행하지 않는다 | 변조본 (가)의 사본에서 `verify-brief.py` 맨 위에 `raise SystemExit(9)` 를 더해도 `verify-counts.py` 의 종료가 9 가 아니다 — PR A 본문에 손으로 든다(변조본으로 두지 않는다 — 보장이 「하지 않는다」라 떨어질 ID 가 없다) |
| E 말없이 넘어가지 않는다 | 변조본 (가) — 사본 `verify-brief.py` 의 `DEFAULT_EXCLUDE = ` 를 다른 이름으로 바꾸면 `FAIL [U5]`. ③ 의 거절 꼴 나머지는 PR A 본문에 손으로 대 본 표를 든다(꼴마다 변조본을 두지 않는다 — 한 ID 의 한 갈래다) |
| F 무는 것 | 변조본 (나) — 사본의 그 상수에서 `".claude/audit-brief.md"` 를 빼고 같은 원천 문장을 든 `.claude/audit-brief.md` 를 심으면 `FAIL [U1] .claude/audit-brief.md`. 끝 줄 「합 29 … 대조군 3」, `sclose 29 3` |
| G 플러그인 그대로 | 요구사항 성공 기준 7 의 명령을 PR 마다 본문에 든다 |

- **게이트** — `./scripts/gates.sh` 를 PR 마다 돌리고 끝 줄을 PR 본문에 든다. 변조 시험은 로컬에서 인자 없이 한 번 돈다.
