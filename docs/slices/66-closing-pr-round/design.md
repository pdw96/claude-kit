# 조각 66 설계 — 닫는 PR 의 글을 보는 회차

설계다 — **어떻게 · 경계.** 무엇을 · 왜는 같은 폴더의 `requirements.md`.

## ① 바뀌는 것

| 파일 | PR | 무엇 |
|---|---|---|
| `docs/master-plan.md` | 착공 · 닫기 | 조각 나눔 — 「닫는 PR 의 글을 보는 회차」를 순서 66 · `진행` 으로 · 조각 폴더. 닫기에서 `닫힘` · 다음 조각. 목표 칸은 고치지 않는다 |
| `docs/slices/66-closing-pr-round/` · `docs/adr/0085-closing-pr-round.md` | 착공 | 이 요구사항 · 설계 · ADR |
| `docs/adr/0073-repeated-asks.md` | 착공 | 끝에 `## 대체 (2026-11-11)` 절 — 「- 7 의 「`## 닫으며` 의 근거」(3 의 규칙) 몫은 ADR 0085 가 대체했다 — …」(ADR 0073 의 4). 본문은 그대로 |
| `docs/procedure.md` | A | 「일곱 단계」 아래 「감사 회차」의 굵은 항목 「돌리는 법」 하나. 지금 글(「한 작업트리에서 하나씩(`vibe-audit` 의 README). 기준이 있으면 `/audit-brief` 로.」)의 둘째 문장을 기준의 규칙으로 바꾼다 — (가) 기준은 이 조각 앞의 마지막 회차가 감사한 커밋, (나) 대장 지나간 쪽의 마지막 회차 절 첫 줄에서 읽고 앞 회차가 없으면 착공 전 기본 가지, (다) 이 조각의 회차는 다 같은 기준, (라) 그래서 앞 조각의 닫는 PR 이 diff 에 든다, (마) `/audit-brief` 로 준다, 근거 ADR 0085. 첫 문장(한 작업트리에서 하나씩)은 그대로 |
| `docs/audit/` | 닫기 | 닫기 전 감사 회차의 기록 · 브리핑 · 대장 등록 |

항목의 글은 PR A 가 쓰고 리뷰가 본다. 수를 글자로 적지 않는다 — `scripts/verify-counts.py` 가 살아 있는 문서에 적힌 수를 본다. 「언제」 · 「어느 감사자」 · 「결과」 · 「넘긴 일」과 단계 표 ·
「이 줄을 무는 검사는 없다」 문장은 그대로다.

앵커볼트는 건드리지 않는다 — 지도의 절 제목(「…의 칸」 여섯 절의 제목 · 표 서식)이 그대로이고, 「감사 회차」는 「일곱 단계」 절 안의 굵은 항목이다. 「가변」의 「검사가 읽는 글」은 셋이 닿는다 —
`scripts/verify-docs.py` 는 지도의 절 제목 · 표를 원천으로 읽고, `scripts/verify-counts.py` 는 살아 있는 문서에 적힌 수를 보고, `scripts/verify-map-pin.py` 는 두 스킬의 지도 링크가
`vibe-slice/` 를 마지막으로 고친 커밋의 지도인지 본다. 항목은 절 제목 · 표를 건드리지 않고 수를 적지 않으며, `vibe-slice/` 를 고치지 않는다(ADR 0085 의 3). 스크립트 · 플러그인 · CI ·
시스템 구조(`docs/architecture.md`)는 그대로다.

## ② 보장하는 것 / 보장하지 않는 것

**보장하는 것**

- **A 닫는 PR 이 diff 에 든다** — 회차의 기준이 이 조각 앞의 마지막 회차가 감사한 커밋이라, 그 뒤의 닫는 PR · 대장 등록 · 다른 조각의 일이 이 조각 회차의 diff 에 든다. 커밋이 빠짐없이 어느
  회차의 diff 에 든다(ADR 0085 의 1).
- **B 기준을 읽는 자리가 하나다** — 대장 지나간 쪽의 마지막 회차 절 첫 줄(「감사한 커밋」). 앞 회차가 없으면 착공 전 기본 가지(ADR 0085 의 2).
- **C 이 조각의 회차는 같은 기준** — 어느 PR 의 머지 전 회차와 닫기 전 회차가 다 같은 기준을 쓴다. 둘째 회차의 diff 가 비지 않는다(ADR 0085 의 2).
- **D 지도 항목 하나** — 「돌리는 법」 굵은 항목 하나만 고치고 `vibe-audit` · `vibe-slice` 는 그대로다(요구사항 성공 기준 3).
- **E 대체가 양쪽에 있다** — ADR 0085 머리와 ADR 0073 끝의 대체 절(요구사항 성공 기준 1).
- **F 이 조각에서 문다** — 이 조각의 닫기 전 회차가 기준 `205bc09` 로 돌아 조각 65 의 닫는 PR 을 본다(요구사항 성공 기준 4).
- **G 장치가 늘지 않는다** — 요구사항 성공 기준 5.

**보장하지 않는 것(알려진 한계)**

- **닫는 PR 의 글은 다음 조각의 회차까지 보지 않은 채 `main` 에 있다** — 그 사이에 그 글을 읽고 일한 세션은 틀린 근거를 받을 수 있다(ADR 0085 의 1 의 대가).
- **다음 회차의 담당이 아니면 diff 에 들어도 보지 않는다** — 다음 조각의 회차가 `audit-quality` 뿐이면 `## 닫으며` 의 근거는 그 담당 밖이다. 다음 `audit-internal` 회차의 기준은 그보다 뒤라 그 글을
  다시 담지 않는다(ADR 0085 의 2 의 대가). 이 한계는 이 조각의 감사 회차 줄이 범위로 든다(요구사항 「제약」 — 지도 「넘긴 일」의 조각 안의 회차).
- **기준을 틀리게 준 회차를 키 없이 막지 않는다** — 브리핑 머리의 「기준」 줄과 대장의 회차 절은 사람(`CHECKLIST.md` 의 감사 회차 줄)과 그 회차의 감사자가 본다(ADR 0085 의 5). 이 넘김은 이 조각의
  감사 회차 줄이 범위로 든다.
- **지난 닫는 PR 은 본 회차 없이 남는다** — 조각 56 ~ 64 의 `## 닫으며` 근거(하지 않을 일 2).
- **다른 레포는 링크가 박힐 때까지 옛 「돌리는 법」을 읽는다** — 두 스킬의 지도 링크를 다시 박지 않는다(ADR 0085 의 3).
- **리뷰가 이 밖을 짚으면 범위 밖이다** — 요구사항 하지 않을 일.

## ③ 받는 입력

검사 장치가 아니다 — 항목을 대어 볼 대상을 닫힌 목록 둘로 든다.

**A 지난 회차의 기준** — 뽑은 법: `docs/audit/briefs/audit-internal-2026-11-0[6-9]*` · `audit-internal-2026-11-1*` 의 「기준」 줄의 머지 베이스와 그 커밋의 둘째 부모 제목(착공 `36843e0`).
대장 밖 몫은 `git diff --shortstat <기준>^1 <기준>^2 -- . ':(exclude)docs/audit'`.

| 회차 | 브리핑 | 기준 | 그 기준이 머지한 것 | 대장 밖 몫 | 새 기준이면 |

| 38 | `audit-internal-2026-11-06-074921` | `f8cf848` | 조각 56 닫는 PR | 3 파일 +34 −2 | 앞 회차가 감사한 커밋 — 조각 56 닫는 PR 이 diff 에 든다 |
| 39 | `audit-internal-2026-11-09-052447` | `2d48d97` | 조각 57 닫는 PR | 4 파일 +56 −8 | 같음(조각 57) |
| 40 | `audit-internal-2026-11-09-070950` | `30822f5` | 조각 58 닫는 PR | 3 파일 +34 −4 | 같음(조각 58) |
| 41 | `audit-internal-2026-11-09-095509` | `7a15be0` | 조각 59 닫는 PR | 5 파일 +40 −2 | 같음(조각 59) |
| 42 | `audit-internal-2026-11-09-151813` | `667ffcf` | 조각 60 닫는 PR | 4 파일 +37 −3 | 같음(조각 60) |
| 43 | `audit-internal-2026-11-09-173337` | `4c04836` | 조각 61 닫는 PR | 2 파일 +35 −1 | 같음(조각 61) |

어느 행도 닫는 PR 이 그 회차의 diff 에 들지 않았다 — 기준이 닫는 PR 의 머지 커밋이었다.

**B 기준이 될 커밋의 꼴** — 이 밖의 꼴이 나오면 그것을 만나는 조각이 항목에 비춰 가르고, 항목에 없으면 저자에게 묻는다.

| 꼴 | 항목이 내는 기준 |
|---|---|
| 앞 조각이 닫기 전 회차 하나를 돌았다 | 그 회차가 감사한 커밋 |
| 앞 조각이 회차를 둘 이상 돌았다(어느 PR 의 머지 전 · 닫기 전) | 마지막 회차 절의 감사한 커밋 — 그 조각의 닫기 전 회차 |
| 앞 조각이 회차를 돌지 않았다(「감사 회차: 없음」) | 그보다 앞의 마지막 회차가 감사한 커밋 — 사이의 조각들이 다 diff 에 든다 |
| 레포에 회차가 아직 없다 | 착공 전 기본 가지 |
| 이 조각이 회차를 둘 이상 돈다 | 다 같은 기준 — 첫 회차를 돌기 전의 마지막 회차 절 |

## ④ 결정

**정한 것**

- 닫는 PR 의 글은 다음 조각의 회차가 본다 — 기준은 이 조각 앞의 마지막 회차가 감사한 커밋 — ADR 0085 의 1(저자). ADR 0073 의 7 의 「`## 닫으며` 의 근거」 몫을 대체한다
- 기준은 대장 지나간 쪽 마지막 회차 절 첫 줄에서 읽고, 이 조각의 회차는 다 같은 기준, 앞 회차가 없으면 착공 전 기본 가지 — ADR 0085 의 2
- 지도의 「돌리는 법」 항목 하나, `vibe-audit` · `vibe-slice` 그대로 — ADR 0085 의 3
- 소급하지 않는다 — ADR 0085 의 4
- 검사를 세우지 않는다 — ADR 0085 의 5
- 감사 회차 `audit-internal` 하나, 새 기준으로 — ADR 0085 의 6

**열어 둔 것**

없음 — 항목의 글은 PR A 가 쓰고 리뷰가 본다. 글이 들 것은 ① · ② A ~ D · ③ B 가 닫는다.

## ⑤ 검증 계획

시험을 세우지 않는다 — 규칙의 문구다. 있는 검사와 `git` · `grep` · ③ 에 대어 본다.

| 보장 | 무엇으로 보이나 |
|---|---|
| A 닫는 PR 이 diff 에 든다 | PR A 본문에 고친 항목의 글. 「마지막 회차가 감사한 커밋」 · 「앞 조각의 닫는 PR」이 있다. `git diff` 의 덩이가 「돌리는 법」 항목 하나 |
| B 기준을 읽는 자리 | 항목에 「대장 지나간 쪽」 · 「회차 절」 · 「착공 전 기본 가지」가 있다 |
| C 같은 기준 | 항목에 이 조각의 회차가 다 같은 기준을 쓴다는 말이 있다. ③ B 의 행마다 항목이 기준 하나를 내는지 PR A 본문에 한 줄씩 |
| D 항목 하나 | `grep -c '\*\*돌리는 법\*\*' docs/procedure.md` → 1. `git diff --stat 36843e0 <A 머지> -- vibe-audit vibe-slice CHECKLIST.md CLAUDE.md` 빈 출력 |
| E 대체가 양쪽에 | `grep -n '0073 의 7 가운데' docs/adr/0085-*.md` · `grep -n '7 의 「`## 닫으며` 의 근거」(3 의 규칙) 몫은 ADR 0085 가 대체했다' docs/adr/0073-*.md` 가 한 줄씩 |
| F 이 조각에서 문다 | 닫기 전 회차의 브리핑 머리 「기준」이 `205bc09` 이고 「변경 파일」에 `docs/slices/65-standing-round-threshold/requirements.md` 가 있다 — 닫는 PR 의 `## 닫으며` |
| G 늘지 않는다 | 요구사항 성공 기준 5 의 명령과 `eval-key.py route` · `full` 의 출력 |

- **게이트** — `./scripts/gates.sh` 를 PR 마다 돌리고 끝 줄을 PR 본문에 든다. `python3 scripts/verify-docs.py` · `python3 scripts/verify-counts.py` · `python3 scripts/verify-map-pin.py` 가
  PASS 다(절 제목 · 새 수 없음 · 링크 그대로).
