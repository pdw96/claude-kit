# 조각 66 — 닫는 PR 의 글을 보는 회차 (2026-11-11 착공)

요구사항이다 — **무엇을 · 왜.** 어떻게 · 경계는 같은 폴더의 `design.md`, 대안이 있던 결정은 ADR 0085.

이 조각을 「다음 조각」으로 적은 닫힌 조각은 조각 65(상시 회차의 문턱)다 — 그 `## 닫으며 (2026-11-10)` 를 읽었다. 넘겨받은 것은 없다 — 회차 46 은 부적합 0 이고 NC-51 · NC-52 를 닫았으며,
확인불가 셋은 그 절이 닫았고, 「문서에 없어서」 A · B 는 조각 나눔 「실패 조건의 경계 — 도구의 멈춤과 저장소 설정」으로 갔다. 이 줄의 근거는 조각 58 의 닫는 세션이 회차 39 「문서에 없어서」
B 로 두었다. 의존은 `—` 다. 저자가 이 착공 세션에서 자리의 갈래를 정했다 — 세션이 추천한 쪽(ADR 0085 의 1). 착공은 `main`(`36843e0`) 위에서 연다. 이 착공 세션의 클론은 얕지 않았다(`git
rev-parse --is-shallow-repository` → `false`).

## 문제

**닫는 PR 의 글은 어느 감사 회차도 보지 않는다.**

- 닫기 전 회차는 ⑥ 의 마지막 PR 이 머지된 뒤, 단계 6 에 들기 전에 돈다(`docs/procedure.md` 「감사 회차」의 「언제」). 닫는 PR 은 그 회차의 결과를 들고 뒤에 선다. 다음 조각의 회차는 기준을
  착공 전 `main` 에 둬 왔다 — 회차 38 ~ 46 아홉 번의 브리핑 기준이 다 직전 조각의 닫는 PR 머지 커밋이다(설계 ③ A).
- 판정 고침만 대장 재감사로 닿는다(NC-41 → 회차 39, NC-51 · NC-52 → 회차 46). `## 닫으며` 의 근거(ADR 0073 의 3) · 「바로잡는 것」 · 확인불가를 닫은 근거는 아무 회차도 보지 않는다 —
  확인불가 U-52 ~ U-58 일곱이 닫는 세션의 `## 닫으며` 근거로 닫혔다(`docs/audit/nc-ledger.md` 「확인불가」).
- ADR 0073 의 7 은 그 근거를 「닫기 전 `audit-internal` 회차가 본다」고 했다. 그 회차는 같은 조각의 `## 닫으며` 보다 앞이다(감사 회차 39 「문서에 없어서」 B,
  `docs/audit/records/audit-internal-2026-11-09-052447.md`).
- 새어 나간 결함은 없다 — 닫는 PR 의 글이 틀려 머지 뒤 드러난 사례는 대장에 없다. 규칙 글이 볼 수 없는 회차를 가리키는 빈자리다.

## 핵심 사용자와 시나리오

- 사용자: 조각의 닫기 전 회차를 부르는 세션과, 그 회차의 `audit-internal`.
- 시나리오: 세션이 ⑥ 의 마지막 PR 을 머지하고 닫기 전 회차를 부른다 → 지도 「감사 회차」의 「돌리는 법」을 읽고 대장 지나간 쪽의 마지막 회차 절 첫 줄에서 「감사한 커밋」을 꺼내
  `/audit-brief <그 커밋>` 으로 브리핑을 만든다 → 브리핑 diff 에 앞 조각의 닫는 PR(`## 닫으며` · 마스터플랜 · 판정 고침)이 이 조각의 PR 들과 함께 든다 → 감사자가 앞 조각의 `## 닫으며` 근거를
  저장소에 대어 본다.

## 성공 기준

1. **결정이 기록된다** — 착공 PR 이 ADR 0085 를 더하고, 그 ADR 이 1 을 이 착공 세션의 저자가 정한 것으로 들며 머리에 「ADR 0073 의 7 가운데 「`## 닫으며` 의 근거」 몫을 대체한다」를 든다.
   같은 PR 이 ADR 0073 끝에 `## 대체 (2026-11-11)` 절과 「- 7 의 … 몫은 ADR 0085 가 대체했다 — …」를 덧붙인다.
2. **항목이 기준을 든다** — PR A 뒤 `docs/procedure.md` 「감사 회차」의 「돌리는 법」 항목이 (가) 회차의 기준을 이 조각 앞의 마지막 회차가 감사한 커밋으로 두고, (나) 그것을 대장 지나간 쪽의
   마지막 회차 절 첫 줄에서 읽으며 앞 회차가 없으면 착공 전 기본 가지로 두고, (다) 이 조각의 회차가 다 같은 기준을 쓴다고 하고, (라) 그래서 앞 조각의 닫는 PR 이 diff 에 든다고 하며, (마)
   ADR 0085 를 든다.
3. **한 자리다** — PR A 뒤 `grep -c '\*\*돌리는 법\*\*' docs/procedure.md` 가 1 이다. `git diff --stat 36843e0 <A 머지> -- vibe-audit vibe-slice CHECKLIST.md CLAUDE.md` 가 빈 출력이다.
4. **새 기준이 이 조각에서 문다** — 이 조각의 닫기 전 회차의 브리핑 「기준」이 `205bc09`(회차 46 이 감사한 커밋)이고, 그 diff 에 조각 65 의 닫는 PR 이 고친
   `docs/slices/65-standing-round-threshold/requirements.md` 와 `docs/master-plan.md` 의 65 줄이 든다.
5. **장치가 늘지 않는다** — `git diff --stat 36843e0 <각 머지> -- scripts .github vibe-audit vibe-slice compare` 가 빈 출력이다. 수트 지문(`scripts/eval-key.py route` · `full`)이 `36843e0`
   과 같다.
6. **게이트** — `./scripts/gates.sh` 가 이 조각의 PR 마다 작업트리와 CI gate 잡에서 통과한다. `python3 scripts/verify-docs.py` · `python3 scripts/verify-counts.py` ·
   `python3 scripts/verify-map-pin.py` 가 PASS 다(절 제목 · 새 수 없음 · 지도만 고친 커밋은 링크를 건드리지 않음).
7. **감사 회차** — 닫기 전 감사 회차를 돌려 `docs/audit/` 의 대장에 등록했다.

## 하지 않을 일

1. **검사를 세우지 않는다** — 브리핑의 기준을 무는 검사가 없다. 새 실패 조건이 없다(ADR 0085 의 5).
2. **지난 닫는 PR 을 다시 감사하지 않는다 — 소급하지 않는다** — 조각 56 ~ 64 의 닫는 PR 과 그 조각들의 요구사항 · 감사 기록은 글자 그대로다. ADR 0073 은 끝에 대체 절만 덧붙인다(ADR 0085 의
   4). 조각 65 의 닫는 PR 이 이 조각의 회차 diff 에 드는 것은 새 기준이 처음 무는 자리다.
3. **「감사 회차」의 다른 항목을 고치지 않는다** — 「언제」 · 「어느 감사자」(원천) · 「결과」 · 「넘긴 일」과 단계 표는 그대로다. 「돌리는 법」 항목만 고친다.
4. **`vibe-audit` · `vibe-slice` 를 고치지 않는다** — `/audit-brief` 커맨드 · 감사자 문구 · 스킬 · 틀 · 판 · 수트 지문 · 사본 · 두 스킬의 지도 링크가 그대로다(ADR 0085 의 3).
5. **다른 자리를 고치지 않는다** — `CLAUDE.md` · `CHECKLIST.md` · `AGENTS.md` · `README.md` 와 지도의 다른 절은 그대로다.
6. **조각 나눔의 다른 줄을 다루지 않는다** — 「실패 조건의 경계 — 도구의 멈춤과 저장소 설정」 · 「ADR 대체 표기의 자리」 · 「넘김의 「다음」과 넘긴 감사자」 · 「규칙 5 표의 행 사이와 답의
   꼴」 등.

## 제약

- 스택: 마크다운. 스크립트를 고치지 않는다.
- 원본: `main` `36843e0`.
- 비용: **$0** — 측정이 없다. 수트 지문은 `vibe-audit/` 만 읽는다(`scripts/eval-key.py` 머리) — 이 조각은 그 밖이다.
- 기간: 닫기까지 **사흘**(2026-11-14 까지).
- 리뷰: 착공 PR 도 구현 PR 도 스킬 `slice-review` 로 가른다. PR 마다 **3라운드**를 넘기면 소유자가 판정한다.
- 감사 회차: 닫기 전 — `audit-internal`(바뀌는 것 — 절차 지도 「감사 회차」의 규칙 글: 「돌리는 법」 항목 · ADR 0085 · 설계 ② 가 같은 말을 하는가, 항목이 「언제」 · 「넘긴 일」(ADR 0083 의
  3)과 갈리지 않는가, ADR 0073 의 7 의 대체가 양쪽에 있는가. 새 기준으로 돈다 — 기준 `205bc09` 라 조각 65 의 닫는 PR(`## 닫으며` 의 근거 · 마스터플랜 65 줄 · 새 줄)도 이 회차가 본다(ADR
  0085 의 6). 이 조각이 넘긴 일 — 기준을 무는 검사가 없어 이 회차가 본다(설계 ②)). 대장에 이 조각에 기대는 줄은 없다 — `audit-internal` 몫으로 열린 줄이 없다(`docs/audit/nc-ledger.md`).
  `audit-quality` 는 고르지 않는다 — 검사 · 변조본 · 평가셋이 바뀌지 않고, 실패 조건을 더하거나 고치지 않아 상시 회차도 걸리지 않는다.
