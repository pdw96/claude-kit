설계다 — **어떻게 · 경계.** 무엇을 · 왜는 같은 폴더의 `requirements.md`.

앵커볼트는 건드리지 않는다 — 지도의 모양은 「…의 칸」 여섯 절의 제목과 표 서식이 앵커볼트이고(`CLAUDE.md` 「앵커볼트」) `scripts/verify-docs.py` 가 읽는다. 「감사 회차」는 「일곱 단계」 절 안의
굵은 글이라 그 밖이고, 구절은 「넘긴 일」 항목 한 자리에만 든다. `vibe-slice/` 를 고치지 않아 `scripts/verify-map-pin.py` 가 보는 두 스킬의 지도 링크도 그대로다 — 지도만 고친 커밋은 링크를
다시 박지 않는다(ADR 0089 의 4). 스크립트 · 플러그인 · CI · 시스템 구조(`docs/architecture.md`)는 그대로다.

## ② 보장하는 것 / 보장하지 않는 것

**보장하는 것**

- **A 이름을 든 넘김만 다음 조각** — 조각 나눔의 줄을 이름으로 든 넘김만 다음 조각의 회차이고, 「닫기 전」 · 「다음」 · 이름 없는 「다음 조각」은 그 넘김을 쓴 조각의 회차라고 「넘긴 일」이
  든다(ADR 0089 의 1).
- **B 넘김은 감사자를 세우지 않는다** — 감사자를 고르는 자리는 원천 셋 하나이고, 넘긴 감사자를 원천이 고르지 않으면 넘김을 고친다고 「넘긴 일」이 든다(ADR 0089 의 2).
- **C 다른 항목은 그대로** — 「언제」 · 「어느 감사자」 · 「돌리는 법」 · 「결과」와 「넘긴 일」의 앞 문장들이 그대로다(요구사항 성공 기준 3).
- **D 지난 자리가 맞는다** — ③ 의 행이 다 새 구절로 자리가 하나로 나고, 넘긴 감사자를 원천이 고르지 않은 자리가 없다(하지 않을 일 3).
- **E 이 ADR 이 대체 규칙을 지킨다** — ADR 0089 의 1 · 2 의 결정 줄이 앞 ADR 의 결정을 번호로 들고 「대체가 아니다 — <까닭>」을 적는다(요구사항 성공 기준 1).
- **F 장치가 늘지 않는다** — 요구사항 성공 기준 5.

**보장하지 않는 것(알려진 한계)**

- **넘김을 쓰지 않거나 잘못 읽은 세션을 키 없이 막지 않는다** — 「어느 회차로 넘겼는가」 · 「넘긴 감사자가 원천에 닿는가」는 글의 뜻과 담당을 가르는 판단이다. `CHECKLIST.md` 와 감사 회차가
  본다(ADR 0089 의 5). 이 넘김은 이 조각의 감사 회차 줄이 범위로 든다.
- **「다음」으로만 적은 넘김은 다음 조각이 원천으로 고를 때만 본다** — ADR 0089 의 1 의 대가.
- **넘긴 감사자를 바꾸면 그 감사자의 담당으로 보는 만큼만 본다** — ADR 0089 의 2 의 대가.
- **다른 레포는 링크가 박힐 때까지 옛 「넘긴 일」을 읽는다** — ADR 0089 의 4 의 대가.
- **리뷰가 이 밖을 짚으면 범위 밖이다** — 요구사항 하지 않을 일.

## ④ 결정

**정한 것**

- 조각 나눔의 줄을 이름으로 든 넘김만 다음 조각의 회차이고 그 밖은 그 넘김을 쓴 조각의 회차 — ADR 0089 의 1(저자)
- 넘김은 범위만 더할 뿐 감사자를 세우지 않는다 — 원천이 고르지 않으면 넘김을 고친다 — ADR 0089 의 2(저자)
- 자리는 지도 「넘긴 일」 항목 끝 문장 — ADR 0089 의 3
- `vibe-audit` · `vibe-slice` 그대로, 링크를 다시 박지 않는다 — ADR 0089 의 4
- 검사를 세우지 않는다 — ADR 0089 의 5
- 감사 회차 `audit-internal` 하나, 지도 「돌리는 법」의 기준으로 — ADR 0089 의 6

**열어 둔 것**

없음 — 구절의 글은 PR A 가 쓰고 리뷰가 본다. 글이 들 것은 ① · ② A · B · ③ 이 닫는다.

## ⑤ 검증 계획

시험을 세우지 않는다 — 규칙의 문구다. 있는 검사와 `git` · `grep` · ③ 에 대어 본다.

| 보장 | 무엇으로 보이나 |
|---|---|
| A 이름을 든 넘김만 다음 조각 | 「넘긴 일」 항목에 「다음」과 「이름으로 들」이 있다. `git diff` 의 덩이가 그 항목 안 |
| B 감사자를 세우지 않는다 | 같은 항목에 「감사자를 세우지 않는다」 · 「원천이 고르지 않으면」이 있다 |
| C 다른 항목은 그대로 | `git diff <착공 머지> <A 머지> -- docs/procedure.md` 의 헝크가 하나이고 「넘긴 일」 항목 안이다. 「언제」 · 「어느 감사자」 · 「돌리는 법」 · 「결과」의 줄이 바뀌지 않았다 |
| D 지난 자리 | ③ A 의 행마다 · ③ B 한 줄을 PR A 본문에 — 구절이 내는 것. `git diff <착공 머지> <A 머지> -- docs/master-plan.md docs/adr docs/slices` 빈 출력 |
| E 대체 규칙 | ADR 0089 결정 1 · 2 의 줄에 「대체가 아니다 —」가 하나씩 — 줄에서 갈릴 수 있으니 줄 번호로 든다(회차 49 OB-66) |
| F 늘지 않는다 | 요구사항 성공 기준 5 의 명령과 `eval-key.py route` · `full` 의 출력 |
