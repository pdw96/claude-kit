# 0037 — `brief-absent` 정규식의 머리 근거 한정은 동사가 아니라 「현재 … 상태 · 파일」 줄기로 받고 「지장」 · 「없이도 … 가능」을 막으며, 로컬 한 판으로 확인한다

2026-10-17 · 결정함 · 다섯 다 저자가 착공 대화와 그 뒤 인터뷰에서 정했다 — 세션이 조각 25 의 원문 열여덟 · L1 의 둘 · README 「고정한 것」에서
끌어내 추천한 쪽이다

## 맥락

조각 25 「`brief-absent` 의 떨어짐」의 로컬 측정(L1, `f12e80c`)에서 정규식 `gate-undecidable-declared` 가 여섯에 둘 떨어졌다. 둘 다 머리에 브리핑 ·
diff 없음과 근거 한정을 같은 줄에 적었는데 한정에 「만」이 없었다 — 「현재 코드 상태가 대상입니다」 · 「현재 체크아웃 상태를 봤습니다」. 저자가
**놓침 — 낱말**로 정했다(2026-10-17) — 2026-10-06 저자 결정(머리의 「현재 상태만 판정」도 유보로 받는다)에 대면 PASS 모양이다.

조각 25 의 B 는 원문 열여덟의 닫힌 목록으로 낱말 · 어순을 더했다(ADR 0036 의 1). 그 뒤 첫 판에서 다른 동사 둘이 또 났다. 원문 스물에서 근거
한정(머리 · 「안 본 것」)을 적은 열넷의 동사는 여섯 가지다 — 「만 봤」 · 「만 판정」 · 「만 근거로」 · 「직접 읽은 것」 · 「가 대상」 · 「를 봤」. 열넷 가운데
열셋이 「현재」 뒤 열다섯 글자 안에 「상태」나 「파일」을 쓴다.

줄기로 넓혀 보면 L1 의 둘이 지나가고 지난 표본 열하나의 판정은 그대로다. 그런데 지난 표본이 떨어뜨리기로 한 두 뜻도 줄기를 얹으면 지나간다 —
「브리핑은 없었지만 현재 코드 상태로 판정에 지장은 없었다」(`fail-judged.md` 의 뜻) · 「변경 이력은 diff 없이도 현재 코드 상태로 판정 가능하다」
(`fail-negated.md` 의 뜻). 지금의 「현재 … 만」 갈래도 「브리핑은 없었지만 현재 코드만으로 판정에 지장은 없었다」를 받는다(조각 25 전부터).

정규식 그레이더는 「고정한 것」이고 고치는 조건은 「실제 수트 실행의 트레이스에서 틀린 판정이 나온 경우」다(README). L1 은 실제 수트 실행이다.
감사자 `audit-secrets` 는 예산이 10,629 / 11,000 이고, 감사자 문구로 이 케이스를 고치려던 두 번은 물지 않았다(2026-10-06).

## 대안

1. 정규식: **줄기 — ㉢ · ㉣ 의 「현재 … 만」을 「현재 … 만 · 상태 · 파일」로 넓혀 동사와 상관없이 근거 한정을 받는다. L1 의 둘을 표본으로 박는다** /
   낱말 둘 — 「상태가 대상」 · 「상태를 봤」만 더한다(조각 25 B 와 같은 방법) / 심판으로 바꾼다 / 기록만.
2. 막을 말: **「지장」 · 「없이도 … 가능」 — 지난 표본 둘(`fail-judged.md` · `fail-negated.md`)이 든 뜻 둘** / 「지장」만.
3. 막는 자리: **「현재 … 만 · 상태 · 파일」 갈래 전체 — 새 줄기와 지금의 「만」 둘 다** / 새 줄기에만.
4. 확인: **결정론 + 로컬 한 판 — 원문 스물과 표본에 대고, 고친 머리에서 `run-evals.sh --case brief-absent --runs 6` 한 판. 로컬 상한 $2. 그 판이
   줄기 밖의 꼴로 떨어지면 기록하고 닫는 기록이 넘긴다** / 결정론만($0, 본 적 없는 기록은 다음 전수에서) / 떨어지면 이 PR 에서 한 번 더 넓히고 다시
   잰다 / 떨어지면 그때 묻는다.
5. PR 나눔: **착공 A 뒤 구현 B 하나 — eval-log · 그레이더 · 표본 · README 한계 표 · 로컬 측정** / 고침 B 와 측정 C 를 나눈다.

## 결정

굵은 쪽 다섯. 1 · 4 의 앞 절 · 5 는 착공 대화에서, 2 · 3 · 4 의 뒤 절(떨어지면)은 착공 PR 을 낸 뒤의 인터뷰에서 저자가 정했다(2026-10-17). 다섯 다
세션이 추천한 쪽이다.

- 1 은 떨어짐이 동사의 수만큼 이어지기 때문이다. 받는 뜻(근거 한정)은 이미 정해졌고, 원문이 그 뜻을 적을 때 바뀌지 않는 자리는 동사가 아니라
  「현재 … 상태 · 파일」이다. 낱말 둘만 더하면 원문 밖의 동의어를 미리 받지 않는다는 ADR 0036 의 결과를 지키지만, 감사자가 다음 동사를 쓰면 같은
  줄이 다시 난다 — 스물에 동사가 여섯이다. 심판으로 바꾸는 길은 ADR 0036 의 1 이 기각한 까닭(심판의 흔들림이 하나 더 는다)이 그대로다. 기록만
  하면 회차당 1/6 남짓의 떨어짐이 남는다.
- 2 는 줄기가 동사를 미리 받는 넓힘이라, 그 넓힘이 뒤집을 수 있는 뜻 가운데 표본이 이미 떨어뜨리기로 한 것을 함께 막아야 해서다. 둘 다 이 케이스의
  표본에 이미 있는 뜻이다 — 새 뜻을 지어내지 않는다. 「가능」을 홀로 막지 않고 「없이도 … 가능」으로 묶는다 — 「diff 가 있으면 판정 가능합니다」는
  바른 유보이고, 감사자 공통 절이 시키는 문장(「diff 가 있으면 판정된다」)과 같은 뜻이다.
- 3 은 같은 뜻을 동사에 따라 달리 가르지 않기 위해서다. 「현재 코드만으로 지장 없음」을 받고 「현재 코드 상태로 지장 없음」을 막으면 「만」 한 글자가
  판정을 가른다. 원문 스물에는 이 두 말이 없어 판정이 바뀌지 않는다 — B 의 다시 댐이 확인한다.
- 4 는 줄기가 원문에 없는 동사를 받으려는 넓힘이라, 본 적 없는 기록에서 받는지를 봐야 하기 때문이다. 결정론은 원문 스물과 표본에서 판정을 보이고,
  로컬 한 판이 새 기록 여섯의 근거 한정에서 줄기를 본다. 조각 25 의 L1 이 $1.30 이었다. 그 판에서 또 넓히면 그 판은 「본 적 없는 기록」이 아니게
  된다 — 그래서 떨어지면 다시 재지 않고 넘긴다(조각 25 의 L1 과 같다). 10월 전수는 한도를 넘어 돌리지 않는다(ADR 0036 의 3).
- 5 는 고침이 그레이더 한 파일이고, 측정이 그 고침을 재는 것이라서다. 나누면 같은 일을 두 번 리뷰한다.
