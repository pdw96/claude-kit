# 0036 — `brief-absent` 의 떨어짐은 정규식을 원문의 닫힌 목록으로 넓히고, 심판은 재심 뒤 경계 행을 박으며, 전수 없이 로컬로 확인한다

2026-10-16 · 결정함 · 넷 다 저자가 착공 대화에서 정했다 — 세션이 아티팩트 여섯 · README 「고정한 것」 · 「심판」 · ADR 0035 에서 끌어내 추천한 쪽이다

## 맥락

`brief-absent` 가 여섯 전수의 열여덟 회차 가운데 넷에서 떨어졌다 — 정규식 `gate-undecidable-declared` 셋(2026-10-07 둘째 1 회차 · 10-15 낮
1 · 3 회차), 심판 `trap-no-guessing` 하나(10-15 낮 2 회차, FAIL ×3). 10-15 낮 전수는 한 전수에 셋이 겹쳐 0.708 로 문턱(0.8) 아래였다.
아티팩트 여섯을 받아 보니 두 그레이더의 사정이 다르다(조각 25 요구사항 「문제」).

- **정규식** — 떨어진 셋 다 유보 문장이 있다. 정규식이 받는 말과 어순이 아니었다 — 「현재 코드 상태만 봤고 기준 커밋과 diff 는 없습니다」
  (유보가 diff 앞) · 「커밋 간 변화(…)는 보지 않았습니다. 기준 diff가 없고」(같음) · 「`.claude/audit-brief.md` 가 없습니다. … 이번 판정은
  이 HEAD 의 파일 내용을 직접 읽은 것입니다」(「만」 없음). 거꾸로 10-16 3 회차는 유보 문장(「diff가 없어 구분하지 못했습니다」)을 못 읽고,
  다른 근거를 기다리는 U-1 안의 「그 diff도 됩니다」로 지나갔다. 정규식 그레이더는 「고정한 것」이고, 고치는 조건은 「실제 수트 실행의 트레이스에서
  틀린 판정이 나온 경우」다 — 이번이 그 경우다.
- **심판** — FAIL 표가 쉰넷 가운데 넷이고, 넷 다 「검사가 있다가 빠졌는지는 판정하지 못했습니다」 꼴(간접 의문 + 유보)의 회차에서 났다. 같은
  꼴이 열여덟 회차 가운데 열둘에 나왔고 열은 PPP 였다. 심판의 경계 예시 표에 이 꼴의 행이 없다. 조각 24 가 같은 모양(바른 글에 다른 판정)을
  재심 + 이유 묻기로 갈랐고, 심판 문구에 경계 예시 표를 박아 가름을 지났다(ADR 0035).

감사자 `audit-secrets` 는 호출 시 예산이 10,629 / 11,000 이다. 2026-10-06 에 감사자 문구로 이 케이스를 고치려 두 번 쟀고 물지 않았다(0/6 →
2/6 · 0/6, `docs/eval-log/2026-09-16_2026-10-06.md` 「brief-absent — 낱말이 아니라 질문으로 봤다」). 10월 전수 합은 $41.05 로 월 한도 $20 을
넘었다(ADR 0033).

## 대안

1. 정규식: **넓힌다 — 열여덟 원문에서 뽑은 닫힌 목록으로 유보의 어순(양방향)과 낱말을 받고, U-n 갈래가 다른 근거를 기다리는 U 항목으로
   지나가는 구멍을 좁힌다. 원문의 모양을 `pass-*.md` · `fail-*.md` 표본으로 박는다** / 심판으로 바꾼다 — README 「심판」이 「무엇이 있으면
   판정되는지를 함께 적었는가」를 심판의 일로 든다 / 고치지 않고 기록만.
2. 심판: **재심 + 이유 묻기 뒤 경계 행 — ADR 0035 의 방법으로 떨어진 기록을 같은 심판에 다시 대어 재현을 보고, 재현되면 경계 예시 표에 간접
   의문 + 유보의 행을 박아 옛 · 새를 같은 시각에 거꾸로 놓은 기록과 함께 가른다** / 재심 없이 원문만 보고 행을 박는다 / 기록만.
3. 확인: **로컬만 — 정규식은 원문 열여덟과 표본에 결정론으로 대고, 심판은 재심으로 가른 뒤 `run-evals.sh --case brief-absent --runs 6` 한 판.
   전수는 다음에 돌 때 지켜본다** / 고친 머리에서 전수 한 번(10월 한도를 더 넘김) / 11월 첫 전수에서 본다.
4. PR 나눔과 비용: **착공 A 뒤 구현 둘 — B 정규식(표본 · 결정론, 비용 0), C 심판(재심 · 고침 · 로컬 측정). 로컬 비용 상한 $5** / 진단 · 고침을
   한 PR(조각 24 꼴), $5 / B · C 나눔, $3.

## 결정

굵은 쪽 넷. 저자가 착공 대화에서 정했다(2026-10-16). 넷 다 세션이 추천한 쪽이다.

- 1 은 떨어진 셋이 다 유보를 적었고, 정규식이 그 말을 어순과 낱말로 놓친 것이기 때문이다. 받는 말은 2026-10-06 의 저자 결정(유보를 다른 말로
  적어도 받는다 · 머리의 「현재 상태만 판정」도 받는다)이 이미 정했다 — 이번 일은 그 결정을 원문이 실제로 쓴 모양에 맞춰 글자로 박는 것이다.
  정규식은 결정론이라 원문 열여덟에 그대로 다시 대어 고침을 볼 수 있다. 심판으로 바꾸면 이 케이스에 심판이 둘이 되어, 지금 갈라야 하는 심판의
  흔들림이 하나 더 는다. 기록만 하면 전수마다 1/6 꼴로 떨어지는 일이 남고, 한 전수에 둘이 겹치면 verdict 가 빨개진다.
- 2 는 흔들린 것이 같은 글에 대한 심판의 판정이고, 조각 24 가 같은 방법으로 원인을 가르고 고침을 지났기 때문이다. 재심 없이 행만 박으면 재현을
  보지 않고 고친다 — FAIL 표가 쉰넷에 넷이라 이 꼴이 정말 심판을 기울이는지, 다른 무엇(구체 커밋 이름 · 「있었다가」의 시제)이 기울이는지
  원문만으로는 모른다.
- 3 은 10월 전수 비용이 이미 한도의 두 배이고, 고치는 것이 그레이더 둘이라 감사자 · 다른 케이스의 판정이 움직이지 않기 때문이다. 정규식은
  원문 열여덟이, 심판은 재심이 같은 글에서 옛 · 새를 가르고, 로컬 한 판이 본 적 없는 기록에서 둘을 함께 본다.
- 4 는 두 고침의 방법이 달라서다 — 정규식은 키 없이 결정론으로 끝나고, 심판은 재심 · 측정이 든다. 한 PR 에 두면 리뷰가 두 주제를 함께 본다.
  B 가 먼저 머지되어야 C 의 로컬 측정이 고친 정규식으로 잰다.

## 결과

- 1: B 가 `graders/gate-undecidable-declared.md`(패턴과 본문)와 `samples/` 의 새 표본만 바꾼다. 받는 모양은 원문 열여덟에서 뽑은 닫힌 목록 밖으로
  넓히지 않는다 — 원문에 없는 동의어 · 어순은 알려진 한계로 둔다(README 「고정한 것」). 기존 `fail*.md` 다섯은 그대로 떨어져야 한다.
- 2: C 의 첫 커밋은 eval-log 의 재심 · 이유다. 재심 케이스 · 이유 묻기의 스크립트 · 트레이스는 저장소에 싣지 않는다. 옛 쪽이 재현하지 못하면
  「재현 못 함」으로 두고 심판을 고치지 않는다. 고치면 `graders/trap-no-guessing.md` 의 본문만 바뀐다.
- 3: 이 조각은 전수를 돌리지 않는다. 다음 전수에서 이 케이스가 어떻게 됐는지는 조각을 닫는 기록의 「지켜본 것」이 든다.
- 4: 두 그레이더 다 full 지문에만 들고 route 지문 밖이라 B · C 의 CI 는 eval 잡을 건너뛴다. 로컬 측정은 조각 전체 $5 안이다.
