# 0006 — 기획과 설계는 한 PR, 구현은 설계가 정한 나눔대로

2026-10-06 · 결정함

## 맥락

강호쟁패 #1 은 착공 문서와 가설공사(구현)를 한 PR 에 담았다. 지도(ADR 0005)에서 단계와 PR 의 관계를
정해야 했다. 증거는 PR 하나뿐이다.

## 대안

1. **기획 + 설계 한 PR, 구현은 설계 ⑥ 의 나눔대로** — 둘 다 문서라 리뷰가 짧다(ERP #80 처럼).
2. **단계 하나 = PR 하나** — 기획 PR 과 설계 PR 을 따로.
3. **지도에서 정하지 않는다** — 증거가 하나뿐이니 빈자리로 두고 단계 구분 조각에서 정한다.

## 결정

**1.**

## 결과

- 「PR 이 커진다」는 처음 문제에 설계 단계에서 답한다 — 구현 PR 의 경계를 설계 ⑥ 이 미리 정한다.
- 2 는 기획만으로는 리뷰할 거리가 적고 PR 수만 는다.
- 이 조각부터 적용한다 — 착공 PR(기획 + 설계)과 구현 PR 이 따로다(`docs/design/slice-2.md` ⑥).
- 강제는 없다. 설계가 머지되기 전에 구현 PR 이 서지 않게 하는 것은 로드맵 3.
