# 0071 — 하네스 밖 팔은 측정 전용 계정의 자격과 세션 자격이 없는 기계를 세울 때까지 러너가 잠근다 — ADR 0069 의 5 를 대체한다

2026-11-03 · 결정함 · 저자가 조각 52 의 닫는 세션에서 정했다(세션이 「잠그고 새 ADR / 전제를 고쳐 적고 유지 / 그 팔을 뺀다」를 대 보이고 잠그기를 추천했고, 저자가 그쪽을 골랐다).
같은 자리에서 저자가 측정 토큰을 교체하기로 했다

## 맥락

ADR 0069 의 5 는 하네스 밖 팔(`claude-security` 를 `claude -p` 로 직접 돌리는 길)이 제3자 플러그인에 측정 자격을 넘기고 `--permission-mode dontAsk` 로 격리 없는 Bash · Write 를
주는 것을 받아들였다. 근거로 든 전제는 셋이었다 — 고정 커밋의 플러그인, **측정 전용 자격**, **버리는 측정 기계**. 닫기 전 감사 회차 28(`audit-secrets`)이 그 전제를 확인불가 U-44 로
물었고, 닫는 세션이 저자 인터뷰와 이 세션의 환경으로 답을 받았다(2026-11-03).

- **(가) 자격** — `EVAL_OAUTH_TOKEN` 은 측정 전용이 아니라 저자 구독의 OAuth 토큰이고, CI 저장소 시크릿(`CLAUDE_CODE_OAUTH_TOKEN`, eval 잡)과 같은 값이다(저자 답).
- **(나) 기계** — 클라우드 세션의 컨테이너라 세션과 함께 버려진다. 다만 그 기계에는 세션 자신의 GitHub 자격이 환경 변수로 있다. 러너는 그 변수를 그 팔에 넘기지 않았지만, 그 팔의
  Bash 는 같은 사용자로 돌아 다른 프로세스의 환경(`/proc`)에 닿을 수 있는 자리다.
- **(다) 프록시** — 이 세션의 git 은 자격 없는 URL(`https://github.com/pdw96/claude-kit`)로 push 가 된다. 프록시가 GitHub 요청에 세션 자격을 붙이는 것으로 보인다. 러너는 그 팔에
  `HTTPS_PROXY` 를 넘겼다.
- **(라) 저장소** — 공개다(저자 답). 압축본으로 실은 측정 원문도 공개다.
- **흔적** — 두 측정(조각 51 · 52)의 그 팔 기록(하위 에이전트 것 포함)에서 `env` · `printenv` · `/proc/*/environ` · `curl` · `wget` · 자격 값 · 자격 접두사 꼴은 0 건이었다(감사 회차 27 · 28).

ADR 0069 의 5 가 받아들인 위험은 적힌 것보다 컸다 — 저자 구독 토큰과 세션의 GitHub 권한이 제3자 코드의 격리 없는 Bash 에 닿는 자리였다.

## 대안

1. **잠근다 — 러너가 하네스 밖 팔을 종료 2 로 막고, 측정 전용 계정의 자격과 세션 자격이 없는 기계를 세우는 조각이 푼다** / 전제를 사실대로 고쳐 적고 받아들임을 유지한다 / 그 팔을
   러너에서 뺀다.

## 결정

굵은 쪽.

- 받아들임을 유지하면 다음 측정도 같은 토큰과 같은 기계 권한을 같은 자리에 둔다. 토큰을 교체해도 새 토큰이 같은 자리에 간다.
- 그 팔을 빼면 보안 축의 가장 가까운 상대가 사라진다(ADR 0068 의 1). 잰 결과(조각 52 PR C 의 6/6)는 기록으로 남고 README 「같았던 축」이 든다 — 다시 잴 길만 닫는다.
- 잠그면 코드는 남아 다시 잴 조각이 조건을 세우고 풀면 된다. 푸는 조건 — (1) 측정 전용 계정의 자격을 쓴다(저자 구독 · CI 시크릿과 다른 값), (2) 그 팔이 도는 기계에 세션 자격이 없거나
  그 팔이 닿지 못한다(셸 격리, 또는 세션 밖의 버리는 기계), (3) 그 팔에 넘기는 프록시가 세션 자격을 붙이지 않는다. 셋을 그 조각의 ADR 이 근거와 함께 적는다.

대가 — 보안 축의 경쟁 팔은 다시 재지 못한다. 하네스 팔(`vibe-audit` · `none` · `pr-review-toolkit`)이 부르는 쪽의 자격을 하네스 격리 안에서 어떻게 다루는지도 확인하지 않았다(U-44 (마)) —
그 팔들을 다시 재는 조각이 먼저 본다.

## 결과

- ADR 0069 의 5 를 대체한다. 0069 의 1 ~ 4 · 6 은 그대로다.
- 조각 52 PR D 가 `scripts/run-compare.sh` 에서 `claude-security` 팔을 종료 2 로 막고, `compare/README.md` 와 설계 끝 날짜 항목이 이 ADR 을 가리킨다.
- 감사 회차 28 의 U-44 는 이 결정의 근거로 판정되어 NC-35 가 된다(닫는 PR 의 대장 등록). 저자의 토큰 교체는 대장의 그 줄에 날짜로 적는다.
