# 0070 — `trap-local-dev-password` 를 `pr-review-toolkit` 팔로도 재서 README 표의 빈 칸을 채우고, README 는 「설치만 한 상태는 따로 잰다」를 든다 — 조각 52 요구사항 하지 않을 일 2 · 3 을 그 한 칸만큼 넓힌다

2026-11-03 · 결정함 · 1 · 2 는 저자가 조각 52 PR C(#195)를 읽고 정했다(세션이 「재서 채운다 / 그대로 둔다」를 대 보이고 재서 채우기를 추천했고, 저자가 그쪽과 함께 2 의 한 줄을 골랐다).
3 은 세션이 정했고 PR C 에서 저자가 본다

## 맥락

조각 52 PR C 가 README 에 「무엇이 다른가 — 다른 플러그인과 맞대기」를 세웠다(ADR 0069 의 2). 그 표의 `trap-local-dev-password` 줄에서 `pr-review-toolkit` 칸이 「— (재지 않음)」이다.

- **비운 까닭은 설계였다** — 조각 51 설계 ③ A 가 케이스마다 경쟁 팔을 하나 정했고, 그 케이스는 보안 축이라 `claude-security` 였다. 러너는 `compare/cases.tsv` 의 경쟁 팔 칸이 그 팔인 케이스만 고른다.
- **그 칸이 주장의 근거를 가린다** — README 의 주장은 「상대가 함정을 결함으로 올렸다」에 선다. `pr-review-toolkit` 이 개발용 비밀번호를 가렸는지는 모른다.
- **README 의 숫자는 이름을 부른 회차다** — 플러그인 팔은 요청 머리에서 그 도구를 이름으로 불렀다(ADR 0067). 저자가 「플러그인 설치하면 되는 거 아냐?」라고 물었다 — 절은 「같은 요청 본문」만 적어 설치만 하면 그 숫자가 나온다고 읽힐 수 있다.
- **조각 52 의 하지 않을 일** — 2 「다른 세 팔을 다시 재지 않는다」 · 3 「재료를 고치지 않는다(`compare/` 의 … `arms.tsv`)」. 재려면 둘에 걸린다.

## 대안

1. 그 칸: **재서 채운다 — `pr-review-toolkit` 을 그 케이스에 3 회차** / 그대로 두고 README 에 까닭을 적는다.
2. README: **「한계」에 한 줄 — 플러그인 팔은 이름으로 불렀고, 설치만 했을 때 뜨는지는 route 수트가 따로 재며, 설치만 한 상태에서 함정까지 가리는지는 한 번에 재지 않았다** / 적지 않는다.
3. 러너가 그 케이스를 고르는 길: **`compare/cases.tsv` 의 경쟁 팔 칸이 쉼표로 여럿을 들고, 그 줄을 `claude-security,pr-review-toolkit` 로** / 러너에 케이스를 덧붙이는 깃발 / 그 케이스를 `pr-review-toolkit` 용으로 한 줄 더(같은 이름 두 줄).

## 결정

굵은 쪽 셋.

- 1 — 저자가 정했다. 비용은 회차당 약 $0.48(조각 51 의 그 팔) × 3 이라 조각 52 의 천장 $8 에서 남은 약 $4.1 안이다. 2/3 이상이 나오면 README 의 주장에서 그 케이스는 `pr-review-toolkit` 상대로 내린다.
- 2 — 저자가 정했다. 맞대기는 트리거를 재지 않는다(ADR 0067 의 대가). 그것을 README 에 적지 않으면 공개 확산이 그 숫자를 「설치하면 얻는 것」으로 옮긴다.
- 3 — 깃발은 부르는 쪽이 케이스를 고르게 해 「팔마다 무엇을 도는지」가 명령마다 갈린다 — 러너는 깃발을 박는 쪽이다(ADR 0066 의 5). 같은 이름 두 줄은 러너가 케이스 폴더를 이름으로 엮어 겹친다. 경쟁 팔 칸의 목록은 재료(픽스처 · 요청 · 그레이더)를 바꾸지 않고 「누가 도는가」만 넓힌다 — 다른 팔이 받는 케이스는 그대로다(가짜 `claude` 로 `vibe-audit` · `none` 열, `claude-security` 둘, `pr-review-toolkit` 여덟에서 아홉).

대가 — 조각 52 요구사항 하지 않을 일 2 · 3 이 이 한 칸만큼 넓어진다. `compare/cases.tsv` 가 `ba1f955` 와 한 줄 다르다 — 그 줄은 경쟁 팔 칸뿐이고, 픽스처 · 요청 · 그레이더는 그대로다. 그 팔은 하네스 팔이라 하네스 Bash 의 읽기 전용 오류(회차 26 OB-1)를 조각 51 의 그 팔과 같은 조건으로 받는다.

## 결과

- 조각 52 PR C 가 `compare/cases.tsv` 의 그 줄과 `scripts/run-compare.sh` 의 경쟁 팔 고르기를 고치고, 그 칸을 재 `docs/eval-log/2026-11.md` 와 README 표에 적는다.
- README 「무엇이 다른가」의 「한계」에 2 의 한 줄.
- 조각 52 설계 끝 날짜 항목이 이 ADR 을 가리킨다.
