# 0012 — 조각을 열 때 직전 조각의 「닫으며」를 읽는다

2026-10-07 · 결정함 · 저자가 정했다

## 맥락

조각마다 새 세션에서 연다. 새 세션은 `CLAUDE.md` → `docs/procedure.md` → 마스터플랜을 따라 조각을 꺼내지만, 직전
조각이 배운 것 — 「닫으며」의 넘긴 것 · 리뷰가 찾은 갈래 — 을 읽으라는 자리가 절차에 없다. 조각 4 를 닫으며 그 교훈을
다음 세션에 넘기려니 첫 메시지에 길게 적어야 했고, 저자가 조각마다 그렇게 쓸 수는 없다.

## 대안

1. **절차 0 단계(착수 전)의 들어가는 조건에 「직전에 닫은 조각의 `## 닫으며` 를 읽었다」를 더한다** — 새 세션은 「조각 N
   착공 시작하자」 한 줄로 시작하고, 교훈은 저장소가 넘긴다.
2. 교훈을 `CLAUDE.md` 에 모은다 — 매 세션 읽지만, 조각마다 늘어 「매 세션 지킬 규칙」이 아니게 되고 조각 4 가 걷은
   것과 같은 꼴이 된다.
3. 그대로 둔다 — 새 세션에 줄 첫 메시지에 사람이 적는다.

## 결과

- 「조각 N 착공 시작하자」만으로 직전 조각의 리뷰 갈래가 다음 착공에 닿는다. 「닫으며」의 「리뷰가 찾은 갈래」는 다음
  조각이 읽는 입력이 된다 — 쓸 때 다음 세션이 읽을 것으로 쓴다.
- 「직전에 닫은 조각」은 조각 나눔에서 가장 최근에 `닫힘` 이 된 줄의 조각 폴더다. 읽었는지는 검사하지 않는다 — 사람이
  본다(ADR 0010 의 2 와 같은 까닭이다).
- 절차 지도의 칸(「…의 칸」 네 절)은 바뀌지 않는다 — 앵커볼트 밖이다.
