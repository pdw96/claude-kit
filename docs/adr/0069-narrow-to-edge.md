# 0069 — 「같다」 축의 감사자는 그대로 두고 README 에서 주장하지 않으며, README 는 저장소 규칙의 효력 범위만 주장하고, `claude-security` 팔만 정답지를 가린 러너로 $8 안에서 다시 잰다

2026-11-02 · 결정함 · 1 ~ 3 은 저자가 조각 52 의 착공 세션에서 정했다(세션이 갈래마다 추천을 앞에 두고 물어, 저자가 셋 다 추천한 쪽을 골랐다). 4 ~ 6 은 세션이 정했고 착공 PR 에서
저자가 본다

## 맥락

조각 51 이 네 팔을 같은 재료 · 같은 요청 본문 · 같은 심판으로 돌려 축마다 판정을 냈다 — data · contract · secrets 같다, internal 앞선다(`docs/eval-log/2026-11.md` 「조각 51 PR C」,
ADR 0066 의 4 의 규칙).

| 축 | 묶음 | `vibe-audit` | 플러그인 없음 | 경쟁 팔 | 차 |
|---|---|---|---|---|---|
| data | 놓친 결함 | 11/12 | 12/12 | 12/12 | −1 |
| contract | 놓친 결함 | 6/6 | 6/6 | 6/6 | 0 |
| secrets | 되먹임 | 5/6 | 3/6 | 6/6 (하네스 밖) | −1 |
| internal | 되먹임 | 6/6 | 3/6 | 2/6 | +3 |

- **회수율 묶음은 감사자가 놓친 결함이다** — 조각 39 가 ERP 에서 담당 감사자가 놓치고 Codex 리뷰가 찾은 결함으로 만들었다. data · contract 의 판정은 이 묶음에서만 나왔고, 두 축에
  함정 케이스가 없다.
- **앞섬은 함정에 모였다** — 함정 둘에서 `vibe-audit` 5/6 · 플러그인 없음 0/6 · `pr-review-toolkit` 0/3(`trap-slice-scope`) · `claude-security` 3/3(`trap-local-dev-password`).
  떨어진 회차는 닫힌 조각 · 옛 `PRD.md` · `127.0.0.1` 에 묶인 개발용 비밀번호를 고칠 결함으로 냈다. internal 의 +3 은 `trap-slice-scope` 한 케이스에서 다 나왔다.
- **secrets 의 경쟁 팔은 정답지를 받았다(NC-29)** — 러너가 재료(`case.yaml` · `graders/found.md`)를 플러그인 폴더 안 `compare/` 에 엮고 그 폴더를 `--plugin-dir` 로 넘긴다
  (`scripts/run-compare.sh:79-96` · `:198`). 주 트레이스 여섯에는 그 경로가 0 건이지만, 연구원 · 하위 에이전트의 호출은 트레이스에 실리지 않는다. 그 팔은 격리 없는 Bash 를
  가져 디스크의 이 저장소 클론도 읽을 수 있다.
- **회차 26 「안 본 것」** — 하네스 밖 팔이 제3자 플러그인에 `CLAUDE_CODE_OAUTH_TOKEN` 을 넘기고 `--permission-mode dontAsk` 로 Bash · Write 를 준다(`audit-secrets` 몫).
- **비용** — 11 월 합이 이미 약 $66.1 이다. 그 팔 여섯 회차는 지난번 $4.09(심판 포함)였다.

## 대안

1. 「같다」 축(data · contract · secrets)의 감사자: **그대로 두고 README 에서 앞선다고 말하지 않는다** / 체크 항목을 효력 범위 쪽으로 좁힌다 / 감사자는 두고 README 가 그 축은 경쟁
   플러그인을 함께 쓰라고 권한다 / 감사자를 뺀다(이름은 앵커볼트).
2. README 의 주장: **「저장소가 스스로 정한 규칙의 효력 범위(닫힌 조각 · 옛 문서 · 로컬 전용 값)를 고칠 결함으로 올리지 않는다」 — 숫자 · 재료 · 모델 · 커밋 · 표본 크기와 함께,
   상대는 플러그인 없음과 `pr-review-toolkit`. 자리는 루트 `README.md` 의 절 하나** / 판정 표 그대로 「내부 규칙 감사에서 앞선다」 / 숫자 없이 서술만.
3. 다시 재기: **`claude-security` 팔만, 천장 $8** / 러너만 고치고 재지 않는다 / 네 팔 다(천장 $35).
4. 정답지를 가리는 법: **재료를 플러그인 폴더 밖 임시 폴더에 두고 `--plugin-dir` 에는 플러그인만 넘기며, 회차마다 임시 HOME 의 세션 기록을 남겨 정답지 낱말을 센다** / 플러그인
   폴더 밖에 두기만 한다 / 재료를 기억에만 두고 디스크에서 지운다 / 격리로 막는다.
5. 자격과 `dontAsk`: **받아들이고 적는다 — 고정 커밋의 플러그인 · 측정 전용 자격 · 버리는 측정 기계** / 하네스 밖 팔을 셸 격리 안에서 돌린다 / 그 팔을 뺀다.
6. 결과를 남기는 길: **조각 51 닫기와 같은 압축본(`docs/eval-log/compare-<날짜>.tar.xz`)에, 러너의 끝 줄이 그 길을 찍는다** / 압축본만 / 아티팩트 · 릴리스 첨부.

## 결정

굵은 쪽 여섯.

- 1 — 저자가 정했다. 「같다」는 그 축에서 감사자만의 몫이 이 재료에 없다는 말이지 어느 줄이 쓸모없다는 말이 아니다 — 회수율은 감사자의 실패로 만든 재료라 반대로 기울고, 두 축에는
  함정이 없다. 좁히면 문구가 바뀌어 수트 지문이 바뀌고 route · full 수트가 돈다. 그 돈으로 「좁힌 뒤 나빠지지 않았다」만 재고 「좁혀서 나아졌다」는 재지 못한다. 경쟁 쪽을
  권하는 문장은 그 플러그인의 판 · 이름에 README 를 묶는다. 빼는 것은 앵커볼트(`CLAUDE.md`)다.
- 2 — 저자가 정했다. 잰 것 가운데 상대가 0 이고 `vibe-audit` 가 5/6 인 자리만 주장한다. `claude-security` 는 secrets 함정에서 3/3 이었고 그 칸이 NC-29 의 전제 위에 서서 상대로
  두지 않는다. 판정 표 그대로 「internal 에서 앞선다」고 쓰면 +3 이 한 케이스에서 나온 것을 가리고, `gate-comment-owned` 처럼 셋이 같은 자리까지 넓게 읽힌다. 숫자 없이 쓰면 「공개
  확산」이 옮길 근거가 없다. 루트 README 에 두는 까닭 — `vibe-audit/README.md` 는 수트 지문 밖이지만 `CHECKLIST.md` 가 판 올림을 묻고, 「공개 확산」이 영어로 옮길 입구가 루트다.
- 3 — 저자가 정했다. secrets 의 판정이 그 팔 하나에 달렸다 — 4/6 이상이면 「같다」, 3/6 이하면 「앞선다」. 러너만 고치면 NC-29 의 전제가 그대로 「공개 확산」에 넘어간다. 네 팔을
  다 다시 재면 다른 세 팔의 칸이 고친 것 없이 다시 돌고, 11 월 합이 약 $92 가 된다. 천장 $8 은 지난 $4.09 의 두 배 안쪽이다.
- 4 — 폴더 밖에 두기만 하면 NC-29 의 「배제하지 못한다」가 그대로 남는다 — 디스크에는 여전히 있다. 기억에만 두어도 이 저장소의 클론에 `compare/` 가 있어 막지 못한다. 격리는
  하네스 안에서 그 스킬이 서지 않은 원인과 같은 꼴(ADR 0068)이라 측정이 서지 않을 수 있다. 건네지 않고, 남는 길은 센다 — CLI 가 임시 HOME 에 쓰는 세션 기록은 하위 에이전트의
  것까지 든다. 세지 못한 하위 실행은 C 가 그 수를 적는다.
- 5 — 측정 자격(`EVAL_OAUTH_TOKEN`)은 측정에만 쓰고, 플러그인은 한 커밋에 고정했고, 측정 기계는 세션과 함께 버린다. 격리는 4 와 같은 까닭으로 측정을 세우지 못할 수 있다. 빼면 보안
  축의 가장 가까운 상대가 빠진다(ADR 0068 의 1). 받아들인 위험은 설계 ② 「보장하지 않는 것」에 적고 닫기 전 `audit-secrets` 회차가 본다.
- 6 — 조각 51 닫기의 압축본은 파이썬 `tarfile` 로 풀리고 0.5MB 였다. 같은 길이면 두 측정이 한 자리에 있다. 러너의 끝 줄은 NC-28 의 둘째 제안이다 — 다음 측정이 기억에 맡기지 않는다.

대가 — README 의 주장은 함정 두 케이스 · 6 회차 위에 서고, 이 재료 · 이 수트 모델(`claude-sonnet-5-5`) · 이 경쟁 커밋(`a7ba5b9`)에서만 맞다. 「같다」 축의 감사자 문구는 그 축에서
감사자만의 몫이 없다는 측정을 안고 그대로 남는다. secrets 의 판정은 여전히 하네스 밖 팔과 견준다.

## 결과

- 1: 조각 52 요구사항 하지 않을 일 1. `vibe-audit/` 를 고치지 않는다.
- 2: 조각 52 PR C 가 `README.md` 에 절 하나를 더한다 — 성공 기준 6.
- 3 · 4 · 6: 조각 52 PR B 가 `scripts/run-compare.sh` 의 하네스 밖 길을 고치고, PR C 가 그 팔을 다시 재 `docs/eval-log/2026-11.md` 에 secrets 축 판정을 다시 적는다. 설계 ② A ~ E.
- 5: 조각 52 설계 ② 「보장하지 않는 것」 · 닫기 전 `audit-secrets` 회차.
