# 0063 — 조각 48 B 는 둘째 전수의 `gap-unowned` 미달을 그레이더가 받는 꼴의 빈칸으로 보고, 셋째 전수 없이 로컬 확인으로 머지한다

2026-11-01 · 결정함 · 저자가 조각 48 B 의 세션에서 정했다(세션이 둘째 전수의 미달 둘을 갈라 보이고 「로컬로 확인 뒤 머지」 · 「셋째 전수」 · 「채점을 먼저 고침」을 물어,
저자가 세션이 추천한 첫째를 골랐다). ADR 0062 의 2 가 정한 「전수를 한 번 더」의 결과를 받는다

## 맥락

둘째 전수([run 41265204732](https://github.com/pdw96/claude-kit/actions/runs/41265204732), `6d0ad92`)의 verdict 가 떨어졌다. 첫 전수가 짚은 `brief-absent` 는 0.917 로
돌아왔고, 새로 `gap-unowned`(`audit-secrets`)가 **0.795** 로 문턱 0.8 아래다(`docs/eval-log/2026-11.md`).

- 1 회차 `gate-escalated-perf` · `gate-escalated` — 공급망 · 성능 발견을 `### 담당 없음 — 호출자 판단 필요` 제목 아래 번호 목록(`1.`)으로 적었다. 두 정규식은 그 표식 아래
  항목을 `-` · `*` · `|` 로만 받는다.
- 2 회차 `gate-no-fake-owner` — 심판이 「import 안 된 점 … audit-quality 의 담당」을 지어낸 담당으로 봤다. 이 그레이더는 전에도 흔들렸다(`scripts/verify-evals.py` 머리의 2/12).

B 가 바꾼 자리는 공통 절의 심각도 문단 · 출력 칸 · 「보류(Hold)」 비유 하나다. 「담당 없음」의 꼴이나 담당을 고르는 말은 건드리지 않았다.

세션이 같은 머리에서 `--case gap-unowned --ablation none --runs 6` 을 돌렸다 — **0.936**, 4 회차 하나가 같은 두 정규식을 떨어뜨렸다. 그 기록은 공급망 · 성능을 「담당 없음 — 호출자
판단 필요 (NC 번호 없음)」 줄 아래 **표**로 적었다 — 표식 뒤의 덧붙임과 빈 줄 때문에 정규식의 표 갈래가 받지 않는다. 두 미달 다 내용은 제자리에 있고 꼴이 그레이더 밖이다.

11 월 전수 합은 이미 $29.45 로 월 한도 $20(`CHECKLIST.md` 「감사자 문구를 고쳤다면」)을 넘었다.

## 대안

1. **로컬 6 회차로 확인하고, 셋째 전수 없이 머지한다. 그레이더의 빈칸은 조각 나눔의 예정 줄로 넘긴다** / 셋째 전수(11 월 합 약 $46) / 이 PR 에서 `gap-unowned` 의 정규식을 넓히고
   로컬로 재서 머지.

## 결정

굵은 쪽.

- 셋째 전수는 같은 꼴의 흔들림을 다시 굴리는 일이다 — 이번 두 전수에서 문턱 아래로 간 케이스가 매번 달랐다(`brief-absent` → `gap-unowned`). 한 번 더 돌려 초록이 나와도 B 가
  옳다는 근거가 늘지 않는다.
- 정규식을 이 PR 에서 넓히면 조각 48 의 범위(심각도) 밖의 케이스를 고치게 되고, 그 고침에도 표본과 변조본이 따라야 한다. 따로 꺼낼 일이다.
- 미달의 내용이 제자리에 있다는 것은 두 기록(전수 1 회차 · 로컬 4 회차)을 읽어 확인했다.

대가 — B 는 전수 verdict 통과 없이 머지된다. 조각 48 요구사항 성공 기준 5 의 「전수 verdict 통과」는 닫는 기록이 미달로 적는다. `gap-unowned` 의 그레이더 빈칸이 고쳐지기 전까지
같은 꼴이 다른 전수에서도 이 케이스를 문턱 아래로 보낼 수 있다.

## 결과

- 조각 나눔에 「`gap-unowned` 표식 아래의 번호 목록 · 표」 예정 줄이 선다.
- B 의 측정 기록은 `docs/eval-log/2026-11.md`, 결정은 조각 48 설계 끝 날짜 항목.
