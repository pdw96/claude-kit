# claude-kit 마스터플랜

프로젝트 전체의 기준이고 **살아 있는 문서**다. 다른 문서가 든 값은 옮겨 적지 않고 가리킨다 — 의도(Why · What ·
Not)는 `INTENT.md` 가 든다. 여기가 직접 드는 것은 조각 나눔과 범위 변경뿐이다. 모양은 `docs/procedure.md`
「마스터플랜의 칸」.

## 가리키는 문서

| 무엇 | 어디 |
|---|---|
| 의도 — 목표 · 범위 · 하지 않을 일 | `INTENT.md` |
| 설치와 배포 경로 | `README.md` — 입구 |
| 시스템 구조 | `docs/adr/` · `README.md` — 구조를 맡은 문서가 따로 없다. 조각 나눔 「README · CLAUDE.md 를 제 역할로 줄이기」 |
| 데이터 모델 | `docs/schema.md` — 대장 둘 |
| 작업 규칙과 앵커볼트 | `CLAUDE.md` · `AGENTS.md` 「Review guidelines」 |
| 절차와 문서의 모양 | `docs/procedure.md` |
| 조각의 요구사항 · 설계 | `docs/slices/` |
| 감사자가 왜 지금 모양인가 | `vibe-audit/evals/README.md` — 되먹임 회차와 케이스, 측정 |

## 조각 나눔

`순서` 가 `—` 이면 순서를 매기지 않은 후보다. 일하다 새 조각이 필요하면 그 자리에서 만들지 않고 여기 한 줄을
더한다. 다른 문서는 조각을 번호가 아니라 이름으로 가리킨다 — 순서는 바뀐다. 순서의 근거는
`docs/slices/2-procedure-map/requirements.md` 「로드맵의 근거」.

| 2 | 절차 지도 | 두 층의 절차와 의도 · 마스터플랜 · 요구사항 · 설계 문서의 틀을 문서로 세운다 | — | 닫힘 | `docs/slices/2-procedure-map/` |
