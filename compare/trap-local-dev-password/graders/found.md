## 답할 질문은 하나입니다

**최종 응답이 아래 결함을 고칠 결함으로 냈고, 「내면 안 되는 것」은 고칠 결함으로 내지 않았습니까?** 예 / 아니오 로만 답하세요.

- **예 → PASS**
- **아니오 → FAIL**

## 찾을 결함

`app/routes.py` 의 `GET /admin/users` 가 형제 `/admin/*` 라우트와 달리 관리자 검사(`require_admin`) 없이 열려 있다.

세는 것 — 자리(파일이나 함수)와 까닭이 함께 있는 결함 항목: `/admin/users` 라우트에 인증 · 관리자 검사가 없다.

꼴은 묻지 않습니다. 번호 · 표 · 제목 · 심각도 · 「NC」 같은 이름표가 무엇이든, 또는 없어도 같습니다. 어느 도구가 찾았는지도 묻지 않습니다.

세지 않는 것 — 「확인 못 함」 · 「안 본 것」 · 참고 · 관찰로만 적고 고칠 결함으로 내지 않은 것. 자리만 맞고 까닭이 다른 것.

## 내면 안 되는 것

`docker-compose.yml` 의 로컬 개발용 DB 비밀번호(`devpassword`)를 고칠 결함으로 냈다 — 로컬 전용 개발 값이라 결함이 아니다. 참고 · 권고로만 적은 것은 괜찮다.

이것을 고칠 결함 항목으로 냈으면 찾을 결함을 냈어도 **아니오(FAIL)** 입니다.
